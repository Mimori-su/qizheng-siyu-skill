# 解析分类与流水线（多代理断盘）

> 按《基础知识扫盲》的分类，把断盘解析拆成 N 个"分类"，每个分类由**一个子代理**负责；**顺序接力**：第 1 步完成 → 输出交给第 2 步 → 依此类推，最后一步汇总。

## 一、分类（11 类，与扫盲目录对应）

| 序号 | 分类 | 该步子代理负责什么 |
|---|---|---|
| 1 | 十一曜星体象意 | 读每颗星（日月木火土金水炁孛罗计）的人物/场所/身体/职业/物品/正负面征象 |
| 2 | 四时喜忌 | 按生月四时，读各星喜忌（如秋金喜水泄、冬土喜火罗日忌水孛） |
| 3 | 明晦昼夜 | 昼/夜生、向明背晦、升沉顺逆、残月增辉、火月争光 |
| 4 | 星体强弱 | 入垣升殿庙旺喜乐、宫主/度主、迟速逆留、得地失地 |
| 5 | 生克与恩难仇用 | 生克链、制化/通关、解救放出的吉凶、余奴犯主（含五类特殊情况） |
| 6 | 十二宫 | 宫义、五行、掌守、七强五弱、各宫主星 |
| 7 | 神煞 | 神煞起例与应象（口舌/血光/喜事/文书/出行/丧孝/破财） |
| 8 | 二十八宿 | 躔度五行、宿象意、限度宜忌 |
| 9 | 运限 | 大限（宫限+度限）、小限、月限、飞限、流年、太岁填实、顶度 |
| 10 | 财帛 | 财帛宫/财帛主、正偏财、财库、判财四步、财帛宫破财信号 |
| 11 | 八格/富贵层次 | 贵富贫贱寿夭贤愚、格局层次、职业取象 |

## 二、流水线（顺序接力）

```
输入：星盘数据（命度/身度/十一曜落宫躔度/化曜/神煞/大限/流年）
  │
  ▼
[子代理1] 十一曜星体象意 ──输出──┐
  ▼
[子代理2] 四时喜忌（接收1的输出）──┐
  ▼
[子代理3] 明晦昼夜（接收1+2）──┐
  ▼
[子代理4] 星体强弱（接收前序）──┐
  ▼
[子代理5] 生克与恩难仇用（接收前序）──┐
  ▼
[子代理6] 十二宫（接收前序）──┐
  ▼
[子代理7] 神煞（接收前序）──┐
  ▼
[子代理8] 二十八宿（接收前序）──┐
  ▼
[子代理9] 运限（接收前序）──┐
  ▼
[子代理10] 财帛（接收前序）──┐
  ▼
[子代理11] 八格/富贵层次（接收前序）──┐
  ▼
汇总成最终断盘结论
```

## 三、每个子代理的职责约定

1. 每个子代理只做自己那一个分类，**不越界**。
2. 每个子代理**接收上一子代理的全部输出** + 原始星盘数据，在此基础上继续。
3. 输出格式统一：`【分类名】结论 + 关键依据（星体/生克/行号）`。
4. 生克/余奴/财帛这几步必须严格按 skill 里的校准规则（旺衰→谁无制→解救吉凶→余奴五类）。

## 四、运行方式

用 workflow 工具的 `pipeline`/顺序 `agent` 串联：每个 `agent` 的 prompt 里带上"上一子代理的输出 + 本分类职责 + 原盘数据"，顺序 await，最后汇总。
