# 余奴犯主专题

本专题沉淀余奴犯主的全部判定、解救、转化与读象规则，出处标注到资料库文件与行号（基础知识扫盲.txt／天官派理论梳理.txt／琴堂派理论梳理.txt）。末尾附用户校准结论。

## 一、本体：谁是奴

1. **四余归属**：炁＝木余（仁之小者）、孛＝水余（智之小者）、罗＝火余（礼之小者）、计＝土余（基础知识·性情论 2927–2931）。**金无余奴**——金"以土计为恩，以火罗为难，无余奴，较不喜孛"（2591，孛泄金气）。
2. **总定义**（《四十二详论》2921）："气孛罗计，乃五星之奴，不宜与身主度主，及命主共躔，此则小人犯主之象也。若得四余独行，不杂七政之间则美也。主星旺，奴星弱，则无害，主能制之；奴星强，主星弱，主不能制之，则害主矣。"
3. **四余本性**：小人星，不宜侵犯太阳（2915《果老星宗》，如小人在君王之侧）；喜独行、忌冲突混杂（2917《玉衡经》）。但四余非纯凶——"一主专权，敢掌当朝之大事；四余独旺，能教众国以来降"（2911《望斗经》）；"一孛朝天，到官宫而作宰"（2913《摘金碎玉》）——独行得用反成格。
4. **广义"奴"含泄气一层**（2995–3001）："余奴怕伤主，泄气最为殃。我去生他，挈去我之气脉为泄，五星背令最怕逢之——金见水孛、木见火罗、水见木炁、火见土计、土见金星，四正度相逢亦凶。"（"土见金星"中金星对土只作**普通泄气**，不按余奴犯主论——见校准结论2。）

## 二、犯主的形式（怎么才算犯上）

1. **同躔共宫**：与身主、度主、命主共躔（2921）。
2. **同度先后**：奴前主后＝余奴抗主（郑希成注2999："水孛同躔一处，或孛前水后，谓之余奴抗主"）。
3. **主起别宫、奴独占本殿**＝伤主（2999）；即"主曜失躔，奴余反居正位"（1141：木居亢失位、炁反得寅亥居之；罗卯戌、计子丑、孛巳申同例）。
4. **躔同五行之度（划度）**："划度者，则四余犯本主度也。如孛犯四水度，炁犯四木度，罗犯四火度，计犯四土度也"（7359）。
5. **顶度**（天官派核心手法）：奴星对顶主星所躔之度，纵不同宫亦算犯。顶度本身是中性交感技术，可主动借星顶度取化（天官258–259：借用金星顶木星、借用水星顶罗）。
6. **泄气**：见一.4。

## 三、犯不犯得动：强弱判定

1. 主旺奴弱无害，主能制之；奴强主弱则害主（2921）。
2. **当令之主的余奴一般犯不了**（2091：卯辰巳月木见炁，连珠同行）。
3. **例外**：奴居旺地＋主落空亡，纵当令也伤（2113："炁在亥宫是很旺的位置，且命度主又在空亡位，此时这个炁对命度主和月身的伤害还是比较大的"）。
4. **失令最怕**（2167）：木到七八月弱，"财主就管不住余奴了"。
5. 主起高强，虽犯度不为害（2999、7361）。
6. **主秉令则奴主相扶反吉**（2999、7361、7367）：如冬月水星秉令，孛不犯主，"奴烈罗计皆不划主，最宜详辨"。

## 四、解救与转化

1. **太阳解救**（天官派铁律，609–610）：《天官赋》"余奴占度，主必无光。主侍君行，奴为我用。凡余奴犯主，必逢太阳解救。若无太阳，便作无光论矣。天官朝阳，余奴同宫反吉。"木为天官辅太阳行，炁不能犯——以有太阳为主耳。
2. **制奴**：克星制余奴，即"金煞制余奴"（1199）。袁世凯案（865）：炁犯木命度，金克炁，难星为用；但太阳夹在金炁之间有解决争战之意，隐患是运限推动炁仍会犯度（871）。琴堂十二宫断丑宫（天官1249）："太白得地，赶退余奴，无有不是。"
3. **通关**：难星余奴与主之间有星通关则祸解（1299案例：月身遇到难星和余奴，中间还有火去通关）。
4. **先入为主定敌我**（果老法，865）：炁先入宫犯我、金后入＝难星克余奴，对我有利；若金先入，则金克我、炁在后抗杀——同一组星，先后不同则敌我互换。**先后以宫位为准（以宫为用）——见校准结论1**。
5. **包夹转移**：余奴包夹克别物时，不算犯主（487）。
6. **奴为我用（抗杀／敌杀）**：先见杀再见奴＝余奴抗杀，吉；先见奴再见杀＝杀制余奴（2171）。《琴堂五星赋》"须知余奴拒敌，得经本主自如"（2993：炁与金难同宫，余奴敌杀，本主无忧）；火得罗为余奴敌杀，宛转成局（2415–2425）；"煞克于奴，本主自旺"（1133–1134：金煞与炁同行相敌，力不及木，本主得免）。**识别要点（校准20，案例8上海盘）**：杀星克主星/用星时，先查主之奴是否贴杀——同宫同度相守最切，其次对冲三合；奴贴杀即敌杀成立，杀力被牵制，主得救。**抗杀看奴与杀的位置关系，不看奴自身旺衰空亡**——奴落空亡/被杀伤不碍抗杀，恰应"先将奴仆杀伤，而本主得免"。实例：计都（劫财）拱克水星（正印用星），孛（水之奴）与计同宫同度相守＝贴杀抗杀，水星得救。
7. **四余作天官不忌**（天官368）：四余作天官而主星为伤官者不忌，以余奴能抗主也——但须看向背：伤官向天官而来亦有忌，背我而去不妨；伤官前来而天官后来亦无妨。
8. **日月之奴反为仆用**（琴堂十二宫断，天官1267）：午未二宫属日月，罗计非朔望而遇此，"为我奴仆，反凶为吉，甚是获福"。

## 五、行限中的犯主（《余奴伤主论》3011–3017）

- **炁伤木**：炁躔角斗奎井或木炁同躔，限至木度决死；有水孛金在木度可解（水孛生木、金制炁）；秋月斗角井最忌，奎度可解。
- **孛伤水**：孛躔箕壁参轸，限至水度决死；参壁箕尤甚、轸祸轻；水败背令不忌；有木气土计在水度可解（木气泄孛、土计制孛）。
- **罗伤火**：罗躔尾室觜翼，限至火度决死；尾室极怕、翼度祸轻；正三四六八九十月忌之切；有水孛木气在火度可解（水孛克罗、木气生火）。
- **计伤土**：计躔氐女胃柳，限至土度决死；有火罗木气在土度可解（火罗生土、木气制计）。
- **行对顶度处见祸**；生于冬月秉令者奴主相扶反吉；主起高强虽犯度不为害（2999）。
- **总纲**（1135–1138）："余奴犯主，纵吉为凶"，"限遇煞奴，十难一免"——且**难星的余奴也算**：如金见火为煞，限行不见火、见罗，为煞之奴星，亦不免。
- **流年激发**：填实奴星之宫即吊起犯主（2117案例：癸亥年亥填实炁星犯主、吊起计星夹克限度）。

## 六、化曜层的余奴欺主（天官派）

1. **总纲**（264–265）："最忌余奴犯主，主贵而无光。"己年火为天官兼命度主，最忌罗顶度，纵合天官魁星贵格而不贵，宜太阴星制之。鱼按极关键：**此时癸罗为偏财能生官星，但仍以余奴犯主论**——化曜关系再好，犯主仍论犯主。
2. **降等梯度**（科甲案例群698–758）：
   - 魁星暗顶余奴（698：乙日顶罗、丁计顶气、戊火顶罗之类）：纵身命合天官清高，上中一榜。
   - 天官顶奴（717壬年木天官顶炁、718癸年木顶炁掌枭囚）：主必无光、官星有损→贡士、入泮。
   - **有制则升**（758丁年水主、孛枭躔度为余奴欺）：得气星偏财三合得制→大贵，但"终嫌余奴之破，异路功名"；若得杰星顶孛、制尽为妙，则是科甲。
3. "文魁照耀值余奴，章而暗；奴犯主有难堪用"（848–849）。
4. **余奴顶主贵贱不一论**（967–968）：奴顶主不一律凶，看奴所化之曜——甲年气化天官顶木主大贵、辛年孛化魁次之、壬年气同、己年气化文亦然、庚年孛化生官主富、丙丁年气化生官天荫顶木多有巨富、戊年孛化天官顶水妙；反例：戊年气化伤官顶木为贱（若会生官，异路功名）；"丁年计化官魁，土若顶之，最凶"（**照原文用——见校准结论3**）。
5. **两母争权**（1125–1126）：恩星与恩奴同会（土主限见火罗同会），吉而实凶——母与余奴方争权未息，纵能爱子亦无力。
6. **母星反党余奴**（1119–1120）：木不生火、反生余奴之罗，"是我父母有用之气，反党余奴刑囚之辈，何暇顾我"。

## 七、应象读象库

- **小人**：犯主即小人犯主之象（2921）；"余奴夹克我，身边有小人，除非煞制余奴——用煞身边小人全被干掉，有手段的人"（1053）；余宿侵本垣＝小人用事（琴堂729）。
- **夺财**：余奴旺而克财星＝钱被别人夺去（1103）；恩星生余奴（奴恩同行泄其气）＝钱被别人拿走（1109–1111，**惟炁星主吉**——炁泄恩不论凶）；奴杀破库破禄必破（1105）。
- **权在奴**（琴堂799–800）：奴星在高强，权在奴星少得志；官星为奴所泄＝奴隶执权。
- **梗吉星**（1137–1139）：余奴入命，梗诸吉星而无力——用而无用、利而不利。
- **仆从贫贱**（琴堂716–729）：地驿余奴前后拱＝执鞭为仆从；马前马后安身＋奴宿侵舍＝奴隶为身离远乡；驿马前安身＋余奴侵舍＝必为仆从。
- **重拜双亲**（琴堂894–895）：奴星入命、主星入奴，又逢逆行相克相反——"不是随娘嫁娶，也须换父操持"。
- **疾**（琴堂1016）：奴星犯月，疾主侵欺。
- **妻妾财帛**（孛星断，天官959）：妻妾星被孛划→妻妾淫乱或不情、夫妇反目；财帛被孛划→为我之恩则一生得小人之财、为我之难则一生被小人欺凌；孛划宫度主或在宫度→盗贼之辈、面是背非。
- **代用**（2923）：五星本坏以四余代用——妻主坏者无正妻或重婚、子主坏者或非亲子、宅屋不新不高广。
- **女命**（2925）：忌四余星旺，皆主重婚；月孛当头克夫害子。
- **情感**（7509–7515）：情感星的余奴顶度也引动情感，但后面出问题；余奴＝被替代——遇余星时对方一般有感情经历，被替代也意味着小三。
- **职业**（2229）：杀制余奴＋财生杀格局→风险性大的行业（股票、投资之象）。
- **僧道**（琴堂713–714）：紫气高强师巫有分；命主随奴，孤衾孤枕。

## 八、用户校准结论（2026-10-09）

1. **先后以宫为用**：判定余奴抗主／抗杀、敌我先后时，以**宫位先后**为准（果老"先入为主"），不以同度度数先后为准。
2. **金泄土＝普通泄气**：泄气条"土见金星"中，金星对土不作余奴犯主论，只按普通泄气看（金本无余奴）。
3. **"丁年计化官魁，土若顶之，最凶"照原文用**：不做校改，临盘照用。
