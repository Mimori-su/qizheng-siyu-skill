# 来源与许可说明（七政四余起盘引擎_跨机版）

本轮构建日期：2026-10-16。本包由"引擎交接包_桌面壳轮_20261016/engine"（App 口径排盘引擎正本）
重编译打包而成，引擎源码零改动。

## ① 本工程整体：Moira 衍生工程（GPL v2 或更高版本）

本工程衍生于 **Moira — A Chinese Astrology Charting Program**，
Copyright (C) 2004-2015 At Home Projects，原工程以 **GNU General Public License v2（或更新版本）** 授权。
依 GPL 第 2 条，本衍生工程同样以 **GPL v2 或更高版本** 发布与分发。完整许可全文见
`LICENSE_GPLv2.txt`（随本包分发；另复制一份于构建轮次目录）。

- **口径**：以 App（七政四余安卓版）增量为准的无头 CLI 排盘引擎；App 增量与 Moira 骨架的
  差异处均以我方定标（六轮审计、回归 37/37 全绿）为准，定标依据不在分发件内展开，见正本
  `engine\README.md` 与相应施工报告。
- **源码随附（GPL 合规）**：`src\` 为引擎源码 72 文件原样副本（`org.athomeprojects.base` /
  `swisseph` / `app` 三包）。GPL 第 3 条要求分发可执行形态时随附对应源码，本包里的
  `app\engine.jar` 即由 `src\`（含构建脚本口径）在 JDK21 下重编译所得，二者一一对应；
  可用正本 `engine\build.cmd` 口径重建（`javac -encoding UTF-8 -d out src\...`）。
- **许可全文来源说明**：本机未找到 GPL v2 现成副本；`https://www.gnu.org/licenses/old-licenses/gpl-2.0.txt`
  在本构建环境被网络策略阻断（经代理 TLS 连接重置，多次重试均失败）。故 `LICENSE_GPLv2.txt`
  取自 SPDX 官方许可文本库逐字副本：
  `https://raw.githubusercontent.com/spdx/license-list-data/main/text/GPL-2.0-only.txt`
  （GNU GENERAL PUBLIC LICENSE Version 2, June 1991 全文 17337 字节）。此为该 GPL v2 正本，
  仅来源镜像不同，内容未做任何改动。

## ② swisseph 目录：Swiss Ephemeris Free Edition Java 移植（未改动副本）

`src\org\athomeprojects\swisseph\` 为 **Astrodienst AG, Switzerland — Swiss Ephemeris Free Edition
Version 1.64.01** 的 Java 移植（Thomas Mack, mack@idb.cs.tu-bs.de, 2001）之未改动副本，
随 Moira 工程原样进入本工程。授权与免责按各源文件头的原始声明执行（文件头原文：
"This is a port of the Swiss Ephemeris Free Edition, Version 1.64.01 of Astrodienst AG ... For
copyright see the original copyright notices below ...", "Copyright (C) 1997 - 2000 Astrodienst AG,
Switzerland. All rights reserved. ... Refer to the Swiss Ephemeris Public License (SEPL)"）。

- **星历数据文件**：`ephemeris\` 内 `sepl_18.se1`、`semo_18.se1`、`sepl_06.se1`、`semo_06.se1`
  （太阳系行星/月亮分段星历）与 `fixstars.cat`（恒星表），为排盘运行所必需的数据文件，
  与 App 资产内嵌的星历同款精确级。
- 本包**不附** `seas_18.se1`（主小行星历）——见 README"口径边界"第 1 条。

## ③ 本包不含的内容

本包**不含** App（七政四余安卓版）反编译产物，**不含** Moira 的 SWT UI（`moira/`）、
Applet（`moiraApplet/`）与 SWT/AWT 控件（`swtext/`、`awtext/`）代码。分发物仅为：
无头 CLI 引擎 class（`app\engine.jar`）、资源表（`rsrc\`）、星历数据（`ephemeris\`）、
引擎源码（`src\`）、裁剪 JRE21（`runtime\`，Temurin 21.0.12.1，其自带 `legal\` 目录内含
JDK 各组件的许可与通知文件）与本文档系列。
