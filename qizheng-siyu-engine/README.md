# 七政四余起盘引擎（跨机版）

App（七政四余安卓版）口径的无头排盘引擎，**自包含发行包**：内含裁剪 JRE21（`runtime\`），
拷贝到任何 Windows x64 电脑即可运行，目标机无需安装 Java / Python 或任何其它环境。

引擎正本（开发版，含 `out\`、`build.cmd`、源码）位于
`D:\Zcode存储区\引擎交接包_桌面壳轮_20261016\engine\`；本包是其发行形态：
同一份源码在 JDK21 下重编译后打成 `app\engine.jar`，行为与正本一致（T1 14 组盘例逐字节一致，
见构建轮次报告 `00_施工报告.md`）。

## 快速开始

在本目录下打开命令行（或把本目录加入 PATH 后任意位置调用 起盘.cmd）：

```
rem 例1：1999锚盘，流年2026（默认时区 Asia/Shanghai）
起盘.cmd 1999-05-03 13:49 29.5 112.5 2026

rem 例2：2003盘，带六壬天将 + 相位 + 恒星盘 + 全方位（组合开关）
起盘.cmd 2003-01-14 04:56 36.6667 117.0167 2026 Asia/Shanghai -liuren -aspects -fixstar -full

rem 例3：指定流年盘日期（MM-DD）与自定义时区
起盘.cmd 1999-05-03 13:49 29.5 112.5 2027 UTC 06-15
```

参数：`<yyyy-mm-dd> <HH:MM> <纬度> <经度> [流年年份=2026] [时区=Asia/Shanghai] [流年盘MM-DD] [开关...]`
开关：`-dougang`（斗罡）`-aspects`（相位）`-full`（全方位）`-fixstar`（恒星盘）`-liuren`（六壬天将）`-equ`（赤道）。
无参数运行会打印用法并以 exit 2 结束；**出生时间按真太阳时直输**（引擎不做经度时差改正）。

自检：双击 `验证_1999锚盘.cmd`（或命令行运行），对 1999-05-03 13:49 锚盘逐项核验 6 个数字锚点，
6/6 PASS 则 exit 0。

## 平台要求

- Windows x64（Win10/11 实测；runtime 为 Windows x64 裁剪 JRE21，Temurin 21.0.12.1）。
- 无需预装 Java：`起盘.cmd` 始终调用本包 `runtime\bin\java.exe`，与系统 PATH 无关（T5 实证）。
- 整个目录可任意移动/复制（含中文路径），内部全部相对定位（T2/T4/T8 实证）。
- 控制台编码：`起盘.cmd` 以 UTF-8（代码页 65001）输出中文。

## 口径边界（三则）

1. **不附 sepl/semo 之外的星历 → 主小行星不输出**：App 资产仅内嵌 sepl_18/semo_18 与 fixstars.cat，
   未带 seas_18.se1（主小行星历）。本包保持同口径：Chiron/四小行星等请求走"资源缺失→置 INVALID"，
   不输出其位置。这是对 App 资产面的忠实，不是缺陷。
2. **星历下界 1801 年**：本包仅附 sepl/semo_06.se1 + _18.se1（覆盖约 1801 起）。
   出生或流年 ≤1800 年时数据缺失 → `compute失败` 干净 exit 1；≥1801 正常。
3. **真太阳时直输**：`HH:MM` 按真太阳时理解，不做经度/时差修正（App 时间输入路径同口径）。

## 目录结构

```
七政四余起盘引擎_跨机版\
├── 起盘.cmd                    启动器（cd 到包根后调用 runtime\bin\java.exe）
├── 验证_1999锚盘.cmd           自检脚本（6 数字锚点）
├── README.md                   本文件
├── LICENSE_GPLv2.txt           GPL v2 全文（随附源码副本的许可依据）
├── 来源与许可说明.md            来源与授权说明（三段）
├── smoke_1999.txt              1999 锚盘参考输出（与正本一致）
├── runtime\                    裁剪 JRE21（jlink: java.base,java.desktop,jdk.charsets）
├── app\engine.jar              引擎 class（base + swisseph + app 无头 CLI 层）
├── rsrc\                       moira_s.prop、cities.prop
├── ephemeris\                  sepl_18.se1 semo_18.se1 sepl_06.se1 semo_06.se1 fixstars.cat
└── src\                        引擎源码 72 文件（GPL 合规随附）
```

注意：请勿移动 `app\engine.jar`、`rsrc\`、`ephemeris\` 的相对位置——引擎按 `engine.jar` 所在目录
上溯定位 `rsrc\`，并按当前工作目录寻 `ephemeris\`；`起盘.cmd` 已处理，手工用 java 调用时请先
`cd` 到本目录。
