# 星体喜忌速查（校准后要点）

## 一、星体本象（人事义，取象第一优先）

| 星 | 本象/人事义 |
|---|---|
| 日 | 贵人、父、君上；不作火论；光 |
| 月 | 身、母、大众、服务、饮食；不作水论；夜生为要 |
| 火 | **教育、文化、文明**（火主礼，礼部＝文化教育部，火掌文魁，文人最喜）；礼、文书；**武星**（军人、警察、外科、消防、屠宰）；**光电、屏幕、影像、影视**、计算机信息、广告、电力、心理哲学；厨师 |
| 水 | **教师、演说家、玄学巫师**、智、数据、贸易流通、口才、交易、**流量、流媒体** |
| 金 | **金融、财会**、音乐、美业、声音、机械 |
| 木 | 文化、仁慈、文书、条陈 |
| 土 | 房产、中介、管理、田宅 |
| 炁（木余，偏印） | **玄学命理**、僧道、孤高学术 |
| 孛（水余） | 偏财、投资；孛入八宫＝股票象 |
| 罗（火余） | 武星、天杀、威权；余奴敌杀 |
| 计（土余） | 财星之一（天财），亦可生官 |

## 二、四时气数喜忌（只用于命宫/命度主/月亮三点）

- 春木：忌水多木漂；夏末秋初木：昼生忌躔四火度。
- 秋木：最怕金（见金则残）；水孛生而不受（受克无根，水泛无益，恩力减）；酉月转寒，气数要求不高；戌月喜火罗。
- 春火（寅卯月）：火自己为气数星，要强旺；木炁为气数星；夜生见太阴光彩，文武富贵。
- **春末夏初火（辰巳月）**：火入水宫、水入火地＝**桃花滚浪，水暖花红，名利双清**；忌与水孛同行（受克）；**见水能用**（条件：水不甚旺、火不甚弱）；逢土有救（子来救母，破水孛）；**见金为党鬼**（金生水助难）；得罗为余奴敌杀。
- 夏火：喜水孛制伏，不喜木炁（焰高成烬）；夏末秋初火：借水济盛，忌木炁火罗太阳。
- 冬火：最喜木炁相扶（水生木生火，精神转运，合为贵论）；忌水孛土计罗交互克泄。
- 秋土（申月、酉月，校准108）：喜水孛，忌火罗，忌日。旧文「仲秋土急须火罗生之、见水孛以弱论」已作废，不要执行。木衰不能克土。
- 冬土：喜火罗、日；忌水孛；嫌土计；忌金伴（金伴无情）。
- 冬月：忌水孛、土计、金伴。
- 总纲：冬夏两季气数要求高于春秋；**取用时必须查原文，不凭"难＝忌"一刀切**。

## 三、明晦与月相

- 夜生：月、火、金、罗向明；日、木、土、水、炁、计、孛背晦。
- 昼生反之。
- 火为夜星：昼生残晦更凶，夜生发用；土为昼星：夜生残晦更凶（昼火夜土）。
- 残晦之月（初八前、二十后）见火增辉；满月逢昼生则月背晦打折。
- 火月争光：月朗（上弦至下弦）时火来争辉为忌，月暗淡时火增辉为喜。

## 四、状态与力量

- 升殿、入垣、庙旺、喜乐、得地，在强弱五样里看。五星的明晦、逆、伏、留、失地不作独立吉凶（校准45），只在生克链里参与「克尽／克不尽」。日月的明晦和月相专门看。
- 水升殿：轸壁箕参；火升殿：尾室觜翼（四水度/四火度类推）。
- 躔度关系：星躔某度，度五行克星＝受克，度五行生星＝得力；同五行宿度＝交感通道之一。
- 宫的影响力没有星体本身大。
- **星体力量大小决定行业是过客还是归宿**。

## 五、常用解救格局

- 用星制难：克命度主之星被用星所克＝得救，上格（如金克木，火制金）。
- 通关：A克B，有C通关（如计土生金生水；水生木生火）——化比制更妙。
- 土木互克：二度之间有火罗可解（泄木生土）。
- 祥云捧月：炁拱月，主贵气护持。
- 日月夹命度、日月照身＝贵人有情。
- 桃花滚浪：辰巳月火入水宫/水入火地＝名利双清。
- 子来救母：火被水克，得土计破水。
- 余奴敌杀：春冬火得罗敌水孛之杀，宛转成局。

## 六、贵星与十神化曜（职业用）

- 文教赛道贵星：天官、魁星、文星、科名、科甲——聚于用星/官禄线→体制、考试、文教。
- 钱的性质：正财＝上班领薪；偏财＝投机横财；劫财＝风险博弈；天财坐官禄＝事业即钱；伤官＝才华技术变现；食神＝作品口福。
- 疾厄宫（八宫）＝风险投机之地；金星＋疾厄合体＝炒股信号（见校准7）。

## 七、宫位双义与现代化延伸（校准增补）

- **男女宫（五宫）**：学生、子女、晚辈，**兼主创作、作品、娱乐、艺术表达**。命宫主/贵人入此宫＋伤官偏印旺＝创意制作类（视频、设计、内容创作）。
- **火现代延伸**：教育文化之外，亦主**光电、屏幕、影像、影视媒体**（火为文明之光）。
- **水现代延伸**：教师演说玄学之外，亦主**数据、流量、流媒体、交易**。
- 日＝光、水＝流：日水结构入作品宫＝影像流媒体象。
- **格局性质先于贵星**：伤官/食神格（伤官叠旺、兼财帛主）→ 贵气应作品名气；官格（官印清正）→ 贵气应官职。贵星入官禄不必然＝公职。

## 八、武职与执法信号（校准增补）

- **火罗计孛为武星**：命度主/用星为火罗计孛→武职候选（军、警、法检、消防、外科、屠宰）。火先天凶星（破坏、武器、犯罪、血光），有制为用→对治凶险。
- **天杀为用且得令**＝掌刑杀之权＝执法者；配官星/天官居官禄→公职执法；无官星→外科、屠宰等。
- **值难居官禄**＝职业带危险性；官星居官禄＋官禄主入奴仆＝体制内服从型劳碌公职。
- 火为夜星，夜生向明升殿→夜间发用（夜勤、镇场）；火星临卯戌（太冲、河魁）主兵将之权。
- **难星能用看气数**：辰巳月之火见水能用（水火相济、桃花滚浪名利双清），条件＝水不甚旺、火不甚弱；过旺之水（如孛旺）仍忌。
