# 健康与身心功能取象框架

依已确认的健康与身心取象规则组织；尚未逐条核对的传统功能细项继续待核。

## 分析前置

- 必须继承 qz-core 的原局结构、五行偏性、喜忌和运势资料。
- 明确用户问的是身体倾向、疾厄宫、某类不适取象还是健康年份。
- 先声明“不作医学诊断”。
- 身体、心理及两者联系均检查；采用中医功能取象，不把功能概念直接等同现代解剖器官或疾病。真实症状、生活环境、工作压力、作息和既往诊疗独立记录。
- 没有临床反馈时只能提出待核对方向；不能把盘面当成疾病筛查、心理测评或患病风险排序。

## 关键观察点

- 疾病宫：健康、身体、思想压力和危机取象。
- 相貌宫/命身：身体感应、外显状态和承接能力。
- 五行偏性：木火土金水的过旺、过弱、寒热燥湿取象。
- 神煞：仅辅助提示，不可单独判断疾病。
- 运势引动：原局有健康信号时，再看流年/限度是否触发。

## 全盘扫描与重点定位

1. 先检查十一曜的实际受制、消耗、交战及救应，不只看疾厄宫。比较四时、昼夜月相、宫宿生扶克泄、垣殿、四柱填实与来星力量；日月不套普通五行生克。旺衰描述术数作用，不是医学严重程度。
2. 身体线索优先检查疾厄宫、本宫／对宫／两个三合宫的星曜、疾厄主，以及与这些星有直接关系的受制星。写明关联路径，不能无限递归把全盘都称为疾厄关联。
3. 心理线索重点检查相貌宫及其本对三合宫内结构、相貌主的完整交感和受克／交战，再参照月亮、身度主的内在感受。宫内结构与宫主自身状态分栏；相貌宫空宫仍查宫主和对三合，不视作没有内心感受。
4. 相貌宫或相貌主受克、交战，可作为内心压力、紧绷、反复思虑等困扰的传统取象线索，但须同时检查制化、支持和现实反馈；不得直接推出精神疾病、人格缺陷或心理承受能力结论。
5. 结合星体、地支宫气、落宫、掌宫、化曜、躔度、相关神煞读象；神煞仅补充，不凭“病符”“刃”断病、手术或事故。受制也可能主要表现为其他人事议题，不能一律翻译成健康问题。

## 健康专题的刑与对刑

刑与对刑用于健康／身心专题，侧重持续、慢性的牵制感；不扩张其他专题的通用相位范围。

- 在本宫、对宫、三合宫、同七曜属性宿度之外，另读取用户原始相位表明确列出的 **刑（45°）与对刑（135°）**，作为两星的直接观察关系；即使上游通道表曾过滤，也不得遗漏。保留原始名称、星对、本命／流年身份及资料时点。
- 不自行设容许度、相位权重或重新计算规则；未给相位或角度口径不明时记“未核”。不自动增加关、辅、夹、对夹等其他角度作为健康直接作用入口。
- 刑与对刑的表达侧重持续、反复、慢性的牵制与不舒畅感；这里的“慢性”是传统取象节奏，不是慢性病诊断、确切病程、必然持续时长，也不能反推“没有刑就不会有慢性问题”。
- 相位说明联系，星曜本体、喜忌、力量与救应决定如何读象；有刑不等于五行相克，相克也不等于已经患病。有生扶、制化仍分别保留，不因有救应就宣称不会出问题。
- 同一星对若同时经宫位、宿度及刑相联系，只记多个路径，不累加为多份独立伤害或医学风险。A刑B、B联系C，不等于A直接作用C。
- 本命与阶段引动分栏：不能把某日流年相位写成终身状态，也不凭“持续”一词补出年份。问应期仍继承原局→宫限→度限→小限／飞限→太岁→年干化曜→顶星→流年星的既定流程。

## 中医功能资料与身心联系

传统功能取象包括“心—主神明”“肝—主疏泄”“脾胃中焦气机升降”“七情内伤”“劳逸失宜”及气血津液。调用细项时须核对应定义，不把本表当作已完成医学审校。

| 传统资料入口 | 可以组织的观察问题 | 使用边界 |
|---|---|---|
| 心主神明 | 精神状态、思维活动、睡眠与恢复体验 | 不能由火星状态诊断心脏病、失眠或精神障碍 |
| 肝主疏泄、调畅情志与气机 | 情绪表达、压抑或烦躁体验，以及是否与身体不适同时出现 | 肝气郁结不等于抑郁症；不把正常情绪病理化 |
| 脾主运化、脾胃升降 | 饮食反应、精力与反复思虑的反馈联系 | 不从土星状态认定脾虚，也不认定“想太多导致疾病” |
| 七情、劳逸与气血津液 | 压力的强度、持续性、休息与身心变化 | 传统功能联系不是已经证实发生在当事人身上的医学因果 |

身体功能、心理体验、身心联系三栏分别有证据才写；不强求每颗星同时推出身体和心理问题。可核对生活节奏、情绪与不适是否相伴变化，不预设单向因果，更不把身体症状解释成“只是心理作用”。

功能连锁的每一段标明：盘面关系、资料中的传统理论联系，还是本人实际反馈。传统功能链不能补造星曜交感；已知结果也不能反向补出缺失病象。资料中的中医证候与现代病名等号、绝对疾病断言、方药和治疗内容不直接导入报告。

## 内部证据记录

每条线索保留：`星曜与身份 → 本命／限运／流年来源及时间 → 通道（含刑／对刑）→ 作用方向和双方力量 → 救应／反证 → 疾厄或相貌／命身关联 → 功能取象与核验状态 → 身体／心理／身心联系 → 实际反馈或未反馈`。

真实症状、传统解释、医生诊断分栏。既往病例不作为通则，完整个人案例和可识别健康经历不写入 Skill。

## 输出层次

先完成内部证据，再按以下客户框架择要输出：

1. 核心提醒：结论先行，说明主要关注方向，不给疾病概率和健康评分。
2. 身体功能：说清涉及的功能、支持与制约，以及需要核对什么。
3. 心理状态：结合相貌宫、相貌主与月亮、身度主，描述有依据的内心体验，不贴疾病标签。
4. 身心联系：有依据才讨论相伴变化；不足时明确待核或略去，不凑连锁反应。
5. 现实核对：区分本人反馈与推演，考虑环境、作息、压力和既往诊疗。
6. 建议与支持：给可行的日常观察、沟通和专业求助方向，不开药、不列检查或治疗方案。

窄问题只展开相关内容；身体与心理均已检查，不等于每节都要有不利结论。表达温和而不粉饰，不能为了情绪价值捏造保护或保证安全。规则边界见 `medical_safety_rules.md`。

用户要求“不存档”时，客户段和内部推演都只在对话中交付，不创建客户档案、咨询记录或病例；规则本身的授权更新不包含保存个案。
