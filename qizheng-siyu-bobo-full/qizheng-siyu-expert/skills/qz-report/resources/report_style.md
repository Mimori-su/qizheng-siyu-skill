# 报告风格

## 语言原则

- 中文为主，字段名和文件名可保留英文。
- 内部审查与通用跨专题汇总先数据后判断、先证据后结论；本命格局客户版先给简明总评，再展开有据分析，最后给具体鼓励建议。专题客户模板优先于通用顺序。
- 内部逐项区分“已确认规则”“整理后的分析框架”“模型推理”“不确定项”；客户正文直接给出有依据的判断，不逐段展示审核话语。
- 语气自信、清楚、温和；结论强度与证据相称，不使用恐吓或无依据的绝对断言。

## 语言的艺术

### 分析式表达：有理有据、有重点、有结构

所有客户解读统一采用下述表达方式，并沿用各专题章节结构。

- **主线清楚，分清重点。** 开头直接回答所问问题，概括最相关的判断与发展路径；后文围绕主线展开，按实际需要分清主力、辅助及影响结论的条件，不把所有星曜、财路或事件等量罗列。小标题体现本段判断，段落之间有承接。
- **主要判断必须带分析。** 按“核心判断 → 关键盘面依据 → 作用推导 → 具体人事”自然展开，依问题补充收益、建议或影响结论的成本或限制，不要求每段机械写齐。客户正文应能看出为什么得出结论；从已核定的内部证据中择要解释，不能只给结论、列术语，或把全部依据留在内部版。简版同样保留关键推导。
- **保留术语，随即解释；综合取象参与推导。** 命度主、宫主、入垣升殿、化曜、宫宿等术语用于说明判断依据，并在相邻句说明其现实意义。综合星曜本象、力量、落宫与掌宫、实际交感、化曜、宿度及有关神煞，说明谁在什么领域得到何种支持、受到什么约束。星宿的有据类象要改变或细化人物、任务、关系、事件的描述，不能只报宿名、五行旺衰，或在结尾补几个形容词；资料不足处回到上游核验，不在润色时补造断法。
- **把因果落到具体场景。** 说清能力怎样产生价值、机会经谁或什么渠道到来、成果通过什么过程形成；确有影响结论的消耗时，再解释其原因。依专题选择工作任务、合作分工、收入方式、家庭互动等场景；“资源、承接、兑现、落实”等概括词须有具体所指。用“例如”引入情景说明，未获现实反馈的推演不写成已经发生的事实。多种可能以有依据的主线为先，不靠穷举行业或事件显得具体。
- **情绪价值来自有据的理解。** 充分说明可发挥的本领与已有支持；当问题涉及困难时，解释付出、阻力和处境为何形成，让客户看见可以调整的环节。鼓励和建议对应前文原因，说明怎样发挥优势、合理安排投入；不靠空泛赞美、拔高层次或保证未来来增加安慰，也不把真实不利强行说成好事。
- **结构服务分析，详略服从问题。** 用连贯段落讲因果，平行选项、阶段或财路才用列表、表格；财源等内容可按“来源 → 取得方式 → 收益与成本”组织，不替换专题模板。保留能解释判断的细节，合并重复结论；不以篇幅、术语数量或内部核查过程代替分析深度。

#### 从力量落实到人物与事情

- 宫度生克继承上游“双层解读”，把力量翻译成人事：该星代表谁，哪些宿度事务让其受到约束，哪些宫位领域提供滋养或支持。宫助与度制可同时表达，具体事务有依据才写；正文择要说明帮助与所需付出，不只列“得生、受克”，也不重复内部检查表。
- 星曜力量继承上游已核定的“力量等级＋状态说明”，再翻译帮助怎样到来：用神有力受制，可写支持有分量而落实费周折；偏弱但有效受生，可写后续有资源接续、适合渐进积累。具体说明补充或阻碍的来源，不只重复旺衰标签；完整依据见 qz-wangshuai 的“力量状态与帮助的供给方式”。不换算成百分比、收益或持续年数。

交付前检查主要判断：客户能否读懂“凭什么这样说、具体体现在哪里、怎样回答所问问题”？必要的建议能否回扣分析？缺依据或推导时补齐；不为填满结构增加无关内容或免责句。

### 自信表达：避免防御性写作

适用于性格、格局、婚恋、人际、事业、学历、财运、健康、限运、合盘、校时与简析；文风由 qz-report 统一管理。

- 单项按所问范围输出，简版只压缩文字，不降低证据要求；不要为了套整合模板加上用户没问的其他专题。客户先看结论，内部保留完整理论依据、支持与制约；尚无正式专题模板时采用“核心结论 → 具体分析 → 针对性建议”。
- **围绕实际问题直接讲清。** 把事实、解释和判断说清楚，不一边回答，一边预先应付假想的质疑。默认读者能够正常理解语境，不替读者虚构误解，再反复纠偏。按“结论 → 具体表现或依据 → 必要的行动指引”展开，讲清楚就收住。
- **成立的好处充分表达。** 日月照命、贵人支持、用星得力等已核定助力，应具体说明好在哪里、怎样发挥。用户问优势或帮助时，可以集中讲成立的正面作用；不为显得全面或平衡，在每项好处后追加一句局部弱点。原局力量用于确定助力的性质与分量，与所问结论无关的细节留在内部；确实改变判断的条件按下一条自然说明。
- **重要条件融入判断并解释原因。** 只有确实影响所问结论或行动选择的条件、不确定性、制约或资料缺口，才在对应分析中说明一次，直接讲它怎样影响结果。比如合作分成确实影响个人所得，就说明分配方式与所得之间的关系；不额外套“这不意味着能赚钱”。不为完整句式强配成本或限制，也不以正面表达代替重要事实。
- **删除没有信息增量的免责式限定。** 不习惯性追加“这只是……不能据此认为……”“这并不意味着……”“不应将其理解为……”“这不等于一定……”等句子。删去仅用于防止自己被挑错、却没有增加有效信息的文字；不要换成另一种措辞保留同样的防御姿态。内部的“不能这样断、尚不能证明”等审核话语不搬进客户正文。
- **判断强度一次到位。** 依据充分时直接写“适合从事……”“主要财源在……”“今年重点是……”。需要表达倾向时，一次“容易、更适合、有机会”等已足够；不再叠加“可能、或许、一定程度上、值得优先验证”或句尾退让。判断强度仍以已核定依据为准。
- 通用参考说明按专题需要集中在结尾一次，不在段落中重复，也不在简短追问中机械重述。健康、法律、投资或现实安全问题所需的具体边界按相关规范执行。

交付前逐句检查限定语：删掉它是否会让读者误判本题的事实、结论或行动？不会就删除；会则把必要条件和原因融入正文，避免另起一句自我辩护。

#### 改写示例

以下只示范表达，不新增断法；使用时须已有相应依据。

- 原：“你更适合靠专业服务获得收入，但这不代表你一定能赚大钱。”  
  改：“你更适合靠专业服务获得收入，重点把擅长的内容做成稳定、可交付的服务。”
- 原：“有助于取得合作支持，同时也增加任务与压力。得到机会，不代表可以少做事情。”  
  改：“有助于取得合作支持，同时也增加任务与压力。”
- 有实质风险时保留：“这一路数的优势在知识、设计与服务；重资产投入则要控制固定成本和回收周期。”不要为显得自信删掉后半句。

- “你的优势在……，适合通过……取得成果。”
- “主要支持来自……；需要承担的成本是……，可以提前做好……。”
- 关键资料确实缺失时：“目前缺少……，这一部分先分析到……。”只说明一次，不让其他有依据的判断一起退让。

### 成本表达：说清取得成果需要付出什么

客户版描述取得成果所需的正常投入时，优先用“成本”“投入”或“需要付出的东西”，不以“代价”作为默认措辞。具体说明时间、精力、学习、资金、沟通协调或责任承担，以及这些投入怎样支持成果；避免仅换一个词，仍把正常付出写成负面后果。

- 自然表述如：“这条发展路径需要持续学习，并投入时间积累作品和客户信任。”或“合作能扩大业务，你需要投入精力协调分工，并按约定分配收益。”不必每段都设置“成本”标签。
- 已有依据的损失、风险或限制直接说明具体事实与影响，不统称为正常投入。内部证据沿用原有术语，客户措辞按本节转译。

### 财富表达：充分肯定优势，不虚增金额

财运及格局报告按下述方式表达财富，不改变原局判断规则或专题结构。

- **先讲能做成什么**：充分写明已有依据支持的财富来源、个人本领、外部支持和扩大成果的路径；鼓励要具体，不靠堆砌赞美或增加篇幅。
- **规模、成本与损耗分别说**：资产规模、现金状况、负债、合作消耗及局部投资损失分别表达，不因局部受制一概压低整体层次。确实影响所问结论的制约随对应原因说明，不要求正反等量，也不把坏处包装成好处。
- **讲发展潜力，不设死上限**：区分已知资产事实、经验层次判断与条件具备时的发展空间。财运专题可按 `../../qz-wealth/resources/wealth_framework.md` 第10节采用已确认的经验量级，不能一律省略；命盘不能可靠换算当前人民币身家或确定财富天花板。不为了情绪价值抬高金额档位，也不把单个反馈固化成星曜与金额的对应规则。
- **贵人与机会也是财富助力**：日月会财与日月联系命身都进入财运层次；岁殿岁驾、禄马官魁文、三元禄有效会财亦予正向表达，具体说带来什么支持、机会或渠道。不把命身贵助只写成心情舒服，不堆标签或固定分值；完整成立条件继承财运模块。
- **结尾只作一次整体说明**：普通财富表达采用下句，不在各段反复免责；这句话不能替正文中无依据的金额承诺兜底，涉及真实资金的专业边界仍按财运规范执行。

> 以上侧重优势充分发挥时的发展空间，仅作传统取象参考；实际财富规模，还需结合时代背景、起步资源、个人业务与经营成果判断。

## 跨专题整合与专用表达

- 合并 Core 和专题中的重复结论、证据与谨慎声明，保留影响结论的真实制约、资料缺口和必要风险；不把内部审核措辞原样叠加到客户正文。
- 本命格局客户版采用“简短依据＋现实意义”，展开可用星的行业、能力、资源与成就路径，不只报旺衰或心理标签。八方面是覆盖清单，可合并；同一结论不反复铺陈。依据充分时直接写适合方向，少用重复限定套话；总体参考说明集中在结尾一句，缺关键条件和重要制约仍如实保留。
- 限运客户版按五板块先结论后展开：阶段讲环境重心，事件讲实际变化、帮助、成本与应对，年份讲何时引动。躔度与神煞应进入有依据的具体描述，不变成术语清单；不得只输出旺衰或心理状态。同一事件不跨节反复铺陈。真实不利温和而清楚，不强行转成好事；建议和鼓励对应已有依据，总体参考说明集中结尾，关键缺项和现实专业边界仍须明示。
- 传统格局名是点睛语，不是结论本身：只调用 qz-core 已核定的正向名称，每篇通常一至两个，紧接白话解释；“有形但受限”写“有……之象，但……”。负向格名不进客户正文，现实压力与改善方向仍如实表达；不用“大贵、巨富、极品”等旧式词承诺结果。
- 多专题相互冲突时，写“存在不同取象，需要复核”，不强行得出统一结论。
