# 学业、学历与资格证分析

采用四类学历标识合参方法：先定位标识，以实际交感、旺衰和得用为主判据，再看掌宫、求学路径与成果兑现。学历、技术变现与资格证分别判断。基础力量、通道与喜忌继承本技能，不另设一套原局规则。

## 一、分清所问对象

| 问题 | 判断重点 |
| --- | --- |
| 学习与求学 | 学习支持、吸收与表达、持续投入、求学环境和阻力 |
| 学历与学位 | 正规学历的支持结构、深造倾向、取得学位与获得认可的条件 |
| 执照与资格证 | 行业准入、资格考核及相关职业门槛，单用第五节定位 |
| 所学与工作 | 文凭带来的机会、实际知识技术、岗位任务和收入各自如何成立 |

实际读盘先有Reader、旺衰与Core结论；方法教学无需命盘。确认是本人、配偶还是子女的学历，依已有专题定位相关人物后分析，不把本人的学历线直接移给别人。若只有单人盘，相关人物的推论与其独立命盘分清。

## 二、定位四类学历标识

按已核盘面与化曜起法，将**科甲、魁星、文星、正印**分别对应实际星曜，记录身份来源、落宫、躔宿及掌宫。

- 科甲按所采用体系的命宫对宫主定位，并与盘面标注核对；宫主取法或标注不一致时先留明差异。
- 魁星、文星按本盘对应起法识别；文星不能固定当木星，科名、文昌等旁证不能无条件替代四类标识。
- 正印按已核年干化曜身份识别。本包天官模块中天权对应正印、天印对应正官；来源盘的同名标签保留原起法，不按“印”字直接合并。
- 同一星兼两项以上标识，保留多重含义，但只计一颗星的力量。缺某一标识仅限制对应分析，不能把资料未核当成该星不存在。

## 三、判断学历结构与支持程度

**逐星定位 → 与本人实际联系 → 力量及得用 → 各线合参 → 学历判断。**

1. **交感是学历作用落到本人的入口。**分别检查命宫、命度主、月身及原局身度主体系，按 `../../qz-wangshuai/SKILL.md` 复用或补齐本宫、对宫、两三合、实际同属性宿度与所乘星记录。说明该星联系了哪个对象、走哪条通道；不要求每颗学历星同时连接所有对象。未与本人形成有效联系的星，不仅凭名称计入本人的学历支持。
2. **旺衰决定支持分量，得用决定能否实际发挥。**检查四时、昼夜月相、升殿入垣、宫气与宿气、填实、生扶、克制及救应；区分星体作用和宫宿条件。再看它是否真正支持身命或已成立的可用结构，不能把“有联系”直接读成有益。
3. **是否被选为用星只作综合因素。**学历星不是原局主用，不构成学历低的否决；不设“必须满用”门槛。反过来，只有用星身份也不能跳过力量、交感和实际作用。
4. **合看主力与其他学历线。**支持有力、能到达本人并发挥作用时，可以明确判断学历基础强、有较好的高学历或持续深造倾向；分别说明主力、辅助、受制及补充。多条线可互相支撑，同星多名不按独立证据重复加分。
5. **受制落到具体环节。**看它影响学习过程、取得文凭、成果认可，还是凭头衔获得机会。魁星受伤不能单独推成低学历或不适合一切考试；已有有力学历结构时，可同时存在学位支持强而社会认可、头衔收益受限。主要支持链确被破坏时照实说明，不能见受克就套“文凭硬、名分软”。

本方法支持定性判断学历条件与深造路径，没有通用的专本硕博、名校排名或分数换算表。已有学历由反馈确认，未知经历保持推断；不从单个命例、古代科甲等级或星曜数量生成现代学位定额，也不将学习受阻解释为智力诊断。

## 四、求学性质、地域与实际用途

每颗参与星继续读本象、化曜、落宫、**掌宫**、宿度及相关神煞，区分求学发生的领域、牵涉的人事及支持来源。不能只核学历标识和旺衰便跳到结论。

- 学历星兼迁移主或有效联系迁移体系，可形成异地、跨地域求学的线索；是否海外、是否多份学位须有更多结构与事实，不由迁移一项确定。
- 学历星兼夫妻等人物定位时，核学业与相关关系的具体联系，结合年龄、阶段及实际作用，不一律推成因婚求学或学业被婚姻牺牲。
- 学位取得、名分认可、依靠文凭获得岗位，以及把所学技术变成收入，分别核对。学历强不等于主要靠学历赚钱；技术输出有力也不自动等于高学历。
- 涉及岗位或收入时，再接 `career_framework.md` 与 `../../qz-wealth/SKILL.md`；只问学历时不扩成整篇事业财运报告。

## 五、资格证与阶段变化

**资格证单列正官、科甲、行业宫职主三条线。**正官看准入名分与认可，科甲看资格考核，行业宫职主看具体执业领域；身份同体仍去重，按实际通道、力量、支持与制约合参。行业定位须结合所问行业和已成立的事业取象，不由一个宫名猜职业。学位与执照可以相连，但不共用“有学历星就能拿证”的判式。

问升学、考试、毕业、深造或考证时，接 `../../qz-core/resources/original_vs_transit.md` 的完整运限次序，查看相关星及其支持、制约如何被引动。科名填实、魁星受引、文星入限等可作具体线索，不设必须凑齐的固定信号组，也不据单一信号保证录取或通过。分别核报名备考、取得资格、正式任职；正在考证不是已经通过，学历与资格结构也不自动确认编制身份。缺日期或引动数据只限制时间判断。

## 六、报告与内部记录

按 `../../qz-report/resources/report_style.md` 的单项结构，先给核心结论，再用主要星曜的实际联系与力量解释学历支持、求学性质、阻力及所问阶段，最后给对应建议。只写与问题有关的内容；有充分支持时直接表达优势，限制条件融入影响结论的环节，不反复免责。

内部保留：所问人物与范围 → 四类标识及身份来源／去重 → 身命对象与实际通道 → 旺衰、得用及救应 → 落宫、掌宫、宿度与神煞 → 学位／资格／技术／工作兑现 → 时间层次 → 已知事实、推断与缺项。记录可在对话或内存中完成，“不存档”时不新建客户文件，个人案例不写入Skill。
