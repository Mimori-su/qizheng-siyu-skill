## 一、东方青龙七宿

### 1、角宿（Jiǎo Xiù）—— 角木蛟

**定义**：角为龙角，青龙之首。角宿是二十八宿之首，象征春天到来。为天门、天王帝廷，三光运行之路，主天之纲纪与朝堂群臣。

**传统含义**：「左角李，右角将」；「角二星为天门」；「角二星，为天关，其门开阖，明则泰平，暗则兵革起」；「角二星，为天门，三光之路」；「属东方苍天，主天之纲纪」。

**性格**：威仪刚猛，执法执权，权威沉稳。性格刚强，有敢有为，擅长决策。组合佳则出刚正不阿之人；组合不佳则易刚愎自用、好武斗狠，主手脚有伤。

**职业**：公检法相关——法官、特警队长、纪检委官员、拳击教练、军事教官、领袖、建筑行业。

**象征物**：权杖、印章、青铜器、高楼尖顶、刀斧、烽火号角。

**所掌星官**：列舍2星。石氏：库楼十星(10)、五柱十五星(15)、衡四星(4)、南门二星(2)、平星二星(2)；甘氏：周鼎三星(3)、天田二星(2)、天门二星(2)、平道二星(2)、进贤一星(1)。共11星官45星，连列舍计47星。

**四象**：东方青龙 / **五行**：木（七曜属木）/ **动物**：角木蛟 / **人体**：额头、眼角 / **场所**：宫殿、宫门、重要关口、法庭 / **星度**：十二度 / **辰位**：辰时 / **分野**：郑分野

**现代引申**：角星明大、门阖规整，主天下泰平，朝堂纲纪严明；星暗或门开无序，主兵革四起，朝政紊乱。

**吉凶**：利立规立制，忌擅闯规则

### 2、亢宿（Kàng Xiù）—— 亢金龙

**定义**：亢为龙颈（咽喉）。为天庭、疏庙、尚书之曹，主刑狱听讼、录功行赏，亦主疾疫之事。

**传统含义**：「亢，鸟咙」；「亢为疏庙，主疾」；「亢四星，为天庭，总摄天下奏事，听讼理狱，录功行赏」；「属东方苍天，主刑狱赏罚」。

**性格**：刚正不阿、富有正义感、机智、反应直接。处事公正、有决断力，善理事务。负面为易招口舌官司，情绪易起伏。

**职业**：法律、音乐、学术、文化、法官、尚书、文员、艺术。

**象征物**：金属锁链、天平、呼吸道医疗器具。

**所掌星官**：列舍4星。大角一星(1)、左右摄提六星(6)、折威七星(7)、阳门二星(2)、顿顽二星(2)。共6星官18星，连列舍计22星。

**四象**：东方青龙 / **五行**：金 / **动物**：亢金龙 / **人体**：咽喉、气管 / **场所**：衙门、朝堂、监狱 / **星度**：九度 / **辰位**：辰时 / **分野**：郑分野

**现代引申**：亢星明润，主刑狱公正、赏罚分明，天下无疾疫；星色晦暗，主狱讼不公，疾疫流行。

**吉凶**：利断事，忌争讼

### 3、氐宿（Dī Xiù）—— 氐土貉

**定义**：氐为龙胸（前足）。又名天根，为天宿宫、路寝所止，主宫庭宿卫，亦为定四时的重要星宿，兼主疫疠。

**传统含义**：「氐者言万物皆至也」；「氐为天根，主疫」；「氐四星，为天宿宫，一名天根，主宿卫宫庭，摄提所指，以定四时」；「属东方苍天，主四时定序」。

**性格**：善解人意、善于谋略、隐忍、行动果决。稳重可靠、善守职责，时间规划能力强。负面为性格固执，易受环境影响。

**职业**：自由职业、广告、演艺、运动员、侍卫、管家、守夜人。适合不受束缚、能独立完成的工作。

**象征物**：地下管道、慢性药物、暗盒等与「隐性」相关的事物。

**所掌星官**：列舍4星。石氏：招摇一星(1)、梗河三星(3)、骑官二十七星(27)；甘氏：帝席三星(3)、天乳一星(1)、亢池六星(6)、阵车三星(3)、骑阵将军一星(1)、车骑三星(3)；巫咸：天幅二星(2)。共10星官50星，连列舍计54星。

**四象**：东方青龙 / **五行**：土 / **动物**：氐土貉 / **人体**：腹部、腰脊 / **场所**：宫殿寝殿、守卫室、居所 / **星度**：十五度 / **辰位**：卯时 / **分野**：宋分野

**现代引申**：氐星明大，主宫禁稳固，四时有序，天下无疫；星位偏移，主宫庭守卫松懈，疫疠滋生。

**吉凶**：利守宅，忌妄动

### 4、房宿（Fáng Xiù）—— 房日兔

**定义**：房为龙腹。又名天驷。为明堂、政教之道，天子布政出令之宫，主将相与国家政令。

**传统含义**：「房四星为明堂，天子布政之宫也」；「房为明堂，布政之宫也」；「属东方苍天，主帝王政令」。

**性格**：热情开朗、善于交际、幸运。有政治远见、善布政令，领导力与执行力强。负面为易揽权惹嫌，决策易受干扰。

**职业**：公关、政治家、律师、企业家、官员、帝王、宰相、决策者。

**象征物**：桃花符、婚庆用品、交通工具等与「愉悦」相关的事物。

**所掌星官**：列舍4星，附勾钤二星(2)。西咸四星(4)、东咸四星(4)、罚三星(3)、键闭一星(1)、日一星(1)、从官二星(2)。连列舍共8星官21星。

**四象**：东方青龙 / **五行**：日（七曜属日）/ **动物**：房日兔 / **人体**：胸膛、心脏周边 / **场所**：明堂、议政厅、办公室 / **星度**：五度 / **辰位**：卯时 / **分野**：宋分野

**现代引申**：房星明正，主帝王政令清明，将相得力，天下教化兴；星暗或动摇，主政令不通，将相失和。

**吉凶**：利施政，忌独断

### 5、心宿（Xīn Xiù）—— 心月狐

**定义**：心为龙心，苍龙七宿的核心。为天王之位，主帝王正位与嫡庶次序，是天下帝王权柄的象征。

**传统含义**：「心为天王，大星天王，前星太子，后星庶子」；「七月流火」指心宿二；「属东方苍天，主帝王嫡庶之序」。

**性格**：坚毅勤奋、正义感强、敏锐。心性中正、有核心领导力，身份尊贵易成核心人物。负面为情绪易波动，易陷入亲族纷争。

**职业**：政治家、医生、记者、演员、帝王、核心决策者、家族族长。适合掌握大众心理的职业。

**象征物**：心形饰品、火焰图腾、学术典籍。

**所掌星官**：列舍3星。积卒十二星(12)。共2星官15星。

**四象**：东方青龙 / **五行**：月（七曜属月）/ **动物**：心月狐 / **人体**：心脏、心口 / **场所**：皇宫正殿、家族祠堂 / **星度**：五度 / **辰位**：卯时 / **分野**：宋分野

**现代引申**：中间星为帝王，两边为子嗣，心三星为领导核心，主管天下赏罚。

**吉凶**：利立主，忌内斗

### 6、尾宿（Wěi Xiù）—— 尾火虎

**定义**：尾为龙尾。为后宫、妃嫔之府、九子，主承奉后宫，亦关联君臣关系。

**传统含义**：「龙尾伏辰」；「尾为九子，曰君臣，斥绝不和」；「尾九星，为后宫，亦为九子」；「属东方苍天，主后宫与君臣关系」。

**性格**：严肃谨慎、好胜心强、耐力强。被认为是「战斗力最强的星宿」。

**职业**：医生、土木工程师、雕刻师、技术工程等需要耐力与技术的职业。

**象征物**：武器、生殖图腾、家族族谱。

**所掌星官**：列舍9星。天江四星(4)、鱼一星(1)、傅说一星(1)、龟五星(5)，附座神宫一星。共5星官20星（含附座）。

**四象**：东方青龙 / **五行**：火 / **动物**：尾火虎 / **人体**：尾巴骨、下肢 / **场所**：后宫、宅院、亲属居所 / **星度**：十八度 / **辰位**：寅时 / **分野**：燕分野

**现代引申**：尾星明润且排列整齐，主后宫安定，君臣和睦；星色晦暗，主后宫纷争，君臣斥绝。

**吉凶**：利和家，忌疏离

### 7、箕宿（Jī Xiù）—— 箕水豹

**定义**：箕为龙尾末。为王后之寝、敖客，主四方蛮夷宾客，亦为口舌谗言之宿，象形播谷之箕。

**传统含义**：「维南有箕，不可以簸扬」；「箕为敖客，曰口舌」；「箕四星，为敖客，主蛮夷方客，亦主口舌谗言」。

**性格**：活跃、善于交际、投机、好口舌。表达能力强，能纳四方友人。负面为易招口舌是非，言语易得罪人。

**职业**：经商、自由职业、外交官、辩士、王后。

**象征物**：捣米器具、风伯、扇子。

**所掌星官**：列舍4星。甘氏：糠一星(1)；石氏：杵三星(3)。共3星官8星。

**四象**：东方青龙 / **五行**：水 / **动物**：箕水豹 / **人体**：嘴、舌 / **场所**：后宫寝殿、客舍、交际场所 / **星度**：十一度 / **辰位**：寅时 / **分野**：燕分野

**现代引申**：箕星明润，主四方宾服，外交顺遂；星色晦暗，主宾客不安，谗言四起。

**吉凶**：利交际，忌谗言

【四象】北方玄武
【五行】木（七曜属木）
【动物】斗木獬

12、危宿（Wēi Xiù）—— 危月燕
【定义】危为玄武脊。为坟墓、盖屋，主识先祖、掌坟墓，亦主庙堂宫室建造。
【传统含义】「危为盖屋，主庙堂宫室」；「危三星，为天府，主宗庙宫室，亦主坟墓」；「属北方玄天，主宫室与坟墓」。
【性格】重感情、直率、情绪化。善于建造规划，重先祖根基，处事能防危。负面为急躁、摇摆不定，早年漂泊。

奎宿 | 奎星明大，主兵甲充足，天下无暴乱，沟渎通畅；星暗或动摇，主兵甲匮乏。
娄宿 | 娄星明润，主苑牧丰饶，牺牲充足，享祠谨严；星暗或色变，主苑牧凋敝。
胃宿 | 胃星明大，主五谷丰登，仓廪充盈；星暗或色晦，主五谷歉收。
昴宿 | 昴星明润，主刑狱决断公正，西方边境安定；星暗或动摇，主狱事不公。
毕宿 | 毕星明大，主边兵强盛，夷狄归服，边境安定；星暗或失序，主边兵衰弱。
觜宿 | 觜觿星明润，主秋物收聚丰足，军队物资保藏完备；星暗或动摇，主物资散佚。
参宿 | 参伐星明大且排列整齐，主大将得力，兵事顺遂；星暗或色赤，主兵事失利。
井宿 | 东井星明润，主水利通畅，法度平正，刑狱公正；星暗或偏移，主水患四起。
鬼宿 | 轝鬼星明润，主察奸得力，奸谋无所藏，祠祀谨严；星暗或中星不明，主奸谋横行。
柳宿 | 柳星明润，主饮食丰足，五味调和，祭祀谨严，草木繁茂；星暗或色晦，主饮食匮乏。
星宿 | 七星明大，主文绣兴盛，急事处置得当，天下无盗贼；星暗或动摇，主急事壅塞。
张宿 | 张星明大且排列整齐，主王者恩泽广布，宾客归服，府库充盈；星暗或失序，主赏赐无度。
翼宿 | 翼星明大且相连，主天下礼乐兴盛，四夷纳贡；星散或动摇，主天子兴兵。
轸宿 | 轸星明大，主宰相得力，朝政清明，车骑整备；星动或离位，主大风成灾。
