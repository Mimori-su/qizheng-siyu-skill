# 规则适用边界

现行已确认规则优先。分析顺序保留原局→宫限→度限→小限／飞限→太岁→年干→顶星→流曜，并保留节气月限。已采用方法、条件分支和待核内容分别处理；新材料中的肯定语气不能代替条件核验。

## 已采用的检查方法

| 方法 | 用法与边界 |
| --- | --- |
| 收星完整性与走限四查 | 按 `original_vs_transit.md` 第2.1节，分别检查宫、宿度、宫主、度主，沿已确认通道及实际力量判断。 |
| 引动、作用、事件分层 | 引动本身中性，不因多个入口重复累加星力；内部记录与客户事件表达分开。 |
| 换限前后核对与计算数据绑定 | 进入、延续、退出的作用分别核查；星位、行度、时刻与算法使用一致口径，不由此推断确定应事日。 |
| 生克及救应链复核 | 分清作用对象，连续作用逐段核通道、力量及救应自身是否受制，不套固定力量档位。 |
| 学业、学历、考试与资格 | 按 `../../qz-career/resources/education_framework.md` 定位科甲、魁星、文星、正印，核实际交感、旺衰与得用，再按掌宫和星性细化；与实际工作兑现分开。非用星不直接否定学历，单星不换算学位。 |

四核心、逐星全通道、四时条件化、天官本体与化曜双层、财产归属及报告解释规则继续使用。相似表述不另立重复规则，身度主入口仍保留。

## 顶星算法及适用边界

采用 `λ % 30`、`W=(30/限年数)/2` 与29/1特例，方法和可运行入口见 `../../qz-reader/resources/topstar_query.md`。

计算需要真实行度、限年数及指定时点十一曜坐标。本命与流曜分栏，29/1特例单独标记；不从出生时间伪造行度，不默认用年初中心替代所问时刻，不引入其他行星与斗罡。采样点命中、精确窗口边界、现实应事日分别表达，不把窗口日当作必发日，也不推断每月必然扫过一次。数值算法可用，不代表整套起盘引擎已完成验收。

## 默认不启用的候选与分歧

| 内容 | 状态与处理 |
| --- | --- |
| 度限另立太极、重新配恩难或十神 | 待明确观察对象与关系基准。走限四查只区分受力对象，不替换命度主。 |
| 二十八宿限度宜忌、同经皆犯度、各宿怕自身余奴 | 仅作待核候选；须核星宿、四时、通道和解法，不能从“忌”直接输出灾害，不作为可执行断法。 |
| 流曜固定低于本命、只许特定星参与 | 不采用固定权重或删星，沿十一曜数据与真实作用判断。 |
| 余奴本性凶、抗杀不看旺衰 | 不采用无条件句；仍核条件化力量、制化及救应。 |
| 贴身＞同经＞对照＞三方及确定性档位 | 不设统一排名，逐段关系分别判断。 |
| 判贵只看天官魁文、由单星确定学位或职位 | 不采用排他定义；日月贵助、实际岗位、专业认可、资源归属与现实反馈分层保留。 |
| 天官八法、十神身份自动扩张生克 | 不采用；本体与化曜关系分层，先核实际交感，日月不按火水相克。 |
| 余福余殃固定延续年数、逐日顶星命中日等于应事日 | 待核；计算边界与现实事件时间分开，有限采样不能证明全区间无事件。 |
| 月运暂停、禁流曜、神煞白名单、每颗星全部象义强制铺满 | 不作为通用规则；现行月限、流曜和客户报告规则继续有效。 |

## 更新与调用原则

新增案例先形成待核假说，真实反馈与推断分开，完整个人案例不写入通用技能。相反的四时分支以本包指定的四时喜忌条件分支为先；采用新结论前，明确成立条件、反例、与现行规则的关系及受影响模块，再定点修改。

输入时间起盘的参数与引擎验收见 `../../qz-reader/resources/natal_chart_input.md`。本包的运行与知识调用不依赖个人文件目录或原始附件。
