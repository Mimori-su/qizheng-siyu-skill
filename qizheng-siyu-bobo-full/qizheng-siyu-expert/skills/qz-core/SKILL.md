# qz-core

## Purpose

原局核心分析引擎，是所有专题 Skill 的上游。本 Skill 输出以中文为主，所有结论都要区分“已确认规则”“整理后的分析框架”“模型推理”“不确定项”。

## When to use this skill

当用户请求与本 Skill 定位一致的学习、读盘、核心分析、专题分析、校时或报告整合任务时使用。若用户请求超出本 Skill 边界，先说明边界并交给对应上游或下游 Skill。

## Required inputs

- qz-reader 产出的 qz_structured_data.md，以及 qz-wangshuai 对原局十一曜的质性力量评估；缺必要字段时标缺失，不补造宫宿、昼夜或农历日期。

## Output files

`qz_core_report.md` 为原局记录的数据契约名称，可由对话／内存记录承载；不存档时不创建实体文件。必要内容缺失才回退，不因文件缺失而停止。

## Workflow

1. 检查结构化盘面与上游力量记录是否具备，可读取已有文件或当前结构化记录；不强制落盘。
2. 读取本 Skill 的 resources，只加载与问题相关的文件；四时喜忌先查 Vault 的“十一曜四时喜忌-条件分支”，再继承 qz-wangshuai 的十一曜力量基线，不把强弱当吉凶。旧逐星类象库只作取象与原文回查，不用无条件喜忌句覆盖现行分支。
3. 先定太极：太极点统一为**命度主**，**男女命同论**。身度主用于后天行动、实际承接、内心及身体感应的次级参考，不取代命度主锚点；专题可另定对象太极，须说明与命度主及原局喜忌的关系。
4. 按下方六入口先做观察清单：前四入口先扫宫，顺序为命宫、命度主落宫、月亮落宫、身度主落宫；随后以命度主为中心，**尽三先论宫**，列出主要支持与制约。
5. 宫层之后再看命度、命主星所在度、身度等度层，按四度相通/同度感应复核；此时完成六入口的第五、第六项宿度检索。宿度检索不得越过宫层直接定格。
6. 从原局喜忌出发，按「自己喜欢／力量突出／能解决问题」三个入口找候选用神；三类不要求同时满足。此处用神是可利用力量的广义称呼，不等同于恩难分类里“我生者”的用星。回原局核受伤、救应、有效交感、作用对象和命主承接，比较本星与来星实际力量；分列主要可用、辅助或有条件可用、原局暂不好用、待核及理由。喜欢或强大均不自动等于好用，化曜身份不能越过受制条件；未通过者解释瓶颈，不继续包装成发展优势。已成立的可用力量再按本象、落宫、掌宫、化曜、宿度与神煞叠象，转译本领、行业、资源和成就，分别说明收益与代价。缺关键条件时只保留候选，不选定断语；不增加既定交感通道。
7. 完成原局基础后读取 `resources/tianguan_analysis.md`：本命依命主→格局→天官，检查天官与身命联系、得地八法、喜忌救应及任职／社会认可条件。上一步的可用性门槛用于优势和路线推荐，不得用于删除实际交感后的天官事件象；本体作用与化曜作用可以方向相反，分别记录后合读。命主躔财度、顶伤官和日支填实等条件按已有定义与待核状态保留，不自造经度或排名。流年逐对先本体、后化曜；本命身份、年度身份和年干引动入口分栏。天官推演不受下一步“格名仅修辞”的限制，但不能凭官名保证结果。
8. **结论完成后**，按需读取 `resources/named_patterns.md`，把传统格局名作为命名与表达层；只有查找具体传统名称或原文条件时才继续读取 `resources/named_pattern_catalog.md`。先逐项核对该名称的适用分支、原局／行限范围、季节、昼夜／月相、宫位、宿度、主用身份、有效交感、双方力量、救应、承接和破格条件；不得以名称倒推结论。同名异义须拆分核验，同一结构的别名不累计证据。客户版通常只取一至两个干净成立的正向雅称，成立受限时写“有……之象，但……”并紧接白话说明；负向名称只留内部，但对应的现实压力与代价仍须如实、温和地翻译。格局名不得用来承诺财富、职位、阶层、婚姻、健康或寿命结果。
9. 输出支持因素、制约因素、缺失数据、不确定项和谨慎结论；严格遵守本 Skill 的职责边界。

## 原局喜忌与格局的六个观察入口

1. **命宫体系**：命宫本宫、对宫、三合两宫；先了解外部机会、环境与社会资源。
2. **命度主体系**：命度主落宫的本宫、对宫、三合两宫；命度主仍是所有关系的最高太极点和最终裁量中心。
3. **月亮体系**：月亮落宫的本宫、对宫、三合两宫；记录内在需求与精神驱动力，不取代命度主。
4. **身度主体系**：身度主落宫的本宫、对宫、三合两宫；记录行动和实际表现，不取代命度主。
5. **命度主所躔宿属性检索入口 A**：先确认命度主所躔星宿的七曜属性，再检索与该宿同属性的四宿上有哪些星曜。
6. **命度主本体五行检索入口 B**：另按命度主自身五行，检索该五行的四宿上有哪些星曜；这与第五项不同，不能合并。若命度主为日、月而“本体五行”未获明确定义，记录待确认，不擅自把光体归火或水。

前四项是**宫层观察**，后两项是**度层检索**。三方四正具体指本宫、对宫、三合两宫（如申宫同时看申、寅、子、辰）。检索到同一星曜可保留多个发现路径，但在证据表中只算一颗星，不能把重复命中当独立印证。检索范围不等于直接作用关系：对任意两星，只有本宫、对宫、三合两宫、同五行宿度上的交感成立时，才讨论生克制化；宫位或宿度只作为观察入口，不能自动判“交感到了”。

命宫体系先看恩星、难星、余奴、气数喜忌及日月；命度主体系再看实际生克、制化与最终承接。命宫见有力恩星可作为家庭助力线索；见余奴先查是否有难星制约，见难星须比较它与命度主的力量及是否有恩化、用制，不能单见星名便断好坏。难星所落宫、所掌宫和五行只用于定位可能的压力领域；身体取象不作医学诊断。**太阳、月亮单列为最大的贵人线索**：四个核心点若与日月真实交感，记录日月自身力量（昼夜、农历日期/月相、垣殿等）及帮助渠道；并非见日月就直接断有贵人或层次高。日月不套普通五行生克表；朔望不等于日月食，掩光／争光另核相距与同会条件。固定恩难与调候喜忌分别记录，气数喜但为难星可兼有吸引和压力；强恩可助，强难也可能构成更明显压力，不能以强弱代替吉凶。**同一星的好处与代价可并存**：如冬日遇火罗，可能既得温暖／帮助，又被分去风头，须分别比较力度和落宫人事，不净算成纯吉或纯凶。

### 从喜忌到格局兑现

- **可用性先于成就方向**：先解释候选为何来自偏好、力量或解题，再说明在原局是否受伤、是否有救应、帮助到哪一层及能否承接。详细规则见 Vault 的“本命格局分析系统”的「用神筛选与原局可用性复核」。旺衰决定作用分量，叠象决定作用内容；用神多不等于路线都可行，强难不因强而变吉，单一案例的可用星名单不泛化。
- **助力分通道**：日月交感命度主、命宫、月亮或身度主时，分别记录为核心受益、外部处境、内在支持或行动承接，不合并成「日月都直接扶命度主」。有力的命宫主或气数喜星经本宫、对宫、三合两宫实际照到命宫，也算命宫层的助力与滋润；例如气数喜水与金星同在巳宫、三合酉命宫，可增强外界支持与主观舒适，但是否转成命主实际成就仍须核命度主和身度主的承接。
- **主动性看触发条件**：分别看命度主／命宫主的自主推动力，以及气数喜、星曜落宫／掌宫和化曜所指的偏好领域。命主整体不强推，仍可能在自己喜欢、看得到价值的领域积极投入；不把「得外援」等同本人主动，也不把「主动性较弱」写成无能力。
- **财富中的贵助与成财组合**：日月与财有效联系、日月与命身有效联系都进入财富层次，体现贵人与机会，不要求每项日月助力直接会财，也不只归为体感／享用。岁殿岁驾、禄马官魁文、三元禄有效会财亦强化助力；身份、通道、力量与制约分列，不重复计星力。财源、化曜生财与财帛承载的完整组合及已确认经验量级交给 `../qz-wealth/resources/wealth_framework.md` 第10节；不由 Core 单星定金额。
- **成就方向与财官相对层级**：把有力且有效交感的星曜按本象、命度主关系、气数、落宫、掌宫、化曜身份映射到事业、财富、享用或其他领域；同一星兼多重身份只算一颗星。再分开判断「可获得的机会和资源」「命主能否承接并持续投入」「原局信号在大限／流年及现实中是否兑现」，比较财路与官路哪条更清晰，不凭单星旺弱定财富等级、职位或社会阶层。年干正偏财之间若在有效宫／度通道中相生，可记资源再投入的结构线索；单向相生不是投资获利或复利循环，仍要核两星力量、命主承接和代价，具体财官专题分别交给 qz-wealth、qz-career。

规则优先级：已确认的断法优先，四时条件见 `shared-resources/05-规则库/七政四余/十一曜四时喜忌-条件分支.md`；其中标「推演」的分支仍标推演。不冲突且已确认的细化规则可用于判断与取象；未逐条核验的汇编内容、疑字和异说保留为待核参考。补充资料不能静默覆盖已确认规则，也不以单星或单一格局名直接下结论。

## Rules

- Reader 只读盘，不解读。
- Core 的盘面事实只取自 `qz_structured_data.md`，力量基线继承 qz-wangshuai，断法查已确认规则与已标明核验状态的资料；不绕开数据契约或补造盘面。
- 专题 Skill 必须继承 `qz_core_report.md`，不能各自独立乱断。
- 对每颗实际参与分析的星，继承并核对 `../qz-wangshuai/SKILL.md` 的“逐星全通道复核”：四宫与同属性四宿均列全，旺相休囚和来星力量均有依据。不能用六入口已扫描、软件相位表或旧报告的一句旺衰替代逐星完整核验；复用完整记录，缺项补核，再下力量、喜忌及可用性判断。
- 每颗参与分析的星同时继承 `../qz-wangshuai/SKILL.md` 的“宫度生克双层解读”：先定星曜身份，再分别翻译躔度作用与事务、落宫作用与领域；力量变化和现实助阻分列。宫助度制可以并存，宫气／度气不替代实际星曜交感；客户正文择要呈现，不只复述旺衰标签。
- **作用链复核**：对影响结论的每条关系记录「作用星→已确认通道→受力对象→助阻与程度→救应星是否也受制→相关人事」。救应必须实际到达对象且具有作用力；不能只见第三星便断已化解。宫本身、宫主星、宫内星和宿气分别定位；分段间接传递不改写为两端直接生克。此为检查方法，不新增通道、固定排名或“必然”档位，方法边界及候选项见 `resources/method_boundaries.md`。
- 顶星采用已确认的顶星算法，按 `../qz-reader/resources/topstar_query.md` 获取所查询时刻的计算命中，本命与流曜分栏。沿既有顶星应事规则解读，不把计算命中日期承诺为某件具体事情的必发日；缺真实中心或限年数等参数时只标相应数据缺口；算法采用状态与输入完整性分别记录。
- 不使用确定性、恐吓式、绝对化语言。
- 区分已确认规则、整理框架、推演与待核项；未明确的判法直接说明。

## Safety rules

- 疾病问题：只作传统术数取象参考，提醒咨询医生。
- 法律问题：只作传统术数取象参考，提醒咨询律师。
- 投资问题：不提供投资建议或收益预测，提醒咨询持牌专业人士。
- 心理危机或现实危险：建议寻求现实专业帮助或紧急服务。
