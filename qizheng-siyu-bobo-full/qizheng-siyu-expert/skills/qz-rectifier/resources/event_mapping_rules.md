# 事件映射规则

事件映射用于比较候选时辰，不用于事后制造确定性。

## 映射步骤

1. 事件分类：家庭、学业、事业、迁移、感情、健康、官非、财务、子女。
2. 依正常专题定位，不能只用同名宫位匹配。感情分男女／夫妻；事业天官与官禄同参；健康全盘扫描，再查疾厄与相貌体系；官非纳入事业、财运的共用纠纷规则。
3. 找命身差异：候选时辰是否导致命宫、命度、身宫、身度或度主变化。
4. 找运势引动：按现行宫限、度限、年度流程核对原局信号；不另引未确认倒限算法。
5. 记录支持与冲突：不能只保留符合候选时辰的证据。

## 证据等级

以下是内部描述强弱的辅助语言，不是计分表，也不能把同一结构的同义词命中当多份证据。候选间应比较完整解释、反证及真正有区分力的差异。

- 强：原局主题明显，且事件年份被运势触发。
- 中：原局主题可见，但时间触发不清。
- 弱：只有单一神煞或模糊取象。
- 无效：事件时间不明、数据来源低可信度、与候选差异无关。
