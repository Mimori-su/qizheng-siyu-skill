# 七政四余 Skill｜开始使用

版本：2026-10-17。内含1个总控、13个子技能，以及按需读取的知识页、模板和辅助脚本。

## 加载

1. 解压并保留完整 `qizheng-siyu-full` 文件夹。
2. 由支持本地 Skill 的工具加载根目录 `SKILL.md`，不要只复制单个入口文件。安装到 Codex 时，放入自己的 `~/.codex/skills/` 目录；已有同名目录先备份，再用本文件夹完整替换，避免混入旧文件。
3. 使用指南见 `qizheng-siyu-expert/skills/qz-report/resources/usage_guide.md`，知识索引见 `shared-resources/README.md`。

原有学习整理、择日、校时的 `disable: true` 标记保持。不同宿主对这些既有标记及插件配置的支持可能不同；本包未逐一验证所有宿主加载行为。

## 本次内容

- 运限四项复核、交限前后比较与救应判断。
- 顶星计算：普通命中窗口、独立29/1边界、本命和流曜分栏。
- 学业、学历、升学、资格考试与实际工作兑现分析。
- 出生时间输入规则与历史夏令时校验：落入夏令时期间先提醒确认时间基准与时辰；重复或不存在的钟表时间单独核对，不自动减一小时。
- 已整合的规则写法，以及清理后的地支和二十八宿类象资料。

## Mac 上的能力边界

文字读盘和分析不需要另外安装 Python。辅助工具支持 Python 3.10 或更高版本；Mac 可以使用。完整出生本命起盘引擎尚未完成适配与验收，也未包含在本包中；仅输入生日、时间和地点时，先核验时间，再取得可靠完整盘面，不能由流曜工具冒充本命起盘。

顶星工具需要真实行度中心、限年数与同口径星位。它计算已给时刻的命中候选，不自动推造这些数据，也不保证某件现实事件发生。

## 可选脚本环境

在本包根目录执行，使用自己的虚拟环境：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r qizheng-siyu-expert/skills/qz-reader/scripts/transit_requirements.txt
```

夏令时校验使用系统 IANA 时区库；提示缺少时区数据时，再在该环境安装 `tzdata`。PDF 提取或渲染另需 `PyMuPDF`，文本提取可选 `pdfplumber` 回退。脚本命令见对应资源文档，不需要把环境目录分享出去。

回归检查：

```bash
.venv/bin/python -B -m unittest discover -s tests -v
```

`manifest.json` 记录文件清单与 SHA-256；其中不包含 manifest 自身。客户资料、完整私人命盘、缓存和本机绝对路径未随包提供。用户指定“不存档”时，仅在对话或内存中处理输入。
