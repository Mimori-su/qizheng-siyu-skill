# 人际交往模型

## 调用条件

本模型默认关闭。

以下请求才调用：

- 明确要求“人际交往模式”“人际关系”或“完整人际分析”；
- 点名父亲、母亲、家庭、兄弟姐妹、朋友、社群、恋爱娱乐、婚姻相处、领导或上司；
- 明确要求完整报告包含人际关系章节。

“详细分析性格”“性格报告”“重新分析性格”“看看这个人是什么性格”单独出现时不触发。

只点名一类关系时，只分析该类，不自动补齐其他对象。

## 核心定位

本模型是[性格分析模型](%E6%80%A7%E6%A0%BC%E5%88%86%E6%9E%90%E6%A8%A1%E5%9E%8B.md)之后的按需下游模块。先完成[四核心锚点](%E5%9B%9B%E6%A0%B8%E5%BF%83%E9%94%9A%E7%82%B9.md)、[星曜力量模型](%E6%98%9F%E6%9B%9C%E5%8A%9B%E9%87%8F%E6%A8%A1%E5%9E%8B.md)、[气数星与气数忌](%E6%B0%94%E6%95%B0%E6%98%9F%E4%B8%8E%E6%B0%94%E6%95%B0%E5%BF%8C.md)、[恩星难星用星余奴](%E6%81%A9%E6%98%9F%E9%9A%BE%E6%98%9F%E7%94%A8%E6%98%9F%E4%BD%99%E5%A5%B4.md)与[交感通道](%E4%BA%A4%E6%84%9F%E9%80%9A%E9%81%93.md)，再分析人与人如何互动。

必须拆开三层：

1. **对象与双方关系**：看对象宫位的宫主星；
2. **命主如何回应对象**：看对象宫主星与命度主的作用方向；
3. **关系领域的氛围与事件**：看该宫位本宫、对宫、三方的星曜。

宫内星不自动等同于对象本人。宫主星定位人，宫内星与三方四正定位氛围、活动和事件。

## 恩用仇难的人际方向

以命度主为命主本人、以对象宫主星为对方：

| 对象星角色 | 作用方向 | 互动倾向 |
|---|---|---|
| 恩星 | 对象星生助命度主 | 对方愿意主动付出、照顾和提供资源，常把好处送到命主手边 |
| 难星 | 对象星克命度主 | 对方倾向管理、约束、纠正或教命主做事，命主容易感到压力 |
| 用星 | 命度主生对象星 | 命主喜欢对方，愿意主动付出、照顾或提供情绪价值 |
| 仇星 | 命度主克对象星 | 命主习惯管理、约束、要求或安排对方 |
| 同星 | 对象星与命度主相同 | 双方相似、容易理解彼此，也可能放大相同习惯 |

以上是作用方向，不是吉凶标签。还要看对象星本义、[实际力量](%E6%98%9F%E6%9B%9C%E5%8A%9B%E9%87%8F%E6%A8%A1%E5%9E%8B.md)与[交感通道](%E4%BA%A4%E6%84%9F%E9%80%9A%E9%81%93.md)。

## 调候优先

[调候与气数喜忌](../../05-%E8%A7%84%E5%88%99%E5%BA%93/%E4%B8%83%E6%94%BF%E5%9B%9B%E4%BD%99/%E4%BA%94%E8%A1%8C%E5%9B%9B%E6%97%B6%E5%96%9C%E5%BF%8C-%E4%B8%83%E6%94%BF.md)高于机械生克：

- 难星同时是气数所喜：容易又爱又恨，既有约束和压力，又欣赏或需要这种能量。
- 恩星同时是气数所忌：客观有帮助，主观过程可能抵触或不舒服。
- 保留“客观作用”与“主观体感”两个层次。

### 命度主为日月

太阳、月亮不套普通五行生克，改查日月四时喜忌：

- 太阳通常不喜欢火、罗争光抢风头；木、炁较客观、有自己的见解，不一定顺从太阳。
- 月亮尤其不喜土、计遮蔽，容易形成被压住、看不清或迷茫的体感。
- 其余细则以[五行四时喜忌-七政](../../05-%E8%A7%84%E5%88%99%E5%BA%93/%E4%B8%83%E6%94%BF%E5%9B%9B%E4%BD%99/%E4%BA%94%E8%A1%8C%E5%9B%9B%E6%97%B6%E5%96%9C%E5%BF%8C-%E4%B8%83%E6%94%BF.md)及已确认的日月表为准，不自行补全。

## 对象宫位

### 家庭与父母

- 2026-10-09 升级，完整规则见[出身与父母分析模型](../../../qizheng-siyu-expert/skills/qz-core/resources/parents_framework.md)，不再局限于单一田宅主或童年照顾。
- 父亲以年干正财、太阳、田宅主多点同参；母亲看月亮并保留已核年干正印辅助。日月各自的度主星也是另一观察中心，继续核完整宫宿交感与力量。
- 田宅宫本宫、对宫、两个三合宫看家庭氛围、家产与事务；宫内星一般不直接当父亲。
- “日月见恩”的恩仍以命度主定义。父母自身条件、实际给到命主的支持、相处体感与限运变化分别解读，变化须结合具体日期与当时年龄。

### 兄弟朋友与社会群体

- 兄弟宫主星：亲生兄弟姐妹、较亲近的朋友与日常沟通。
- 福德宫主星：较疏远的人际、社会群体、社交网络与公众互动。
- 两宫都要看本宫、对宫、三方的关系氛围。

### 恋爱与娱乐

- 男女宫主星：桃花或恋爱对象的主要人物星；以星曜本义、力量和交感分析对象的性格倾向及基本关系。
- 男女宫本宫、对宫、三方：恋爱活动、休闲娱乐、吃喝玩乐偏好与约会氛围。

### 婚姻

- 夫妻宫主星：正式伴侣或配偶的主要人物星；以星曜本义、力量和交感分析对象的性格倾向及双方关系。
- 夫妻宫本宫、对宫、三方：婚后相处模式、共同生活氛围与婚姻事件。

对象画像的完整检查与推断边界见[婚恋分析模型](../../../qizheng-siyu-expert/skills/qz-love/resources/love_framework.md)。

男女宫与夫妻宫必须分开：

- 男女宫喜、夫妻宫忌：可能享受恋爱，但对婚姻责任或长期相处感到压力；
- 男女宫忌、夫妻宫喜：恋爱过程可能波折，反而适合明确承诺、相亲或婚后稳定相处。

### 领导与上司

- 官禄宫主星：领导、上司及命主与管理者的关系。
- 官禄宫本宫、对宫、三方：公司氛围、工作内容、管理环境与职场事件。

## 固定检查顺序

对每一个对象宫主星：

1. 星曜本义；
2. 四时、入垣、升殿、受生等力量；
3. 与命度主的恩用仇难或同星关系；
4. 调候与气数喜忌；
5. 宫主星本宫、对宫、三合宫及同五行宿度的交感星曜。

对每一个对象宫位：

1. 本宫星曜；
2. 对宫星曜；
3. 两个三方宫星曜。

## 输出模板

```markdown
### 对象
- 对象宫位与宫主星：
- 对象星本义与力量：
- 与命度主的关系及作用方向：
- 调候、气数喜忌：
- 对象星交感修饰：
- 本宫、对宫、三方氛围：
- 对方倾向：
- 命主反应：
- 关系氛围：
- 条件变化与建议：
```

## 表达边界

- 只描述互动倾向，不给对方贴人格标签。
- 管理与约束可能是教导、规范或承担责任，不直接解释为恶意。
- 主动付出也有现实边界，要结合星曜强弱。
- 只有原局时写长期模式，不虚构已经发生的关系事件。
