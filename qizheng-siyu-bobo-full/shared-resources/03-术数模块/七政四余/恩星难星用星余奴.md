# 恩星难星用星余奴

## 以命度主为中心的五类关系

| 角色 | 作用方向 | 基础意义 |
|---|---|---|
| 恩星 | 生我 | 资源、贵人、支持 |
| 难星 | 克我 | 压力、约束、挑战 |
| 余奴星 | 同我、同气 | 竞争、分利、分压或扛杀 |
| 仇星 | 我克 | 命主主动管理、制约或消耗 |
| 用星 | 我生 | 命主主动输出、成全、泄化或投入 |

命度主为太阳或月亮时，不机械套普通五行生克，改按日月四时喜忌、昼夜、月相和明晦判断。调候优先于角色名称。

## 恩星

恩星的落宫和所掌宫位会带来好处。若恩星同时是[气数忌](%E6%B0%94%E6%95%B0%E6%98%9F%E4%B8%8E%E6%B0%94%E6%95%B0%E5%BF%8C.md)，必须保留双层结论：

- 客观上有帮助或利益；
- 主观上过程不顺、抵触或体感不舒服。

## 难星

代表压力、制约或伤害来源。判断顺序：

1. 是否交感命度主；
2. 难星与命度主谁更有力；
3. 是否被恩星化；
4. 是否被用星制；
5. 是否有余奴抗。

不能见难星就直接断凶。

## 用星

在人际关系中，用星是命度主所生的对象星：命主通常更喜欢对方，也更愿意主动付出、照顾或提供情绪价值。

在事件分析中，用星仍可参与成全、保护或制化关键矛盾。是否成立，要看自身力量、交感通道，以及能否实际作用到命度主。

## 仇星

仇星是命度主所克的星曜，常表示命主主动管理、约束、消耗或掌控的对象与领域。能否形成成果，要继续看命度主是否有力、仇星能否被有效制约，以及最终由什么宫位承接。

## 余奴

余奴星是与命度主同类、同气的力量。默认可能表现为竞争、分夺资源、心态搅扰、利益损耗和分利；正面可表示同伴、合伙或替命主分担压力。

- 看是否被难星制；
- 看是否被用星化；
- 若恩星生余奴，可能是别人得到更多好处。

难星有效攻击命度主，余奴又处于有效通道并实际参与承压、拦截或转化时，才进入[余奴扛杀](../../05-%E8%A7%84%E5%88%99%E5%BA%93/%E4%B8%83%E6%94%BF%E5%9B%9B%E4%BD%99/%E5%9F%BA%E7%A1%80%E5%85%B3%E7%B3%BB/%E4%BD%99%E5%A5%B4%E7%8A%AF%E4%B8%BB%E4%B8%8E%E4%BD%99%E5%A5%B4%E6%8A%97%E6%9D%80.md)判断。若难星本来无力，余奴不能自动记功，仍需检查犯主与分利。

完整格局识别见[本命格局分析系统](%E6%9C%AC%E5%91%BD%E6%A0%BC%E5%B1%80%E5%88%86%E6%9E%90%E7%B3%BB%E7%BB%9F.md)。

## 人际作用方向

| 对象星角色 | 作用方向 | 基本互动 |
|---|---|---|
| 恩星 | 对象星生助命度主 | 对方主动给予和照顾 |
| 难星 | 对象星克命度主 | 对方管理、约束或要求命主 |
| 用星 | 命度主生对象星 | 命主喜欢并主动为对方付出 |
| 仇星 | 命度主克对象星 | 命主管理、约束或要求对方 |
| 同星 | 对象星与命度主相同 | 双方相似，互相理解或放大同类习惯 |

人际断法的完整顺序见[人际交往模型](%E4%BA%BA%E9%99%85%E4%BA%A4%E5%BE%80%E6%A8%A1%E5%9E%8B.md)。调候与气数喜忌优先于机械生克。
