# 星曜力量模型

## 本命盘判断顺序

十一曜——太阳、月亮、木、火、土、金、水、紫炁、月孛、罗睺、计都——**逐一建档并比较**，不能只给命度主或几颗显眼的星打标签。每颗星按以下顺序保留支持与制约证据，最后才相对命度主判断其帮助、压力或消耗的分量：

1. **月令与四时：** 看五行旺相休囚死及寒暖燥湿；气数喜忌与星曜旺衰分开记，旺不自动吉。
2. **日月特殊条件：** 太阳核昼夜与光照，月亮另核昼夜、农历日期、月相、明晦和是否日月俱晦。日月不按普通五星四余的恩难生克硬套。
3. **升殿＝得天时：** 核星曜所躔二十八宿度是否升殿，及该宿度的受生、受制条件；用“天赋／先天发挥条件”描述，不与落宫混为一项。
4. **入垣＝得地利：** 核星曜落宫是否入垣，及宫位是否受生、受制；用“后天人事环境的承接”描述，不把宫位名称本身当作力量分数。
5. **四柱地支填实：** 只拿**星曜落宫地支**与出生年、月、日、时四支逐个比较；相同即记录填实，生年支（本命太岁）最重。所躔宿度对应地支不参加填实，也不把三合、六合当作本命填实。
6. **实际作用：** 按[交感通道](%E4%BA%A4%E6%84%9F%E9%80%9A%E9%81%93.md)核有效星曜，比较双方力量、受生受制、通关和泄耗；迟、留、伏、逆等运行状态有盘面依据时再补充。

输出只用“较有力／可用但受限／偏弱”等**质性结论**，并列出依据、制约和缺失条件；不使用固定百分比或“得势”独立指标。全盘比较时对每颗星保留同样字段，不能因为某星是恩星就跳过其受制，或因为某星是难星就跳过其可被制化的条件。

## 得令、天时、地利与交感作用

- **得令**：四时旺相休囚死；日月另看昼夜、月相和明晦。
- **得天时**：躔宿升殿，以及宿度上受生或受制的条件。
- **得地利**：落宫入垣，以及宫位上受生或受制的条件。
- **填实**：星曜落宫支与本命四柱支同支；记录对应年、月、日、时及重复次数，生年支优先，但不换算分数。
- **交感作用**：逐项记录三方四正及其他有效通道中的生扶、承接、通关、受制、泄耗和拦截。

“得势”不作为独立技术指标。见星多也不等于核心星有力，必须同时确认有效通道、作用方向和对方实际力量。日月作为最大贵人星，仍须按其自身强弱、通道和命主承接能力判断可得帮助的大小；见到日月不等于帮助已经落实。

## 十一曜逐项记录字段

| 范围 | 必填记录 |
| --- | --- |
| 日、月 | 月令和气候；昼夜、月相／明晦（太阳不套月相）；宿度与落宫；填实；受蔽、交感、实际帮助。 |
| 木、火、土、金、水 | 月令旺衰与调候；宿度升殿、落宫入垣；填实；有效受生受克；对命度主的恩难余仇用及作用分量。 |
| 炁、孛、罗、计 | 分别随木、水、火、土参看四时，但另保留四余本身的状态、组合与受制条件；逐星核宿度、落宫、填实和交感，不把同五行的两颗星合并成一颗。 |

四时细则按[五行四时喜忌-七政](../../05-%E8%A7%84%E5%88%99%E5%BA%93/%E4%B8%83%E6%94%BF%E5%9B%9B%E4%BD%99/%E4%BA%94%E8%A1%8C%E5%9B%9B%E6%97%B6%E5%96%9C%E5%BF%8C-%E4%B8%83%E6%94%BF.md)逐条看月份早晚、昼夜和具体条件；待核的互异说法不能压成固定吉凶公式。

## 已确认的水星示例

- 水星在巳、申宫入垣；
- 水星在辰、酉宫受生；
- 水星在水宿升殿；
- 水星在金宿受生，力量较强。

这组规则只确认水星，不自动推导其他星曜的入垣升殿表。

## 重要修订

不使用未经已确认的固定百分比权重。客户版也不显示分数。本命四柱填实与流年地支引动是两项不同的检查，不可混写成一条“太岁填实”。
