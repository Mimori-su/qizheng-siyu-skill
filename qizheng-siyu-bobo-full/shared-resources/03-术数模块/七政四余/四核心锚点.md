# 四核心锚点

## 命度主

命度线所在星宿对应的星曜，代表个人能量内核，也是分析命主吉凶事件的主要太极点。

## 命宫主

命宫所在宫位的主星，代表社交面具、对外呈现、外人印象，以及承接外界事务的方式。

## 月亮

通过月亮的落宫、躔宿和交感星曜判断内在情绪、安全感与潜意识需求。

## 身度主

由月亮所躔宿度的五行确定。例如月躔木度，则身度主为木星。主要代表成熟能力、内在驱动力、精神与潜意识方向。

## 关系

- 命度主、命宫主偏向对外可见的一面。
- 月亮、身度主偏向内在感受与深层驱动。
- 身度主不能替代命度主成为命主事件的主要太极点。
- 四者都必须继续检查[交感通道](%E4%BA%A4%E6%84%9F%E9%80%9A%E9%81%93.md)和[星曜力量模型](%E6%98%9F%E6%9B%9C%E5%8A%9B%E9%87%8F%E6%A8%A1%E5%9E%8B.md)。

四核心先按“命度主 → 命宫主 → 月亮 → 身度主”完成定位。进入[本命格局分析系统](%E6%9C%AC%E5%91%BD%E6%A0%BC%E5%B1%80%E5%88%86%E6%9E%90%E7%B3%BB%E7%BB%9F.md)后，另按“命宫体系 → 命度主体系 → 月亮体系 → 身度主体系”扫描资源结构；前者是定位顺序，后者是格局观察顺序。

## 与“三主”表述的对应

“三主”的合称将命度主、命宫主与“身主”并称三主；其中身主由月亮与身度主共同承担。天枢 Oracle 保留四核心的拆分写法，以免把情绪与身心承载（月亮）同成熟能力、深层驱动（身度主）混成同一个判断点。

关于以昼夜调整命度主、身度主关注比重的古法说法，当前未形成已确认的固定执行规则，因此不自动改变本卡的四核心定位顺序。
