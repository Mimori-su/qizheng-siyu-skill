# 性格修饰层：宿度与神煞

## 定位

性格分析的证据优先级为：

```text
核心星曜与强弱
  ↓
交感关系与落宫
  ↓
命宫、相貌宫、福德宫结构
  ↓
四核心星曜所躔宿度
  ↓
核心星曜相关宫位神煞
```

星曜决定性格骨架，星宿与神煞只负责补充“怎样表现”。后两者类似形容词，不可反客为主，也不可单独推翻前层结论。

## 一、宿度调用规则

性格专题只重点读取：

1. 命宫主所躔星宿；
2. 命度主所躔星宿；
3. 月亮所躔星宿；
4. 身度主所躔星宿。

其他星曜的宿度暂不进入性格主流程，避免信息过载。若月亮与身度主、命度主与命宫主为同一星曜，合并证据，不重复加权。

宿度解释从[性格类象索引](../../04-%E7%B1%BB%E8%B1%A1%E5%AD%97%E5%85%B8/%E6%98%9F%E5%AE%BF/%E4%B8%93%E9%A2%98%E5%88%86%E7%B1%BB/%E6%80%A7%E6%A0%BC%E7%B1%BB%E8%B1%A1%E7%B4%A2%E5%BC%95.md)调用，并必须与星曜本义结合。例如：

- 火星躔斗木：先以火星定行动、竞争和推动，再以斗宿补充沉稳、掌控、不服输和识人用人。
- 水星躔尾火：先以水星定观察、思考和表达，再以尾宿补充谨慎、耐力和好胜。
- 月亮躔张月：先以月亮定情绪、安全感和潜意识，再以张宿补充优雅、表达、重情义和生活质感。

不得把星宿负面类象直接写成人格判决。应表达为条件式倾向，例如“压力大时可能更固执或更重防御”。

## 二、神煞调用路径

对每一个核心锚点，按顺序检查：

1. 该星曜实际落入宫位所带神煞；
2. 该星曜所掌管宫位所带神煞；
3. 只提取与性格、人际、认知、学习、表达、边界或情绪有关的神煞；
4. 不熟悉、未录入起法或含义不明确的神煞标记为待补充，不自行解释。

示例：命宫为酉，先看酉宫神煞；命宫主为金星，再看金星实际落入宫位的神煞，并结合金星所掌宫位。月亮、命度主与身度主同理。

## 三、神煞只作形容词

可用的表达形式：

| 神煞 | 性格修饰示例 |
|---|---|
| 天乙贵人、天贵、玉贵 | 较易获得贵人或长辈支持；为人较有分寸、聪慧 |
| 文昌 | 学习、文字、逻辑、考试或知识整理能力较突出 |
| 国印 | 重责任、规则、组织与身份感 |
| 华盖 | 独立、好思考，对艺术、哲学、心理或玄学较敏感 |
| 桃花、红鸾、咸池 | 审美、吸引力、人际感受或关系意识较强 |
| 驿马 | 喜变化、流动、探索，适应异地或多场景 |
| 孤辰、寡宿 | 需要私人空间，精神上较独立；不等于孤独终身 |
| 卷舌 | 语言立场较鲜明，压力下容易争辩或发生口角 |
| 羊刃、阴刃 | 果断、敢承担；失衡时可能急切或反应强 |
| 劫煞 | 面对突发变化反应快；失衡时容易感到阻碍或紧张 |

以上只是修饰词库。每次输出只选择能与星曜骨架互相印证的少量神煞，不罗列整宫。

## 四、冲突处理

- 星宿或神煞与核心星曜结论一致：用于增强描述的具体度。
- 星宿或神煞与核心星曜结论不同：写成“另一面”或特定情境下的表现。
- 多个神煞相互冲突：回到星曜强弱、交感和宫位，不以神煞投票。
- 只有神煞、没有星曜与宫位支持：不得形成主结论。

## 五、待核边界

起法或语义尚未明确的条目，不转写为确定规则。
