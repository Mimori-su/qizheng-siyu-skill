## 总原则

```text
基础信息
  → 关系分析
  → 结构组合
  → 人事映射
  → 星宿与神煞修饰
  → 综合判断
```

不能以单颗星、单个宫位、单个神煞或软件格局标签直接定吉凶和层次。

## 核心太极

- 命度主：命主本人的最高太极，最终判断命主得失与承载。
- 命宫主：社交面具、外在呈现及承接外界事务的方式。
- 月亮：内在需求、情绪、安全感与精神驱动力。
- 身度主：成熟能力、行动力、执行方式与现实表现。

普通五星、四余以命度主为中心区分：

| 角色 | 关系 | 结构意义 |
|---|---|---|
| 恩星 | 生我 | 资源、贵人、支持 |
| 难星 | 克我 | 压力、约束、挑战 |
| 余奴星 | 同我、同气 | 竞争、分利、分压或扛杀 |
| 仇星 | 我克 | 命主主动管理、制约或消耗 |
| 用星 | 我生 | 命主主动输出、成全、泄化或投入 |

命度主为日月时，不机械套五行生克，改看日月四时喜忌、昼夜、月相与明晦。调候优先：难星兼气数喜，可能“有价值但伴随压力”；恩星兼气数忌，可能“客观得益但主观不适”。

太阳、月亮同时是格局中的最高优先级贵人星，独立于恩难余仇用。正式恩星仍只指生助命度主的普通五星或四余；日月贵人支持与正式恩星支持必须分开记录。命度主为日月且正式恩星替代映射未教学时写“待确认”。

## 基础力量

| 层次 | 判断重点 |
|---|---|
| 月令与调候 | 四时旺相休囚死、寒暖燥湿；气数喜忌另栏，不把旺衰当吉凶 |
| 日月明晦 | 太阳核昼夜及光照，月亮核昼夜、农历日期、月相和日月俱晦 |
| 天时 | 躔宿是否升殿及受生受制；升殿表示先天发挥和天赋条件 |
| 地利 | 落宫是否入垣及受生受制；入垣表示后天人事环境的承接 |
| 四柱填实 | 仅星曜**落宫地支**对照本命年、月、日、时四支；同支增强，生年支最重，不比较宿度对应地支 |
| 生扶／受制 | 写清谁作用谁、双方力量、制化是否经有效交感接通 |

太阳、月亮、木、火、土、金、水、炁、孛、罗、计**十一曜逐一做同口径的质性力量记录**，再比较对命度主的帮助、压力与消耗。具体字段见[星曜力量模型](%E6%98%9F%E6%9B%9C%E5%8A%9B%E9%87%8F%E6%A8%A1%E5%9E%8B.md)。“得势”不设为独立技术指标。只用“较强／可用／受限”等有依据的语言，不用未经确认的百分比；本命四柱填实不等于流年三合引动。

## 四阶段格局扫描

四核心先定位命宫主、命度主、月亮、身度主各是谁、各在哪里；进入喜忌与格局观察后，固定按下列顺序扫描。**四个阶段各自都查观察点所在本宫、对宫、两个三合宫**，不只查命宫体系：

1. **命宫体系**：先看命宫本宫、对宫、两个三合宫，列入宫星与宫主星的有效作用，判断外部机会、社会资源和环境承接。
2. **命度主体系**：看命度主**实际落宫**的本宫、对宫、两个三合宫，判断核心能力、真实得失与发展方向。
3. **月亮体系**：看月亮**实际落宫**的本宫、对宫、两个三合宫，判断内在需求、情绪模式和精神驱动力。
4. **身度主体系**：看身度主**实际落宫**的本宫、对宫、两个三合宫，判断成熟能力、行动与现实表现。

命宫体系先扫描属于“观察顺序”，不改变命度主的最高裁决地位。三方四正固定为本宫、对宫与两个三合宫；例如观察申宫时看申、寅、子、辰。盘内星曜的直接交感只允许自身本宫、对宫、两个三合宫及同躔五行宿度；星曜掌宫、化曜与类象负责说明人事，不可自动变成新的交感边。

### 命度主另设两条宿度检索入口

完成四阶段宫位扫描后，**分开**列出：

- **A｜所躔宿属性四宿：** 先看命度主实际躔宿的七曜五行，再查同属性的四宿各有何星曜。例如土星命度主躔木度，A 查四木度。
- **B｜命度主本体五行四宿：** 以命度主自身五行查其对应四宿。例如土星命度主，B 查四土度，作为伴随命主较久的结构性背景。

A 与 B 可以因躔宿属性不同而得到不同星群；即使重合也分别保留检索理由，不把同一星重复当两条独立证据。两者是观察入口，不是无限扩张通道；候选星能否作用命度主，仍回到[交感通道](%E4%BA%A4%E6%84%9F%E9%80%9A%E9%81%93.md)的有效位置核验。

命度主为太阳或月亮时，不把太阳硬指定为火、月亮硬指定为水。A 仍按实际所躔宿的七曜属性检索；B 所需的“命度主本体五行”若无另有已确认映射，标为**待确认**，不自行补造。

四个阶段均须额外回答：该核心点是否交感太阳、是否交感月亮；日月自身是否有力；帮助到达外部机会、命主真实得益、内在支持还是执行兑现层。盘面同一颗星可在多阶段被引用，但只登记一条本命事实与多条观察路径。

### 命宫体系先辨的喜忌项目

| 项目 | 先记录的倾向 | 仍须核实 |
| --- | --- | --- |
| 恩星 | 生助命度主；若能到达命宫体系，通常提示家庭或外界助力 | 恩星自身力量、落宫、掌宫、是否真的到达命度主；生助过多与气数忌可能带来代价 |
| 太阳、月亮 | 最高优先级贵人类别；与四核心有效交感有助于观察层次与支持 | 日月自身昼夜、月相、宫宿、受蔽及命主能否承接，不因“见到”即断强助 |
| 气数喜／气数忌 | 喜者关系到主观舒适与主动追求；忌者易形成烦心或抵触 | 与客观恩难分栏，喜不等于吉，忌不抹去客观所得 |
| 余奴 | 可竞争、分利、消耗，也可分压 | 是否有有力难星制余奴、是否扛杀；不见制化时再讨论竞争和占便宜的风险 |
| 难星 | 可带来管理、压力与制约；落宫、掌宫、五行指向可能来源 | 是否直接克命度主、双方强弱、恩化／用制／余奴承压等救应 |

难星兼气数喜时，要同时写“愿意接触／认为有价值”和“压力较大／过程不顺”；恩星兼气数忌时，要同时写客观帮助和主观不适，不把任一面改写成相反事实。难星若经有效通道直接克命度主，可在**内部理论档**记录其五行身体类象与所掌宫位为待核对线索；不得据此作医学诊断或向客户预告疾病。

命宫层的助力不只来自日月或正式恩星：命宫主、气数喜星等若经本宫、对宫或三合两宫有效照到命宫，也可帮助外在处境，并使该领域较符合命主的主观需要。须分列「命宫得到支持／滋润」与「命度主直接受益」，再查星曜力量及命身能否承接。以美女盘为方法例：酉命宫与巳宫成三合，巳宫金、水照命宫，水又为申月气数喜；这是命宫层的金水助力，不替代午宫太阳拱戌宫命度主、卯宫月亮对照酉命宫这两条日月通道。

## 日月贵人与帮助力度

固定先执行[日月贵人与帮助力度模型](%E6%97%A5%E6%9C%88%E8%B4%B5%E4%BA%BA%E4%B8%8E%E5%B8%AE%E5%8A%A9%E5%8A%9B%E5%BA%A6%E6%A8%A1%E5%9E%8B.md)：

1. 建立四核心与日月的交感矩阵；
2. 判断日月强弱；
3. 判断正式恩星及已确认的结构性助力强弱；
4. 检查通道、承接、受制、截夺和分利；
5. 分开记录“来源类别”“五类角色”与“实际帮助程度”，后者用“帮助强且可达／帮助可用但受限／有帮助线索但较弱／未形成直接帮助／待确认”定性。

日月交感命度主最直接关系命主真实得益；只交感命宫主时先解释为外部机会。日月类别最高，不等于本盘实际帮助一定最大；不得只因“见日月”或“见恩星”便夸大贵人帮助。

财富层次补充（2026-10-13）：**日月会财、日月联系命身均为正向依据**，重点是贵人多、机会多；命身贵助不要求日月直接会财，也不只解释成体感或承受。岁殿岁驾、禄马官魁文、三元禄有效会财亦增加助力。与各路旺财、生财、财帛承载合看，不设固定分值、不按标签数跳档；经验量级与完整成立条件统一见[财运分析模型](../../../qizheng-siyu-expert/skills/qz-wealth/resources/wealth_framework.md)第10节。

## 贵人与资源来源

每颗帮助星都要回答：

1. 帮助依据是什么；
2. 与命度主是什么关系；
3. 自身是否有力；
4. 落宫在哪里——好处在哪里显现；
5. 掌管哪些宫位——资源由什么人物或领域而来；
6. 是否通过有效通道到达命宫体系或命度主。

```text
星曜性质
  + 与命度主的关系
  + 星曜落宫
  + 星曜掌宫
  + 力量与制化
  = 具体贵人、资源、财富或名望来源
```

## 成就方向与财官相对层次

### 用神筛选与原局可用性复核

候选用神有三个入口，满足其中一类即可进入复核，不要求三类同时成立：

| 候选来源 | 选择依据 | 现实问题 |
| --- | --- | --- |
| 自己喜欢的 | 气数所喜、符合本人需要，能触发主动投入 | 命主注重和愿意追求什么 |
| 力量突出的 | 某星或某一方面能量较强，具备可利用的能力或资源线索 | 有什么本领或外部支持可以发挥 |
| 能解决问题的 | 有制难、化难、疏通或改善原局问题的结构线索 | 靠什么突破瓶颈、缓解压力 |

喜欢不等于有利，强大不等于好用，有解法之象不等于解法已经成立。每颗候选星必须回到原局复核：

1. **实际力量与受伤**：合看四时、日月特例、垣殿、落宫和躔度生扶克泄、填实与受制；喜星受伤后还有多少可用能力，不能只凭喜名或化曜身份保留为优势。
2. **交感与救应**：按既有通道逐段检查作用对象、制化路径及救应双方力量；无通道不能补出生克链，尚待限运引动的线索不算已经可用。
3. **到达与承接**：分清帮助到达命宫环境、命度主、其他核心或具体领域，以及本人能否承接和持续投入；不要求每项助力都必须直接生助命度主，也不把外援当成本人能力。
4. **得失与取舍**：保留实际好处、压力、分利和成本，给出主要可用／辅助或有条件可用／原局暂不好用／待核的定性判断及理由。暂不好用的星可用于解释瓶颈，不继续包装为推荐发展路线。

筛选后的取象链为：**可用星及实际作用 → 星曜本性＋落宫＋掌宫＋化曜身份 → 宿度含义与神煞修饰 → 本领、行业、角色、资源渠道 → 财富／职位／名望的成就形态及代价**。旺衰决定作用的分量，叠象决定作用的内容；行业和领域不能仅由一颗星旺衰推出，神煞和宿度类象也不能推翻主结构。

内部记录每个方向“为何选这颗星、原局是否好用、经什么通道作用、对应哪些人事、支持与制约是什么”。客户报告按 [本命格局报告模板](%E6%9C%AC%E5%91%BD%E6%A0%BC%E5%B1%80%E6%8A%A5%E5%91%8A%E6%A8%A1%E6%9D%BF.md) 先给总评及简明格局要点，再说明具体发展方向，不把所有候选都列成优势。此规则为通用方法，不带入特定案例的可用星名单或未经确认的新交感规则。

### 成就方向与层次判断

先分清**自主推动力**与**兴趣触发的投入**：命度主、命宫主和身度主说明本人能否主动推动、维持行动；气数喜星的落宫、掌宫及化曜身份说明命主愿意追求什么。整体不强推，不等于在自己喜欢、看得到价值的领域缺乏行动力。外界资源强也不能当成本人主观能动性强。

只对经原局复核后可用或有条件可用的星曜展开成就方向，按以下链条取象并保留每段反证；未通过者保留为压力或待引动线索：

1. **偏好与目标**：气数喜忌、四核心及其落宫／掌宫，区分主观喜欢与客观得益。
2. **资源和角色**：日月贵人、恩星、命宫层助力，以及年干正偏财、财帛主、田宅主、官禄主／官星等身份；同一曜兼数职只算一颗星。
3. **通道与流向**：先核本宫、对宫、三合或同五行宿度是否真交感，才论两曜生克及资源由哪个领域流向哪个领域。年干正财生偏财可作「已有财源支持另一类经营或积累」的结构，持续投入只是可能的行为取象。
4. **双方力量与命主承接**：对财源、受生的偏财曜、官禄主及命度主分别核四时、昼夜／月相、入垣、升殿、落宫和躔度的生扶克泄、填实与实际交感；帮助和由此增加的责任、压力可以同时存在。
5. **相对层次与兑现**：分别写资源机会、本人承接与行动、限运／现实兑现，比较财路和官路哪一条更清晰。财富可按[财运分析模型](../../../qizheng-siyu-expert/skills/qz-wealth/resources/wealth_framework.md)已确认的经验条件给潜力档，未教明的边界不补造；不由单星旺衰报告当前身家、官阶或收益。

美女盘的**方法示例**：丁年水星为正财、紫炁为偏财。水星巳宫与紫炁午宫不是宫层交感，但同躔张月宿，可以在度层论水生炁；水星兼财帛主、男女主且为气数喜，故兴趣／关系领域的可动用资源可能支持紫炁所在的田宅积累。两者是同宿感应，不是同宫、同度或精确合相；水生炁是单向支持，不是已形成收益循环。紫炁自身力量仍须核，且炁木对土命度主是难星，财路扩张也可能增加命主的承载压力。此例说明推导方法，不自动更新既有客户案例。

## 天官补充：本命格局与从政条件

依[天官分析模型](../../../qizheng-siyu-expert/skills/qz-core/resources/tianguan_analysis.md)，先完成本命命主、喜忌、力量及格局，再核天官与身命的关系、得地八法、天官喜忌与救应，说明从政、任职、社会认可的机会及限制。天官、魁星、文星分别定位；同星兼职不重复计力，不把古格换算现代官阶。

“原局可用性”限制优势和推荐路线，不删除已经实际交感的化曜事件象。星体相克与身份相生可同时成立，分开说明方向、人物领域、帮助与代价；有象不等于已经兑现。八法按适用定义检查，不扩大一般原局体系直接生克通道，不编经络或顶法算法。

保留命主躔财度即生官度的主体，以及“命度主化生官正财而顶伤官”“日支填实且立命于此”等特定条件；填实特例不改全局生年太岁优先规则。输出仍用[本命格局报告模板](%E6%9C%AC%E5%91%BD%E6%A0%BC%E5%B1%80%E6%8A%A5%E5%91%8A%E6%A8%A1%E6%9D%BF.md)，天官并入事业、社会成就、外部资源，内部保留两层证据。

## 格局名称层

本命格局报告不以“套中一个名字”为交付前提。必须先完成结构性总评：优势如何组织、资源怎样到达、命主能否承接、代价与限制在哪里；完成后才可按[格局名称调用与客户表达规范](../../../qizheng-siyu-expert/skills/qz-core/resources/named_patterns.md)匹配有明确定义的传统格局名称。

调用名称时逐项核对：定义与条件分支、原局或行限范围、形态、季节、昼夜／月相、宫位、宿度、主用身份、有效交感、双方力量、受伤救应、命主承接和破格条件。同名异义、同名吉凶分支分别保留；同一结构的多个别名只算一个格局，不增加证据权重。

内部档可以记录正式名称和成立状态；未命名但能够说清的结构，直接用作用关系和现实人事表达，不新造“某某格”。客户版最多择一至两个有助于理解优势的正向雅称；负向旧称只留内部，真实压力仍须温和而诚实地说明。格名不能推翻原局喜忌和可用性，也不能直接推出富贵、官阶、婚姻、疾病或寿命。

[七政基础-格局命名与条件](../../02-%E5%9F%BA%E7%A1%80%E7%90%86%E8%AE%BA/%E4%B8%83%E6%94%BF%E5%9B%9B%E4%BD%99%E5%9F%BA%E7%A1%80%E7%9F%A5%E8%AF%86%E5%BA%93/%E4%B8%83%E6%94%BF%E5%9F%BA%E7%A1%80-%E6%A0%BC%E5%B1%80%E5%91%BD%E5%90%8D%E4%B8%8E%E6%9D%A1%E4%BB%B6.md)用于检索候选格名与条件分支；相反说法并列待核，不覆盖已确认规则。

## 首批格局

### 余奴扛杀格

有力难星能克命度主，同时余奴处于有效通道，确实参与承压、拦截或转化。若难星原本无力，不能把余奴自动写成扛杀有功，仍需检查[余奴犯主、分利或消耗](../../05-%E8%A7%84%E5%88%99%E5%BA%93/%E4%B8%83%E6%94%BF%E5%9B%9B%E4%BD%99/%E5%9F%BA%E7%A1%80%E5%85%B3%E7%B3%BB/%E4%BD%99%E5%A5%B4%E7%8A%AF%E4%B8%BB%E4%B8%8E%E4%BD%99%E5%A5%B4%E6%8A%97%E6%9D%80.md)。

### 恩化难格

```text
难星 → 生恩星 → 生助命度主
```

三段关系必须有实际通道，恩星有力承接，转化链没有被克、被隔或泄散。

### 恩星照命格

恩星进入命宫体系或命度主体系的三方四正，并能形成有效生助。弱陷、受制或兼气数忌时，必须写出资源有限、过程不适或利益被截夺的制约。

日月不自动并入恩星照命格；日月支持单独记录，不自行另造格局名。若传统资料已有名称且全部成立条件通过复核，可在不改变原判断的前提下调用。

## 判格门槛

每个格局都必须同时记录：

- 必要角色关系；
- 有效交感；
- 实际力量；
- 支持证据与反向证据；
- 化解或破格条件；
- 落宫、掌宫及人事承接；
- 成立状态：成立／有形但受限／仅见单项条件／不成立／待确认。

同一盘面事实不能在命宫体系和命度主体系重复算作两条独立证据。

## 人事翻译

```text
作用关系
  ↓
关键星曜及本义
  ↓
星曜落宫
  ↓
星曜掌宫
  ↓
人物、渠道和领域
  ↓
具体事件表达
```

星宿**类象**可修饰快慢、显隐、稳定性与发展方式；星宿的七曜属性另参与上述 A/B 检索及同五行宿度交感核验，二者不能混同。神煞补人物关系和事件色彩。修饰层不能单独改变主事件。

一颗星的本象、落宫、所掌宫位和化曜身份应分栏取象；若掌多个宫位，只提升与当前问题最直接、且有独立证据呼应的来源。太极、叠象和证据轻重可作兼容细则；四时细节按[五行四时喜忌-七政](../../05-%E8%A7%84%E5%88%99%E5%BA%93/%E4%B8%83%E6%94%BF%E5%9B%9B%E4%BD%99/%E4%BA%94%E8%A1%8C%E5%9B%9B%E6%97%B6%E5%96%9C%E5%BF%8C-%E4%B8%83%E6%94%BF.md)逐条核条件。待核的补充细节不能覆盖已确认规则。

## 输出结构

正式报告使用 [本命格局报告模板](%E6%9C%AC%E5%91%BD%E6%A0%BC%E5%B1%80%E6%8A%A5%E5%91%8A%E6%A8%A1%E6%9D%BF.md)，并固定拆成两个文件：

- 客户完整报告：直接交付客户，使用连贯的人生语言；
- 内部理论档：供命师留档，保留盘面证据、已确认规则、推演链、成立条件、反证与待验证项。

两份文件共用同一组结论。先完成内部理论档，再生成客户版；每项内部结论都必须包含支持因素、制约因素和综合判断。
