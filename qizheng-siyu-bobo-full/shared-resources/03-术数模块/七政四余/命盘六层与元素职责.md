# 命盘六层与元素职责

这是一张“先认盘、再断盘”的读盘地图。每一层只负责一类问题；不把任何单层信息当成完整结论。

## 命盘六层

| 层次 | 盘面元素 | 主要职责 |
| --- | --- | --- |
| 中心层 | 命度与命度主 | 锚定命主核心与本命主要观察落点 |
| 宫位层 | 十二人事宫、宫位地支 | 确定人事领域、场景、环境与时空背景 |
| 宿度层 | 二十八宿、度数 | 细化坐标、气质与根基；参与命度主、身度主的确定 |
| 星体层 | 十一曜 | 提供行动主体、基础性质与作用方式 |
| 修饰层 | 十二长生、神煞、化曜 | 补充阶段、特殊色彩与现实身份功能 |
| 时间层 | 大限、限度、流年等 | 引动原局已有信息，观察何时更易显现 |

## 各元素怎样分工

| 元素 | 应回答的问题 | 使用边界 |
| --- | --- | --- |
| 星曜 | 谁在行动、其基本性质是什么 | 不能脱离宫位、关系与力量直接等同具体事件 |
| 宫位 | 事情发生在哪个领域 | 宫内有星不等于已确定人物、结果或成败 |
| 宿度与度数 | 细落点、禀赋、气质、度主归属 | 不能跳过宫主、交感和星力单独定论 |
| 地支 | 环境、方位、时间性与基础物象 | 应围绕当前太极和宫位主线取象 |
| 十二长生 | 一股力量处于萌发、展开、衰退或收藏的哪一阶段 | 是状态信息，不是独立的吉凶标签 |
| 神煞 | 特殊质感、触发点或少见色彩 | 主线不成立时，不得独立创造一件事 |
| 化曜 | 星曜以何种身份或功能出现 | 须注明采用天官或管库体系，不混作同一证据 |
| 纳音 | 在主线明确后的二级修饰 | 单一地支不能直接推定纳音；先取得完整干支 |
| 八卦 | 形态、方位、结构和辅助人物关系 | 只作补充，不取代宫位、星曜与力量判断 |

## “三主”与“四核心锚点”

“三主”概括命度主、命宫主与身主；其中“身主”由**月亮与身度主**共同承担。天枢 Oracle 为避免把两者混成一个点，仍采用四核心锚点：

| 合称术语 | Oracle 对应 | 重点 |
| --- | --- | --- |
| 命度主 | 命度主 | 命主核心、直接承受与本命主要太极 |
| 命宫主 | 命宫主 | 外界场域、对外呈现与现实承接方式 |
| 身主 | 月亮 + 身度主 | 内在感受、身心承载、成熟能力与深层驱动 |

本命整体沿用本库已确认的四核心定位；进入专题时，仍应按问题另设专题宫、宫主或对象太极，不能把任何一颗星永久当成所有问题的唯一中心。有关昼夜调整关注比重的古法说法，暂不作为自动执行规则。

## 建议的读盘顺序

1. 核对排盘体系、软件设置、出生资料和盘面图例；
2. 先区分原局与限运、流年等时间图层；
3. 从六层识别中心、宫位、宿度、星体、修饰与时间资料；
4. 定位 [四核心锚点](%E5%9B%9B%E6%A0%B8%E5%BF%83%E9%94%9A%E7%82%B9.md)，建立 [交感通道](%E4%BA%A4%E6%84%9F%E9%80%9A%E9%81%93.md) 并判断 [星曜力量模型](%E6%98%9F%E6%9B%9C%E5%8A%9B%E9%87%8F%E6%A8%A1%E5%9E%8B.md)；
5. 按当前问题切换太极，进入 [术数六步推演](../../01-%E6%A0%B8%E5%BF%83%E6%96%B9%E6%B3%95%E8%AE%BA/%E6%9C%AF%E6%95%B0%E5%85%AD%E6%AD%A5%E6%8E%A8%E6%BC%94.md)；
6. 最后才把各层资料翻译成现实语言，并留出验证接口。

## 纳音与八卦的技术边界

七政宫位若要调用纳音，必须先知道该宫的**完整干支**；地支单字不足以确定六十甲子纳音。目前既定恒星制下宫位完整干支的来源与起法，尚待确认；在此之前，只接受排盘软件明确显示且可追溯的完整干支，不由系统补造。

八卦可用于形态、方向及关系补充，但须以当前盘面实际宫位和太极为先，不把固定先天宫位图直接替代客户实际排盘。
