## 太阳

| 类别 | 类象速查 |
| --- | --- |
| 基本信息 | 纯阳光体；主光明、生命力、权威、名誉、公开、中心、秩序。居垣于午，升殿于房、虚、昴、星四日度；昼生、光明、不受云雨之曜遮蔽时较易发挥。夜生、光弱或受蔽时，作用较含蓄。 |
| 性情 | 得力：宽厚、端正、坦率、有担当、有大局观。失衡：自尊过强、好面子、独断、过度在意名声。行为：主持、决定、公开表达和承担责任。 |
| 人物 | 父亲、长辈、领导者、掌权者、上司、贵人、公众人物。 |
| 身体 | 传统对应心脏、眼睛、循环、精力与整体阳气；受损时关注目疾、心血循环、炎热与过劳之象。 |
| 行业 | 政务、管理、公共事务、品牌、公关、传媒、教育、舞台与需要曝光的工作。 |
| 事物 | 太阳、灯光、荣誉、证书、旗帜、中心位置、政府机关、礼堂、舞台、广场。 |
