# 四余｜作用关系与取象补充

> [!warning] 资料定位
> 以下为待核的术语、结构与条件；不把尚未核实的组合当成已确认规则，不将旧式性别偏见、疾病与生死断语用于客户报告。

## 基础对应与象意线索

| 四余 | 条件条目中的性质线索 | 取用限制 |
| --- | --- | --- |
| 紫炁 | 木余；汇编归纳清高、好静、博学与独立取向。 | 不因“清高”断定此人孤独、家庭不和。 |
| 月孛 | 水余；汇编归纳机巧、功利取向及变动性。 | 不因单星断定欺骗、淫乱或违法。 |
| 罗喉 | 火余；汇编归纳刚决、急切与强烈表现。 | 不因单星断定暴力、争斗或伤亲。 |
| 计都 | 可取土曜，亦有隐伏、深虑一类象意。 | 不因单星断定阴险、疾病或不幸。 |

以上只是象意候选词。实际解释须先定太极点与宫度，再看四时、强弱、与七政的作用关系。

## 结构规则：不能只按“吉余／凶余”分类

1. **四余独行与文武分列。** 待核组合包括“四余独旺”“文东武西”及四余不宜混杂的不同格局句；是否有力取决于独行、位置、掌曜与整体结构，不能凡见四余便判坏。
2. **余奴犯主。** 四余与同气本主同躔、占本殿或形成有效作用时，旧说称“余奴犯主”；仍须比较主星与余星力量、是否得令及救应，不作单条件判格。
3. **余奴拒敌。** 余星也可能参与制约攻击本主的难星，从而分担压力。此时先写清难星、本主、余星各自的位置、强弱与交感，再判断是否真能制敌。
   - 与之相反，主星衰弱、同类余星过强或占本殿时，也可能出现**余奴伤主**：分夺、耗泄而非代主承压。冬令水旺的水孛同类又可能相扶，必须复核季节与强弱，不把“余奴＝凶”或“余奴＝扛杀”设为常量。
4. **同象不等于同结果。** 示例列紫炁与木、月孛与水、罗喉与火、计都与土的犯主示例，也列对应的生扶、制约或泄化路径。四时、强弱及宫度不同可改变作用方向，不据“同宫”直接推吉凶或应期。
5. **特定格局需核严条件。** 例如 “太乙抱蟾”例要求月孛与月在未宫同度，非只要“月见孛”即可命名；具体成格条件待条件核验。
6. **限度语境不得越级。** “二杀不攻一”与若干同宿度示例出现在行限、度限语境，暂不自动提升为本命格局通则；若用于本命，须有独立本命规则及实盘证据。

## 四时喜忌的缺口

本节主要是四余象意、七政与四余的关系、格局与限度示例，**没有完整的紫炁、月孛、罗喉、计都逐季喜忌表**。如需四余四时规则，应另行核实条件或明确补充条件；不能从七政四时条目自动推导。

## 客户报告边界

- 保留证据链：本主／余星及太极点 → 生克与气数 → 力量、交感与救应 → 相关宫位 → 条件性结论。
- 对“淫贱”“克夫害子”、疾病、死亡、自伤等古籍绝对断语，仅作史料辨识，不复述为现实事实，也不据此给客户贴道德标签或医学诊断。
