# 单一象

第15章先解决了“看谁、看什么”的问题。太极点定好以后，下一步才是读取围绕它出现的各种符号。

取象要从一个个符号开始，但不能停在一个符号上。本章先把最小单位讲清楚：一颗星、一个宫位、一种化曜或一个神煞，单独能告诉我们什么，又不能告诉我们什么。

## 16.1 什么是单一象

单一象，是指**暂时只读取一个符号本身所提供的信息**。

例如：

- 看到月亮，先想到情绪、身体感受、女性、母亲、照顾、夜晚、液体等基本范围；
- 看到夫妻宫，先知道当前信息落在婚姻、伴侣、合作和一对一关系领域；
- 看到帝旺，先知道某股力量处在充分展开、表现明显的阶段；
- 看到印曜，先想到照顾、保护、凭证、教育、依托和母亲等身份功能。

这一步像查字典。它的任务是先确认“这个字有哪些基本意思”，而不是看见一个字便立刻写出整句话。

> **单一象负责打开信息范围，不负责独立完成现实结论。**

## 16.2 各类单象分别负责什么

前面的元素篇已经逐项列过类象。进入实断时，不必每次把整套词条背一遍，只要先记住每套系统的职责。

| 单象来源 | 主要回答 | 读取重点 |
| --- | --- | --- |
| 阴阳 | 还要看哪一面 | 动静、显隐、快慢、内外及相反相成 |
| 五行 | 这股气怎样运动 | 生发、外放、承载、收敛、流动 |
| 十一曜 | 是谁，是什么性质 | 主体、基本性情、人物、事物与力量方式 |
| 人事宫位 | 发生在哪个领域 | 事业、财富、关系、家庭、迁移等场景 |
| 星宿 | 呈现出什么气质和成色 | 细节、风貌、动作倾向与具体表现 |
| 地支 | 处在什么环境和时空 | 方位、季节、时间、场所及基础物象 |
| 纳音 | 同类之间有什么细微差别 | 质感、形态和宫位的第二层修饰 |
| 八卦 | 外形和结构怎样 | 方位、形态、家庭角色及事物结构 |
| 十二长生 | 处在什么阶段 | 初生、发展、成熟、转弱、归藏与酝酿 |
| 神煞 | 多了什么特殊色彩 | 桃花、文名、贵助、阻隔、风险等提示 |
| 化曜 | 以什么身份发挥作用 | 官、印、财、福等现实角色与功能 |

使用这张表时，要先问一句：“我现在读的是哪一个侧面？”

星曜说的是主体，宫位说的是领域，化曜说的是身份。它们的职责不同，不能互相越位。夫妻宫可以说明关系领域被强调，却不能单凭宫名断定婚姻好坏；桃花可以增加吸引、交往和情感色彩，却不能单凭一个神煞断定一定恋爱；印曜可以说明照顾、凭证或母亲身份，却要结合问题和落点，才知道这次具体取哪一层。

## 16.3 单一象能够确定什么

单一象通常能完成三件事。

### 一、确定大方向

太阳、月亮、木星、火星各有基本性质。看到火星，可以先把范围放在主动、急切、竞争、热力、损伤或执行力上；看到木星，可以先关注成长、教育、贵助、规划与扩展。

这只是方向，不是结果。火星不一定带来冲突，也可以表现为执行迅速、行业重技术或事情需要马上处理。

### 二、确定所属领域

宫位能够把宽泛的类象装进具体的人事场景。官禄宫首先指向事业、职责与社会位置，田宅宫首先指向家庭、居所、长期基础与家产。

但宫位只是舞台。舞台亮了，说明这里有信息，不代表我们已经知道谁上场、演什么、结果怎样。

### 三、提供候选答案

单一象最实用的价值，是建立一个有限的候选范围。

例如当前问母亲，月亮的候选意义就会集中在母亲、照顾者、身体感受和家庭女性上；当前问事业，月亮的候选范围则可能变成公众、女性客户、服务照顾、周期性工作或命主的内在承载。

太极点先做第一次筛选，后续的宫位、躔度、生克与化曜再继续缩小范围。

## 16.4 单一象不能确定什么

单一象通常不能独立确定以下四件事。

### 一、不能单独确定具体人物

月亮可以代表母亲，但也可以代表命主的情绪、女性、公众或液体。没有家庭领域、对象宫主、躔度、化曜或现实问题配合，不能看见月亮便直接说母亲有事。

太阳也是如此。它有父亲、权威、名誉、光明和公开等象意，当前究竟取父亲还是事业声望，要看太极和其他证据。

### 二、不能单独确定吉凶

吉星不等于处处吉，凶星也不等于处处凶。星曜是否得时得地、与太极怎样作用、有没有制化，都会改变结果。

同样，长生、帝旺只说明状态较盛，不自动等于好事；病、墓、绝说明状态受限或转折，也不能脱离所问之事直接判凶。

### 三、不能单独确定事情已经发生

原局出现一个象，说明盘中存在相应的信息基础。它是否形成现实事件，还要看有没有完整结构、力量是否足够，以及限度流年是否引动。

看到桃花，只能说交往、吸引、审美或情感信息受到修饰，不能直接说某年一定恋爱；看到财曜，也不能直接说钱已经到账。

### 四、不能单独确定程度和时间

一个象说“可能是什么”，旺衰多寡才回答“有多强”，运势引动才回答“什么时候更容易显现”。缺少这两层，断语容易只有方向，没有分寸。

## 16.5 三个单象例子

### 例一：只看月亮

月亮的单象可以先列为：母亲、女性、照顾、情绪、身体感受、睡眠、夜晚、液体、公众。

此时最稳妥的记录不是“母亲会发生某事”，而是：

> 月亮相关的人物、身心感受或照顾主题可能被强调；究竟应在哪一层，要继续看当前问题、所落宫位、躔度、同宫星与化曜。

### 例二：只看夫妻宫

夫妻宫的单象是婚姻、伴侣、合作、契约与一对一关系。

它可以告诉我们“事情落在关系场域”，却不能独立说明配偶性格，也不能说明关系一定和谐或冲突。要看配偶对象，需要继续找夫妻宫主；要看相处氛围，再看宫内星；要定好坏，还要看双方怎样作用以及谁强谁弱。

### 例三：只看化曜

同一颗星化为财、印、官、福，出场身份会不同。化财时更接近资源、交易和收入功能，化印时更接近照顾、凭证、依托和教育功能。

但化曜只是角色，不等于结果。财曜受损，可能表现为资源难以落实；财曜得力并与命主连接，才更像真实可用的财富。两套化曜还要分别按天官、管库的体系读取，不能见到相同名称便混成一种用法。

## 16.6 单象记录法

看盘时，可以先用一行表格记录每个重要单象，暂时不急着下结论。

| 记录项 | 要写什么 |
| --- | --- |
| 符号 | 哪颗星、哪个宫、哪种化曜或神煞 |
| 本职 | 它在框架中负责什么 |
| 基本范围 | 与当前问题有关的两至四个候选象 |
| 当前关联 | 它为什么与当前太极有关 |
| 尚缺证据 | 还需要宫位、对象、生克、力量还是时间 |

例如：

| 符号 | 本职 | 基本范围 | 当前关联 | 尚缺证据 |
| --- | --- | --- | --- | --- |
| 月亮 | 主体与性质 | 母亲、女性、情绪、照顾 | 当前问母亲，天然人物象贴近问题 | 家庭领域、躔度、化曜、力量与时间 |

这样记录有一个好处：你会清楚地区分“盘里已经给出的信息”和“自己还在猜的部分”。

## 16.7 使用单一象时的常见错误

| 常见错误 | 问题在哪里 | 修正方法 |
| --- | --- | --- |
| 看到一个象就下结论 | 只有范围，没有关系、力量和时间 | 先写成候选方向，等待其他象补全 |
| 把宫位当人物 | 宫位是领域，不一定是对象本人 | 宫位看场域，宫主看对象，宫内星看进入场域的力量 |
| 按名称望文生义 | “贵人”“桃花”“官”容易被字面带走 | 回到各系统的定义和使用边界 |
| 把象意列得太多 | 候选范围过大，无法判断 | 只保留与当前太极最贴近的两至四项 |
| 把近义词当多条证据 | 同一来源被重复计数 | 同一符号只记一票，换说法不增加权重 |
| 忽略日月特殊规则 | 把太阳、太阴机械套普通五星生克 | 按光体、昼夜、强弱、宫宿和交感另论 |

读懂单一象，就像先认识每个词。下一步要做的，是把这些词按职责放到同一句话里：谁进入了什么领域，以什么身份出现，与谁发生怎样的关系，力量又有多大。第17章进入叠加象，正式把零散符号组成可以落到现实中的画面。
