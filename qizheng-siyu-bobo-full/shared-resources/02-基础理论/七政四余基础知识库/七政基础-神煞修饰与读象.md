# 七政基础：神煞修饰与读象

## 一、这张卡怎样用

本卡是传统象义的检索与表达辅助，不是自动断事、医学诊断或现实事实认定表。沿用已确认的分析规则：先看星曜、旺衰、喜忌、有效交感和人事宫位，最后由神煞补充表现方式。神煞不能另建生克通道，也不能单独决定一个人的性格、品行、婚姻、财富或健康。

调用顺序：

1. 确定本次问题与太极点，完成原局和有关星曜的可用性分析。
2. 找到有关星曜的落宫、掌宫及已确认的交感；先说明谁影响谁、发生在哪个领域。
3. 读取这些位置的本命神煞；分析年度时另列被引动的流年神煞，不能把两层混为一个终身标签。
4. 仅选能与主结构对应的少量标签，解释它补充了什么。同一标记、同一位置的重复称呼不重复计数。
5. 助力与制约并写。吉神不能自动取消实际受克，凶名也不能把原本可用的结构直接判坏。

学习分级不等于吉凶评分、事件概率或证据权重。

### 性格专题的范围

只把命宫主、命度主、月亮、身度主的宿度和有关神煞作为修饰层；同一星兼任多个核心身份，合并证据，不重复加权。命宫先看本宫标记，再看命宫主落宫；月亮看其落宫与所掌未宫；其余核心星曜同样核落宫、掌宫。命宫、相貌宫、福德宫是性格结构的重点，但不能因此跳过星曜本身。

事件专题则按实际参与事件的星曜及其宫位取用，不把整盘标签全部堆进报告。用户只问个人性格时，不自动增加人际、婚恋等专题。

| S09 天德、月德 | 缓和矛盾、善意、回旋余地 | 须能作用到当前问题；不能替代实际救应，也不要求当事人忍受伤害。 |
| S10 天解、地解 | 调解、疏通、解除某项限制 | 先有可解释的阻碍再谈解；不能泛化为一切事情都好。 |

| S13 注受 | 接受照顾、资助或善意支持 | 起法有不同分支，未核清时仅作低优先级修饰，不据此建立主结论。 |

## 四、学习、名望与事业身份

本节包含神煞和化曜身份。名称相近不代表同一算法；使用排盘已给出的身份，不自行套用八字十神来重算。

| 编号与标签 | 可补充的象义 | 需要结合的条件与界限 |
| --- | --- | --- |
| S14 文昌 | 学习、文字、语言、知识整理 | 与核心星曜及相关领域相接才采用；不能据此认定学历、智商或考试结果。 |
| S15 文星 | 才气、表达与作品的呈现 | 核承载星是否有力、有发挥渠道；与文昌分开记录。 |
| S16 魁星 | 专项能力、被选拔、获得注意 | 核相关主星、舞台与评价机制；不是固定第一名或成功保证。 |
| S17 科名 | 声望、名声、专业认可 | 不等于学历；须说明因什么本领、在哪个领域获得认可。 |
| S18 科甲 | 学习成果、考核、资格与凭证 | 限运和实际准备另核，不将一个标签等同录取或通过。 |
| S19 天经、地纬 | 条理、组织、规划、知识结构 | 两项保留各自身份；资料中的特殊相忌未经条件核验，不另立绝对规则。 |
| S20 国印 | 制度、职责、职位与认可 | 与官禄、天官及实际承接合看；责任增加可能同时带来压力。 |
| S21 印星 | 授权、实权、能调动的资源 | 七政身份，不自动等同八字印星；职位与实际权限分开说。 |
| S22 官星、天官 | 任职、职业发展与承担任务 | 必须转入现行天官／事业分析流程，本卡不替代其分析顺序。 |
| S23 催官 | 举荐、推进、调任与任职变化 | 核被推动的是什么职位或任务；不直接许诺晋升。 |
| S24 职元 | 自身能力方向、岗位竞争力 | 区分本人本领和外部支持；看承载星旺衰、落宫与掌宫。 |
| S25 局主 | 协作范围、圈层资源、影响广度 | 不把圈子大等同能力强；能否调用资源仍依实际关系。 |
| S26 卦气 | 起步环境、原生培育和资源土壤 | 起法涉及出生时刻，标注不可靠时保留待核；不能据此断真实家境。 |
| S27 斗杓（资料亦作斗标） | 受重视、被推举、方向与职位象 | 名称和定位先核；没有此标记不等于不被尊重。 |
| S28 禄勋 | 福利、待遇、依托与既有资源 | 与禄神、禄元分别记录；是否稳定由有关星曜力量与耗损决定。 |
| S29 禄神 | 薪酬、工资或稳定收入的象 | 必须连到工作和财源，“正财”的象义描述不等于年干财曜身份。 |
| S30 禄元 | 资源与收入的承载星 | 自用资料按禄勋所在宫的宫主定位；没有已确认起法或原盘身份时不猜。 |
| S31 驿马、天马、地驿、马元 | 流动、异地、多场景、变动中的机会 | 分清神煞位置和马元星身份；有马不一定迁居、出国或获利，喜忌与受克同时看。 |
| S32 四元星 | 仁元、寿元、禄元、马元的身份组 | 四项不互换；仁元不等于人元。寿元只保留传统身份，不推算寿命。 |

## 六、冲突、损耗与身心风险修饰

下面的“风险”是传统取象栏目，不是概率计算。身心健康必须交给健康模块综合现实反馈；神煞不支持疾病、受伤、精神障碍或寿命诊断。

| 编号与标签 | 可补充的象义 | 需要结合的条件与界限 |
| --- | --- | --- |
| S40 卷舌 | 立场鲜明、争辩、沟通摩擦 | 先有冲突或表达结构，再说明发生场景；不直接认定此人好斗。 |
| S41 贯索、绞杀、官符 | 牵制、手续、规则、合同与纠纷 | 官非纳入事业财运；必须有实际结构和现实背景，不指控违法。 |
| S42 阳刃、阴刃、飞刃 | 锐利、果断、竞争、工具及急切表达 | 三者不替换起法；受制、限运和现实暴露条件齐备时才作风险提醒，不断必有手术或事故。 |
| S43 劫杀／劫煞 | 外来干扰、资源争夺、突然变化 | 保留原标注；核谁受影响、有无救应，不按字面解释成犯罪或抢劫。 |
| S44 飞廉 | 快速、猛烈、变动与执行 | 对谁有利、谁承受压力由星曜关系决定；不能只因名称就判凶。 |
| S45 亡神 | 遗漏、隐性损耗、事务失序 | 核具体领域，不转写为精神失常、死亡或家人遭遇。 |
| S46 大耗、小耗、天耗、地耗 | 资源外流、支出、周转与消耗 | 各自保留，不一概叫破财；主动投入和被动损失要区分。 |
| S47 岁破 | 原有安排受到冲击、计划重组 | 明确年度和作用对象，不泛化成终身命格。 |
| S48 病符、天厄 | 功能受限、需要照料或修整的象 | 先确认全盘受伤及疾厄关联；也可能指事务困难，不能仅据此断病。 |
| S49 血刃、血支、血忌 | 与器械、损伤、身体议题相关的传统标签 | 必须有健康结构支持；保留三项身份差别，不预测流血或疾病。 |
| S50 剑锋、伏尸、天雄、地雌 | 强烈干扰、锐利或停滞的传统风险色彩 | 不沿用原稿的寿夭、死丧断语；未确认具体用法时只留内部待核。 |
| S51 浮沉 | 波动、反复、状态不稳 | 宫位与对象决定取象；不得由此预测溺水、交通事故等具体伤害。 |
| S52 天哭、披头、丧门、吊客、天狗 | 情绪负担、照顾责任、分离或突发扰动的象 | 有现实背景才具体化，不能断丧亲、克亲或心理疾病。 |
| S53 值难 | 某类挑战的集中标记 | 回查承载星、相对太极与作用时段；不能把“值难”与命度主难星自动等同。 |
| S54 产星 | 生产、孕育相关的专门身份 | 只在相应专题核实含义；不是自动凶煞，也不能用于生育能力判断。 |

## 七、容易混淆的身份与数据边界

- 科名不等于科甲；文星不等于文昌。可以相互支持，不能凭字面合并。
- 禄勋、禄神、禄元是三个字段；驿马位置与马元星也不是同一个字段。
- 天官、官星、催官、印星、职元、局主、卦气各有职责；按既有专题定义继承，不能以一个“贵”字统包。
- 神煞空亡与天空不互代；落空可能表示未落实，不等于该领域永久不存在。
- 年干化曜、命度主恩难关系、神煞身份分别存放。同一颗星可以同时有这些身份，但彼此不能互相改名。
- 疑字、起法不全、同名异义条目不擅自补算法；本卡是读象速查，不是完整神煞起法表。

## 八、落到报告的写法

每个标签只回答一个补充问题：它让前面的结构“以什么方式表现”？写成“主结构结论＋相关生活领域＋一项修饰＋主要条件”，不用堆名词。

例如，已经有表达与知识工作依据时，文昌可补成“适合把复杂信息整理成清晰的说明”；已有关系冲突依据时，卷舌可补成“分歧容易集中在措辞和立场上，先确认需求再讨论对错”。以上为写法示意，不是任何人的既成事实。

正向表达可以肯定优势，但不能抹去成本；风险应温和、具体地说明可观察事项，不以恐吓推动决策。格局雅称另见 [七政基础-格局命名与条件](%E4%B8%83%E6%94%BF%E5%9F%BA%E7%A1%80-%E6%A0%BC%E5%B1%80%E5%91%BD%E5%90%8D%E4%B8%8E%E6%9D%A1%E4%BB%B6.md)。

## 九、内部最小记录

| 字段 | 要记录的内容 |
| --- | --- |
| 神煞／身份原名 | 原盘写法，必要时记录别名但不擅自合并 |
| 层次与位置 | 本命或流年、所在宫、依附星曜、是否已确认起法 |
| 主结构 | 被修饰的星曜关系、旺衰、喜忌和人事领域 |
| 采用理由 | 此标签具体增加了什么信息 |
| 制约与替代解释 | 不成立条件、现实反馈及其他可能 |
| 表达状态 | 客户可用／内部待核／不采用 |

本卡是读象辅助资料，不包含客户命盘、反馈或完整原稿；未明确起法的字段按盘面原标记保留，不自行补算。
