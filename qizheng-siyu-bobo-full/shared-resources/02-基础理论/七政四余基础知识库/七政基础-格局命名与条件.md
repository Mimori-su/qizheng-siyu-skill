# 七政基础：格局命名与条件

## 一、先有结论，再配名称

格名用于说明已经成立的作用结构，增加报告的辨识度与文采；不负责重新裁决原局喜忌。已确认断法、条件化四时、实际旺衰、有效交感和用神可用性优先。

先确认“命主需要什么、哪些星真正能帮忙、帮助从哪里来、命主能否承接、有什么成本”，再查本卡。旺星不一定好用，好听的名称也不等于高层次；格名不能独断财富、官职、疾病、婚变或寿命。

统一核验：

> 原局结论 → 名称及条件分支 → 本命／行限范围 → 时令、昼夜、月相 → 宫位、宿度、前后与距离 → 主用身份和实际交感 → 力量、受伤、救应与承接 → 成立状态 → 人事翻译。

本卡是候选条件索引，**不是单条件触发器**。下面每条都须通过这条核验链。三方四正按本宫、对宫、三合宫；“夹、辅、拱、朝、前后”等另按已确认的各自定义，不因表中并写而视作同义。没有交感的星，不可为了拼格局就建立直接生克。

### 成立状态

| 状态 | 处理 |
| --- | --- |
| 成立 | 分支条件完整，实际力量与原局作用相符，客户可使用名称并解释。 |
| 有形但受限 | 形态存在，但有受制、力量不足或承接限制；如使用名称，必须同段说明限制。 |
| 仅见单项条件 | 只作内部线索，不以该格统论全盘。 |
| 不成立 | 记录不符条件，不进入客户正文。 |
| 待确认 | 缺关键资料、同名异义或条文矛盾；不自动调用。 |

同一结构的多个雅名，只是一份证据。一般每份报告选择一至两个最贴切的名称；没有合适名称时直接说明结构即可。以下“可用表达”只是翻译方向，仍需落宫、掌宫、宿度及化曜确定具体领域。

## 二、日月与光明结构

| 编号与格名 | 形态与适用条件 | 必核限制／可用表达方向 |
| --- | --- | --- |
| G01 日月居垣 | 日在午、月在未，各居本垣 | 昼夜、月相、遮蔽及有效联系仍核；表达为两类支持各有落脚点，不承诺贵位。 |
| G02 日月升殿 | 日躔星、虚、房、昴；月躔张、危、毕、心，各入自身宿度 | 只一颗满足时只说该星升殿；升殿不代替全盘力量评估。 |
| G03 日东月西 | 日在寅卯辰一侧，月在申酉戌一侧 | 先核实际方位与出生条件；形态完整后说明日月各有发挥位置。 |
| G04 日南月北 | 日在巳午未，月在亥子丑 | 不能仅看位置就忽略冬寒、月暗或受掩；与 G05 重叠时不重复算格。 |
| G05 阴阳得地 | 日、月分别处于适用的明暗与方位条件，资料以日东南、月西北为一支 | 采用的方位口径须一致；日月各有支持不等于本人主观能动性很强。 |
| G06 日月包五星 | 五星在日月两端之间形成实际包围形态 | 必须核宫度序列，不能用星数替代；结构是否可用另看五星关系。 |
| G07 日月包四余 | 四余处于日月两端之间 | 同样核序列、罗计关系及受制；不把四余一律作吉。 |
| G08 日月夹／拱身命及人事宫 | 日月对明确的身命、田财、官福、妻嗣等目标形成相应夹或拱 | 目标、夹拱方式、受益人必须写清；只说明有关领域获得日月支持的条件。 |
| G09 孤月独明 | 太阴独居、月有光，重点核夜生；日期条件为“初八以后、二十三以前” | 日期边界保持该条件，不擅自扩展；冬月不照搬孤清为美，须另看暖气。独居不等于三方完全无星，不同强度条件分开。不得许诺健康或寿命。 |
| G10 一星伴月 | 月旁以单金相伴为此处索引分支，夜生更需核月光 | “一吉星相伴”是 G09 的另一条件分支，不能泛化任意星皆好；冬寒与遮光另论。 |
| G11 水涵蟾魄 | 水月相会，望前望后且月有光的分支 | 核冬寒、水是否过量及双方受伤；表达为清润与感受的配合，不由名字许诺关系圆满。 |
| G12 金助月华 | 金月相会，以秋夜且金可用为主要分支 | 昼生、冬月及金受制另核；不能把所有金月同宫判成同等助力。 |
| G13 木月清贵／木月双清 | 木月相会，夜生有月光；有弦望分支及二三四月分支 | 按所选分支核月份，不拼成全年通则；木炁是否清云、是否增寒仍看原局。 |
| G14 火月交辉／火月同宵 | 火月相会；晦朔夜生与有光夜月的资料分支不同 | 先看月相和火量；满月、过燥或争光时不可只取雅名。 |
| G15 祥云捧月 | 炁月相会，以有光夜月为前提；另有未命、初八至十五及前后三度的严格分支 | 各分支不混用；三度前后条文存在方向冲突，未核前不作精确算法；冬月温度须另核。 |
| G16 太乙抱蟾 | 孛与月的相会名称，正向分支重夜生、月光及特定落宫 | 同名有相反条文。须说明采用分支，核寒暖与土计；不能因孛月同宫直接认定成立。 |

## 三、五星与生克制化结构

| 编号与格名 | 形态与适用条件 | 必核限制／可用表达方向 |
| --- | --- | --- |
| G17 五星居垣 | 木寅亥、火卯戌、土子丑、金辰酉、水巳申，各归其垣 | 必须逐星满足；入垣是得地，不自动表示所有星对命主都有利。 |
| G18 五星升殿 | 木角斗奎井、火尾室觜翼、土女胃柳氐、金亢牛娄鬼、水箕壁参轸 | 逐星核宿度；不得把受生宿当本气升殿。 |
| G19 木火文明 | 木火形成实际相生，所用条目以同宫为候选 | 核时令、强弱和双方身份；冬春与夏热不可同论。可表达知识、创作或行动彼此促进。 |
| G20 火土高强 | 火土相会且相生可用 | 夏燥、土焦及火过强时保留代价；不把“有生”直接当舒服或幸福。 |
| G21 土金坚实 | 土金相会并有有效支持 | 土埋金、秋金是否需要再生等按四时分支复核；不能把星间相生与人事结果画等号。 |
| G22 金水相涵／金白水清 | 金水相会，金有力、水可泄秀或润泽；金白水清重点核秋金分支 | 冬令金寒水冷、泄金过度或水伤所需之火时不用此名掩盖问题。 |
| G23 五星循环 | 木火土金水形成有序相生的实际结构 | 有五颗星不等于五段链成立；逐段核通道和强弱，不借名称跨宫建立不存在的联系。 |
| G24 五星聚会 | 五星聚集于相同宫度范围的候选形态 | 先有精确范围再用；聚集也会交战或拥挤，不自动翻译成财富与地位。 |
| G25 子母重逢 | 命主与恩星有实际相会，且得时得位、资源可达 | 恩星也可能气数不喜；同时写支持、体感与成本，不保证家庭状况。 |
| G26 恩化难／化难生恩 | 难星、生恩星、恩星扶命度主构成可行链 | 三方都要有力且有通道；“难星存在＋恩星存在”尚不足成链。 |
| G27 余奴扛杀／余奴敌杀 | 难星原本施压，余奴确实参与承受或分流 | 不因同类星出现就认定救主；分担压力与分夺资源可以同时存在。 |
| G28 恩星照命 | 恩星进入命宫或命度主有关通道并能发挥 | 交感、强弱与命主承接必须补齐；按落宫、掌宫说明资源来源。 |
| G29 子来救母／一将当关 | 资料以土计制水、保护受水所制的火为主要示例 | 先确认水确为当前问题、土计能制且不另伤关键星；不得把全部土计都作救应。 |
| G30 精神转运 | 冬火弱、水为患，木能承水并续生火 | 必须核水木火实际链路，不能跳过木的受伤与力量；名称不作心理健康诊断。 |
| G31 上生下润 | 土的相关日照结构与水孛润泽同时可用 | 不是一见水就吉；土能否承水、日的作用、寒暖与星体交战分别核。 |
| G32 炼金成器／金罗相会 | 金得适量火罗温炼；春金与秋冬金各有条件分支 | 火罗仍可能克金；有利的调候和压力并存，受伤过重时不得借成器掩盖。 |
| G33 寒谷回春 | 冬木得火罗，或冬火得木炁，冷暖调整有效 | 回到原局判断火木是否好用；冬日喜暖仍可能伴随争光。 |
| G34 水火相济 | 夏令旺火遇可用水，强弱适中且有真实联系 | 宫内交战的不顺不因调候有用而消失；帮助与伤耗必须并列。 |

## 四、禄马、名望与发展形态

| 编号与格名 | 形态与适用条件 | 必核限制／可用表达方向 |
| --- | --- | --- |
| G35 金水从阳／金水朝阳 | 金水与太阳形成所选分支要求的随、朝或辅；金水有相应吉用身份 | 核昼夜、位置、实际作用及受制；同宫只是候选，不能直接许诺权位。 |
| G36 火金侍月 | 火金与月形成侍从关系，夜生且相关星可用 | 火会不会争光、金会不会受火伤，分别核；强星不必然是好助手。 |
| G37 向阳花木／日边红杏 | 木与日有实际关系，且木为命、官、恩等有关用星 | 孟春、冬昼及其他季节的条文分开；木旺蔽日时须保留竞争和遮蔽成本。 |
| G38 月中仙桂 | 木躔四月宿，或秋令木月相会的不同分支 | 依具体分支核月光与木的用途；不混同 G13，不许诺早年成名。 |
| G39 桃花浪暖 | 木水会命，奎度分支尤重木得生的结构 | 不与“桃花滚浪”的水火互入条文混名；冷水、受伤与通道另核。 |
| G40 禄马同乡 | 已定位禄元、马元同处强而可用的位置，并能照身命 | 两个标签不等于已经获得利益；说明收入与移动、业务或资源流转的关联。 |
| G41 禄马朝元 | 禄马或其承载星对身命形成实际夹拱朝向 | 先核各自起法与作用位置；不能仅看到禄马字样便谈远方发财。 |
| G42 金马嘶风 | 马元会身命，且资料规定的辰巳行限条件成立 | 属行限相关索引，不移成本命定终身；实际机会与代价仍看限主和原局。 |
| G43 马头带剑 | 马元与刃宫或刃星形成实际关系 | 可修饰执行、竞争和奔走；不能据此断军事职业、事故或掌权。 |
| G44 北海挑灯 | 夜火为当前可用星，落亥 | 未经“可用”筛选的火不套此名；表达为在需要开拓或照明的环境中发挥作用。 |
| G45 南枝向暖 | 冬木为用，居午或得有效太阳温助 | 不能用“木生火”机械解释全部得益；环境温助与自身消耗都核。 |
| G46 江汉秋阳 | 秋令水与日同行且双方适用 | 核水量、日光及喜忌；以清明、表达和资源配合取象，具体行业另由宫曜宿煞综合。 |
| G47 元武当台 | 巳宫立命，水躔轸，兼得适用金助为另一加力条件 | 入垣升殿只说明水有基础；水是否是原局可用力量、金是否真的有通道另核。 |
| G48 一福专权／一星满用 | 前者重福元在垣并独守福位；后者重单星守命、强而兼有可用身份 | 两名分别定位，不混成“一颗星旺就好”；兼任角色不重复加权。 |
| G49 中流砥柱 | 其他力量受限，仍有一颗真实可用之星能够支撑关键结构 | 要证明其承接与解决问题的作用；不是泛泛赞美“很强”。 |

## 五、群星、四余与位置形态

用户已确认的群星格局要求须检查罗计关拦；不要只排出漂亮的图形就判成格。关拦、漏出、前后次序不清时，保留候选即可。

| 编号与格名 | 形态与适用条件 | 必核限制／可用表达方向 |
| --- | --- | --- |
| G50 罗计中分／文武两班 | 前者有罗午计子分支；后者有七政与四余分处两侧的分支 | 不能把任何罗计相对都称中分成格；核实际分布、关拦及日月官福的状态。 |
| G51 出乾入巽 | 罗亥、计巳的候选位置组合 | 须加核命身关联和四余实际作用；位置符合不改变难星、余奴或气数身份。 |
| G52 四余独步 | 四余分处而不与七政混处的条件分支 | 全盘分布逐一核验；不能从“独步”推成不受任何影响。 |
| G53 一星跳垣 | 罗计截星结构中，一颗相关星漏出边界 | 先确认被截群体及漏出星；漏吉漏忌作用不同，不把任何孤星叫跳垣。 |
| G54 金计同垣 | 金与计同宫，金为所用、环境可承接的分支 | 土金生助不保证没有埋金等成本；原条文有关计克金的说法待核，不纳入生克表。 |
| G55 土罗相会 | 土为所用，与罗同会且力量条件适合 | 罗能助土也可能增燥，夏秋不能只写有恩无代价。 |
| G56 五曜环阳／四余捧月 | 五曜对日、四余对月形成原条文规定的环拱分布 | 核昼夜、南北方位、次序及关拦；不得用“五曜／四余都在盘内”替代构形。 |
| G57 五曜连珠 | 五星在连续宫位或顺度形成连续次序的分支 | 宫序与度序分开，是否允许间断不能自行放宽；作用链还须逐段核。 |
| G58 众曜拱南／群星朝北 | 群星分别集中巳午未或亥子丑，命宫与所取方向有关 | 核具体集中范围和关拦；群星的可用性、承接和内部冲突仍决定评价。 |
| G59 日月合璧／二星合璧 | 严格分支：日虚月危、日星月张、日房月心、日昴月毕，各升殿且相邻相近 | 另一分支用同宫／对照／三合定义，不能混用；距离未核时记待确认，不自动成立。 |
| G60 水火既济 | 有水子火午的分居分支；亦有水先、火后、同宫照命的前后分支 | 两分支分别记录；无可靠顺逆、宫度前后数据时不调用。调候有益不抹去交战。 |

## 六、需单列而不能自动消解的条件分歧

| 项目 | 处理要求 |
| --- | --- |
| 孤月独明与一星伴月 | 独居、无众星环绕、三方清静、一吉星相伴是不同条件强度；不能把任一条件替代全部条件。冬月与夜生月光另核。 |
| 祥云捧月的前后三度 | 前后三度的定义存在不同描述；不据此写死经度算法。 |
| 太乙抱蟾 | 同名兼有月孛相会的正负解释，须保留月相、昼夜、寒暖、落宫、所用身份等分支，不一律吉也不一律凶。 |
| 金骑人马 | 资料既有单论金入寅的限制，也有命度、太岁、福德主等成立条件；寅在本体系属木，不继承资料中“寅为火宫”的解释。未核分支前不使用。 |
| 日月失垣、失殿 | 没有获得一项加力，不等于受伤；只作力量字段，不反推疾病、贫困或家人遭遇。 |
| 日月合璧、水火既济、君臣庆会 | 同名不同构形分别存档，不能拼接宽松条件；缺具体分支就不点名。 |
| 寒暖与生克同时存在 | 冬日得火罗之暖仍可能争光，夏土得火之生仍可能燥热；一项好处不删除另一项代价。 |
| 原局与行限条文 | 需要限宫、度限或流年才能成立的，只用于相应时段，不直接写成终身本命。 |
| 缺字、疑字和古义未明 | 保留待核，不按常识猜星名、方向、方位、阴阳度或吉凶。 |

## 七、客户表达与内部留档

客户版先给简明结论和客观长处，再细分事业角色、财富结构、外援及代价。格名只放在已解释清楚的优点旁边，如“这份支持可用‘子母重逢’来概括：资源有渠道接到本人，但能发挥多少仍要看……”。不把比喻当作既成社会成就，不连续罗列雅名。

负向格名不用于贬低客户；真实存在的限制仍要说清楚，不能改说成好事。身心健康、婚恋等高风险内容不能借格名作诊断或指控。神煞修饰规则见 [七政基础-神煞修饰与读象](%E4%B8%83%E6%94%BF%E5%9F%BA%E7%A1%80-%E7%A5%9E%E7%85%9E%E4%BF%AE%E9%A5%B0%E4%B8%8E%E8%AF%BB%E8%B1%A1.md)。

内部至少保留：格名编号、条件分支、本命／行限、时令昼夜月相、宫度位置、身份与通道、力量及受制救应、命主承接、成立状态、采用或不采用的原因。只保留简明证据链，不要求输出隐含思维过程。
