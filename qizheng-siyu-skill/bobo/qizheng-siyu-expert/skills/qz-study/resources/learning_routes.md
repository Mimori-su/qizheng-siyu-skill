# 学习路线

## 入门路线

1. 重要概念：掌握太极、体用、喜忌、气数。
2. 星盘组成：认识七政四余、二十八宿、十二宫。
3. 干支五行：建立四时和旺相休囚基础。
4. 看盘流程：学习尽三、余奴相犯、看盘起手式。
5. 运势与基本喜忌：区分原局结构和阶段引动。

## 专题路线

- 感情：太极转换、关系宫位、桃花与合盘。
- 财运：财源、取得方式、支配与留存。
- 健康：疾病取象与身心功能，遵守非医学诊断边界。
- 官非：组织责任、合同争议与财务纠纷，分别接事业和财运。
- 子女：生育取象、子女及亲子关系。
- 择日：事项定位与候选日期比较。
- 生时校正：候选盘比较与真实事件核验。
