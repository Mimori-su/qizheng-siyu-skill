# 校时报告规则

## 报告结构

- 核心结论先行：哪个候选目前更吻合，或哪些候选仍无法区分；不强制排序，不报分数或百分比。
- 候选资料与关键差异表：时间、数据来源、命身宫度变化、相关事件结构；仅列有区分价值的内容。
- 逐事件对照表：同一事件逐一对应所有候选，列支持、矛盾、待核；没有真实事件时先给候选分析差异，不假造已验证经历。
- 下一步核对：给最能区分候选的一至三个具体问题；不反复索取泛泛“更多事件”。
- 文风按 `../../qz-report/resources/report_style.md`，客户正文直白简洁，内部另列来源和条件。

## 候选核对清单

已有真实事件时，对每个候选分别列出支持、冲突和无法判断的事件；没有事件时只列候选差异，不虚构经历。两种方式均说明数据缺口和最有区分价值的下一步核对事项，不把“事件清单”作为开展候选分析的前置门槛。

## 禁止写法

- “这个时辰百分百正确。”
- “凭这一个事件就能定时。”
- “用户记忆一定错。”
- “为了贴合盘面，强行改事件时间。”
