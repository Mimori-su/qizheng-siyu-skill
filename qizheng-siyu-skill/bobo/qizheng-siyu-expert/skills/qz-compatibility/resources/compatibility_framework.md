# 通用合盘分析框架

依据已确认的合盘教学组织分析步骤；示意例不是客户案例，也不是实盘验证。未确认机制放在文末，不以常见占星规则补写。

## 一、先各论原局，再看相互作用

双方分别保留：出生条件、命度主、命宫与宫主、月亮、身度主、气数喜忌、恩难仇用与余奴、十一曜力量及救应、所问专题的原局倾向。

原局回答“此人本来需要什么、擅长什么、哪里有压力”；合盘回答“此人的星进入对方的哪些领域，怎样作用于对方”。对方的补充不等于改写原局，也不等于永久拥有对方资源。

原局中未交感的星，不因两人认识就自动形成任意作用。必须写清跨盘通道；只有限运建立的临时作用另记起止与引动条件。

## 二、坐标与方向

统一使用盘面地支坐标：A 子对 B 子，A 丑对 B 丑，以此类推。人事宫名由接收盘解释，不把 A 夫妻宫直接贴到 B 夫妻宫。

每一条证据记录为：

`方向 → 来源星与地支 → 接收盘锚点/作用对象 → 通道 → 接收宫位领域 → 作用与体感`

例如 B 火在卯，A 卯为官禄，则是 B 火进入 A 官禄领域；若 B 卯为财帛，其财帛身份仅说明来源盘的资源背景，不能把 A 官禄改称财帛。再反查 A→B，不从前一方向推定互惠。

本宫／对宫／两个三合宫依既有地支规则：子午、丑未、寅申、卯酉、辰戌、巳亥对照；申子辰、亥卯未、寅午戌、巳酉丑为三合。以申为中心检查申、寅、子、辰。这里不另加九十度四正。

宫位重叠与精确相位分开：同宫不自动记为零度“守”，对宫不自动记为精确一百八十度“照”。原盘提供的本命相位不能抄成跨盘相位；无度数/容许度规则不自行生成跨盘角度断语。

## 三、通用四核心扫描

固定先看命度主、命宫、月亮、身度主；命宫主补充外在承接与表现，不替换命宫这一空间入口。

| 入口 | 主要回答 | 检查方式 |
|---|---|---|
| 命度主 | 对方触及本人的哪些核心追求与事件，怎样帮助或施压 | 看本人命度主落宫处的对方星；并把对方命度主落入接收盘，检查该宫本对三合的人事领域与实际星曜作用 |
| 命宫 | 对方怎样进入本人的生活环境、社会呈现与外部承接 | 命宫本宫优先核对，再查对宫、两个三合宫；补看命宫主落点与有效作用 |
| 月亮 | 相处后的情绪、安全感、被照顾与温暖感 | 看月亮落点及通道遇见的对方星，也记录对方月亮落入接收盘何宫 |
| 身度主 | 深层感受、承受与实际发挥得到何种支持或约束 | 检查身度主落点、原有压力及对方星是否生扶、制难或增加负担 |

同一星兼任多个锚点，只记录一次星体力量，分别说明对应主题；同一路作用从几个入口被看见，不计作几份独立证据。

## 四、三种作用路径

### 1. 直接作用

先定接收方命度主及喜忌，再判断来源星的生克、同类、气候与本义。专题另定对象太极时须标清：对命主的关系，与对月亮/身度主/宫主的关系可以不同。

“属于难星/恩星”只是关系分类，不等于已经有效克到/生到命度主；必须另核命度主落点与通道。仅进入某个人事宫时，先说明该领域的影响，不跨越通道下身命受伤或得助的结论。

- 恩星生命度主：支持、照顾与资源供给的倾向。
- 难星克命度主：管理、要求、约束与压力；看强弱、救应及气数喜忌。
- 用星受命度主所生：本人愿意投入、关心或给情绪价值的倾向。
- 仇星受命度主所克：本人容易管理、调整或要求对方。
- 同曜/同类：相似性先描述；竞争、分利或余奴作用须有相应定位与作用依据，不能把同星直接断为小人或第三者。
- 命度主为日月：不套普通五行关系，按当前条件化四时、昼夜、月相和明暗规则；太阳温暖与争光、月亮照顾与遮蔽等也要查条件。

这些是关系倾向，不是对现实对象动机的读心。对方是否主动帮助、是否有权限与是否兑现，另用真实反馈确认。

### 2. 帮本人解决原局问题

先定位“本人原有何问题”，再核对“对方什么星沿何通道作用于问题星”，最后看是否缓解核心或专题压力。

`A 原局问题星 → B 星与它的有效制/化关系 → 双方力量与代价 → A 哪一锚点/领域因此获益`

例如 A 的辰或酉位置有木炁为忌，B 相应位置有金，是制木炁的候选帮助；仍要看金是否有力、木炁是否确为本次问题、是否同时伤到 A 其他重要星。不能写成“见金全盘转吉”。

再如 A 午宫有身度主且受难星作用，B 午宫的星能制难，才有“减轻内在负担”的依据；有星相会不等于已制难。

### 3. 同时帮助与消耗

单列实际帮助、主观体感、责任/分利/受管束成本。气数喜而为难星，可出现愿意靠近、愿意求助而同时有压力；气数忌而为恩星，可实际受益但不喜欢帮助方式。不可互相抵销成单一“合/不合”。

已确认的示意规则：

- B 太阳进入 A 月亮或身度主所在宫，是温暖、照亮和正向感受的候选线索，继续核太阳力量与其他交感。
- A 卯为官禄且气数喜火，B 卯有火罗，可形成 A 乐于寻求 B 工作帮助的倾向，同时检查其难星/争光等代价。
- A 子为命宫或命度主所在且气数忌水，B 子有水，可构成相处不舒服的线索；是否仍有资源收益须另看，不据此直接否定整段关系。

## 五、力量：来源基础与接收效果分栏

来源星的力量按其本人原局先确定，继承 qz-wangshuai：季节、昼夜、月相（日月适用）、垣殿、落宫与躔度生扶克泄、出生地支填实、原局实际交感与制化。来助、来克与救应星亦同。不得用 A 的出生月令重算 B 的先天旺衰，也不得拿 A 的四柱给 B 原局填实。

进入接收盘后另问：

1. 是否接触正确锚点/专题对象，通道是否成立？
2. 接收方是否需要这股力量，是气数喜、忌还是有利有弊？
3. 来源星与被帮助/被制约对象力量相比，够不够发挥作用？
4. 是否有接续帮助、牵制或同时产生的新成本？
5. 此作用涉及的现实资源，本人是否拥有、能调用、愿投入、已兑现？四者分开。

用“有力而受限、支持有限但有效、需现实条件承接”等质性语言，不给双方力量固定比例、不用星数多少直接比输赢。跨盘对方原局的一整条关系网不会无条件搬来；每一环都核位置与作用。

## 六、从作用翻译到人事

先判断生克与气数，再结合：星曜性质、接收落宫、双方各自掌宫（分开标注）、来源盘原有化曜身份、躔宿、相关神煞。

宫主主要定位人与关系；宫内和本对三合星描述领域氛围、活动与事件。实际 B 的性格/本领优先从 B 自己原局读取，A 的对象星只描述 A 的需求与关系视角，不能覆盖 B 本人。

来源盘化曜身份不直接变成接收盘同身份；若要另起跨盘化曜映射，须有已确认起法，否则保留来源身份和接收方恩难关系分别读象。宿度、神煞最后修饰，不凭单个标签裁决相处结果。

## 七、时间与证据

需要时间分析时读 `../../qz-core/resources/original_vs_transit.md`，双方分别按原局 → 宫限 → 度限 → 小限与飞限 → 太岁本对三合 → 流年天干化曜 → 顶星 → 流年星，再比较阶段需求与实际交往条件。两人同年各有变化，不自动等于恋爱、结婚、签约或分手。

内部每项结论保留支持因素、制约因素、现实反馈与未核条件；无反馈不标“已验证”。资料冲突先隔离，不混合不同出生版本。

## 八、暂不自动启用

- 跨盘同七曜属性宿度是否及如何独立成通道；当前只在各自原局复核中继承既有同宿规则。
- 跨盘精确角度的容许度、角度权重、不同通道固定倍率。
- 父母子女、师生、客户服务等新增角色的完整定位与优先级。
- 星曜强弱换算现实职位、身家、婚姻成功率或忠诚度。

不因这些局部未教完而暂停已明确的本对三合叠盘；按已知范围报告即可。
