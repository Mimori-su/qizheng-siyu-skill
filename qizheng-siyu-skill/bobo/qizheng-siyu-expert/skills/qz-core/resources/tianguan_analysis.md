# 天官分析顺序

本模块区分已确认规则与待核条件；现代事件用语用于解释实际作用。

适用于本命格局、天官喜忌、从政与任职机会及流年事件；采用已确认的两层读法、变五行和分析顺序。

## 一、总原则

**先完成原局体系分析，再叠加天官之象。天官采用变五行读法：确定交感星曜后，直接按化曜身份之间的关系读象，不以星曜本体五行的生克关系作为读象的成立门槛。**

同一组星曜可以同时存在两种关系：

| 分析层 | 看什么 | 作用 |
| --- | --- | --- |
| 星体本象层 | 星曜本体五行、生克、喜忌、力量，以及原局和限运结构 | 读取本体生克之象，说明相关助力、制约、作用方式和代价 |
| 天官变五行层 | 交感星曜的化曜身份及其相生、相克关系 | 说明人物、事件和事情之间的联系，例如靠表达、技艺挣钱 |

**本体相克与化曜相生可以同时成立。分别读完后叠加，不用其中一层否定另一层，也不把两层相抵成一个笼统的吉凶。**

**天官也用于本命格局判断。**除读取事件之象，还要依据用户提供的天官论法，判断天官喜欢什么、不喜欢什么，与命主是否有情，以及有没有从政、取得职位和社会认可的机会。化曜关系可以直接读象；从政机会和显达程度，则结合命主基础、整体格局、天官得地、交感及喜忌综合判断。

本命格局的成格条件不作为化曜事件读象的前置门槛。“好用／不好用”的复核决定能否推荐为优势、发展路线及实现程度，不决定已交感化曜关系能否读出事件之象。先读事件方向，再说明支持、阻力与实现条件；不用化曜吉名粉饰本体受伤，也不用受伤否定全部事件内容。

每对星先核已成立的宫、度或限运通道，连续作用逐段核实；限运建立的临时联系注明生效范围。八法只用于本模块已确认的身命／贵曜联系检查，不扩大原局体系一般生克通道。“经／络／顶”等定义或数据不足时标缺项，不自定角距、容差、经度数或评分。日月的化曜身份不改变其光体本身不套普通五行生克的规则。

星曜本义、落宫和掌宫用于把两层关系落实为具体人事：

| 项目 | 需要回答的问题 |
| --- | --- |
| 星曜本义 | 涉及什么性质的人、能力、事物或活动？ |
| 落宫 | 事情出现在哪个生活领域？ |
| 掌宫 | 牵涉哪些人物、事务和资源？ |
| 化曜身份 | 在这件事中扮演什么角色：产出、钱财、职位、支持、竞争等？ |

## 二、一般分析顺序

总体次第仍为：**命主 → 格局 → 天官。**

| 顺序 | 操作 | 输出要点 |
| --- | --- | --- |
| 1. 继承原局体系基础 | 读取既有命主、喜忌、力量、交感、格局与限运结论 | 保留原局背景及已经确定的支持、制约 |
| 2. 确定交感对象 | 按原 Skill 的宫、度和限运规则，找出当前实际交感的星曜 | 写清哪两颗星发生联系、通过什么通道联系；不能把全盘化曜任意配对 |
| 3. 标明化曜身份 | 按既有起法确认各星化曜，本命与流年身份分别标注 | 例如：土化伤官，炁化财 |
| 4. 直接读取化曜关系 | 在天官层按十神关系读象，不先拿实体星的本体生克筛掉该关系 | 例如：伤官生财，读为表达、技术、作品等与挣钱相联系 |
| 5. 细化两端的人事 | 分别读取两颗星的本义、落宫、掌宫 | 说明什么能力或哪方面事务成为收入渠道，财又体现在哪个领域 |
| 6. 补充星体本象关系 | 回到两颗星的本体五行、生克、喜忌及力量 | 补充这条事件路径中的帮助、压力、约束或代价 |
| 7. 合并表达 | 保留两层各自的信息，写成具体事件描述 | 同时说明事情的方向和实现过程中可能出现的状况 |

这里的“先读化曜，再补本体”，指已完成原局体系基础后，对天官模块的展开顺序。

## 三、本命天官格局、喜忌与从政机会

### 1. 本命判断次第

**命主基础 → 整体格局 → 天官与身命的关系 → 天官得地与八法 → 喜忌及组合 → 从政机会与显达条件。**

| 顺序 | 要看什么 | 判断指令 |
| --- | --- | --- |
| 1. 命主基础 | 命主喜忌、旺衰、得宫得度及原局支持、制约 | 沿用既有原局体系 Skill。先分清命主本来喜欢、忌惮哪些力量，不因某星化官、化财就改判为喜。 |
| 2. 整体格局 | 五星结构是否清楚、主要格局是否成立 | 原局基础与格局决定天官作用的背景；格局一般而天官得地，仍可保留起发、取得职位的机会，显达程度须另论。 |
| 3. 判断重点 | 命度主与天官、魁星、文星等的实际交感 | 与哪一贵星联系密切，就重点审相应格局；官、魁、文分别记录，同一星兼任时再叠加。 |
| 4. 天官得地 | 天官所在宫度、力量、所受生扶与损伤 | 分清有名无实、得地得用、得地但受制等情况，不能只看化曜名称。 |
| 5. 八法联系 | 穿命、贯主、经络、守、冲、钓及填实 | 说明天官如何联系本人，以及联系的亲疏、直接程度。 |
| 6. 天官喜忌 | 财的生扶、贵曜帮助，以及伤官、空陷、混杂等 | 先按天官法读喜欢与不喜欢的关系，再叠星体本象的助力和代价。 |
| 7. 成格与救应 | 有利结构是否完整，受损处是否有财、印、食神等相关组合 | 不要求每颗星都好；条文“得一格无破”须保留该格成立、未破的条件。 |
| 8. 从政机会 | 本人和天官的联系、贵气的形成条件、支持与阻碍 | 明确回答有没有从政、入组织任职或获得职位认可的机会，以及机会依靠什么、受什么限制。 |
| 9. 实现时机 | 原局条件被哪些限运或流年引动 | 本命先论条件与方向，时间问题再进入流年流程。 |

条文另列“命度主化生官正财，而顶伤官”为贵格，身主化生官亦有相应论法。保留这条作为本命检查项；“顶”的技术定义沿用本派已确认规则，不自行替换成任意同宫或三方交感，也不添加条文没有的“天官必须先不成格”等前提。

### 2. 天官喜欢什么、不喜欢什么

命主的原局体系喜忌与天官格局的喜忌分开记录，再合看二者是否一致。某星能帮助天官，同时对命主形成压力时，两面都要说明。

| 条件 | 天官层面的含义 | 本命判断方式 |
| --- | --- | --- |
| 喜与身命交感 | 贵气能与本人发生联系 | 优先看穿命度、贯主、守命以及冲钓，不只看天官自身位置好不好。 |
| 喜得宫得度 | 天官有适宜的位置和承托 | 结合条文的强宫、官福、贵人禄马卦气、恩生之度等条件，逐项记录，不能只凭一个吉名。 |
| 喜近太阳、登驾、守官福 | 与权威、组织、职位及社会支持相联系 | 按已有原局体系规则叠加星曜状态和具体人事，不省略命主基础。 |
| 喜财生官 | 资源、经营成果或现实支持帮助职位与贵气 | 正财、生官及天荫按各自身份读取；同宫、同度、同经等联系照盘面分别记录。 |
| 喜与官魁文等贵气相通 | 选拔、名望、文职或职位机会得到帮助 | 天官与魁星共同拱命、躔魁度等按条文论助力，不把各类贵星混成一个名称。 |
| 喜满用 | 天官兼具多项有用身份或条件 | 例如守命又兼恩星、得地又与贵曜有情；说明每项如何帮助本人。 |
| 不喜空陷、失地、休囚 | 贵气不易落实，或职位显达受限 | 可有职位机会而不显达，也可表现为支持不足，不能直接等同完全不能从政。 |
| 不喜伤官损官 | 表达、主张或产出与职位、规则发生矛盾 | 先读其象，再看是否有伤官生财、财生官，或印制伤官等相关救应。 |
| 不喜煞刃及破坏性混杂 | 职位路径夹杂压力、冲突或不清纯因素 | 明确是哪颗星、何种身份及交感造成问题；有制化时继续读其作用。 |
| 填实可加强或补救 | 原有条件得到落实、触发 | 空陷得填实先按有限改善，不直接升级为高格。 |

### 3. 八法的使用重点

| 方法 | 条文中的重点 | 指令 |
| --- | --- | --- |
| 穿命度 | 前四法中最紧 | 天官守命且在命度最直接；异宫而在命度之经，按条文亦纳入分析。 |
| 贯主 | 次于穿命度 | 看与命主同经、同宫同度等联系；沿用既有经度体系，不自行换算为相同经度数。 |
| 经络贵曜 | 喜与贵气星相通 | 记录天官与哪些贵气身份联系；摘录未分别定义经、络，不补造技术规则。 |
| 守命 | 后四法中最重 | 天官守命，再看得地、满用及与命宫有情的程度。 |
| 冲 | 次于守 | 看对宫、对度联系及是否清纯。 |
| 钓 | 次于冲 | 看三方联系；与魁星共同拱命可增助力。 |
| 填实 | 加强或有限补救 | 本文特别重视日支填实且立命于此；不把这一例改成所有填实规则都以日支为最高。 |

不编造八法的完整绝对排名，也不把“穿、贯、守、冲、钓、填”累加成未经确认的分数。

### 4. 怎样回答有没有机会从政

| 本命情况 | 适合输出的判断 |
| --- | --- |
| 命主基础较好、整体格局成立，天官又得地并与身命密切交感 | 从政或获得组织职位认可的条件较清楚；继续说明贵气来自何处，以及哪类限运能够引动。 |
| 天官有利，但与本人联系不直接 | 有制度、权威或贵人方面的环境线索；是否落实为本人职位，仍要看身命联系，不能只见天官好就断本人从政。 |
| 整体格局一般，天官独得地得用 | 可以保留任职、起发和得到认可的机会；对显达程度从谨，不机械换算古代科第为现代职级。 |
| 天官受伤，但有财承接、印制伤或食神制杀等关系 | 同时解释阻碍与解决路径，不能只凭伤官、七杀的名称否定从政机会。 |
| 天官空陷休囚、受损且帮助不足 | 从政路径或职位显达受到限制；指出具体限制，避免仅凭一星下终身否定。 |
| 官魁文中有一格成立而无破，其他部分有不足 | 保留该格支持的机会；其余不足另外解释，不以局部成功抹去其他问题。 |

“有从政机会”“已经从政”“能升到某个职级”分别处理。以用户提供的天官规则判断机会和条件，不凭单一格局指定现代官阶。

## 四、流年分析顺序

**流年在既有流程中定位交感星曜后，对每组关系先读星体本象之象，再读天官化曜之象。**

```text
继承原局与限运背景
→ 确定当年交感的星曜及通道
→ 先读本体生克之象
→ 结合双方星性、落宫、掌宫，说明涉及的人事
→ 再读化曜关系之象
→ 将两层合并为当年的事件描述
```

| 流年步骤 | 具体要求 |
| --- | --- |
| 先读本体 | 先说明谁生谁、谁克谁，以及相关宫位和人事如何受到作用。生克的利弊继承原局体系喜忌，不能见克就断凶。 |
| 再读化曜 | 直接读取食伤生财、印夺食、财坏印等关系之象；本体相克不妨碍另读化曜相生。 |
| 最后叠象 | 将本体作用方式与化曜事件内容放在一起表达；有挣钱之象，也可能同时存在约束、投入或其他代价。 |

## 五、示例：炁化财，土化伤官

前提：炁、土已经按既有规则发生交感；“财”保持已知身份，未给正偏时不自行补定。

| 分析层或步骤 | 关系 | 读象方式 |
| --- | --- | --- |
| 星体本象层 | 炁属木，木克土，即炁克土 | 先看炁对土的作用，再依原局体系喜忌、力量及双方宫位解释具体助力、制约或代价 |
| 天官变五行层 | 土化伤官，炁化财，构成伤官生财 | 表达、技艺、技术、作品等与挣钱相联系；土所代表的人事对财的形成有帮助 |
| 读取土的一端 | 土的本义、落宫、掌宫 | 说明通过什么能力、人物或事务形成产出，以及这些产出如何帮助挣钱 |
| 读取炁的一端 | 炁的本义、落宫、掌宫 | 说明钱财、资源或收益表现为何种事物，落在哪个领域、牵涉哪些事务 |
| 两层合读 | 本体“炁克土”，化曜“土伤官生炁财” | 土相关的表达、技艺或宫位事务可以成为财源，同时炁对土仍有本体层面的作用；两条方向分别保留 |

**此例用于流年时，顺序固定为：先读炁克土，再读伤官生财。**

在未提供具体宫位和星曜状态时，只给上述关系框架，不补造具体职业、客户、金额或事件。

## 六、化曜的人物、事件与作用关系

### 1. 化曜人物和事件速查

| 化曜 | 十神 | 人物取象 | 事件取象 |
| --- | --- | --- | --- |
| 天禄 | 比肩 | 自己、兄弟姐妹、同辈、同事、合伙人 | 自主行动、合作、共同承担、分配 |
| 天暗 | 劫财 | 同行、竞争者、争夺资源的同伴 | 竞争、分利、共同支出、资源分流 |
| 天福 | 食神 | 子女、学生、受自己培养的人 | 技艺、作品、产品、教学、稳定产出、享受 |
| 天耗 | 伤官 | 子女、学生、表达或技术能力突出的人 | 表达、创作、技术、批评、突破、挑战规则 |
| 天贵；本文生官指正财 | 正财 | 客户、交易对象、提供收入或资源的人 | 收入、经营、交易、资产、支持事业的资源 |
| 天荫／天廕 | 偏财 | 商业伙伴、出资者、带来外部资源的人 | 项目收入、商业机会、资源调配、外部资助 |

| 天刑 | 七杀 | 强势上级、施压者、强劲对手、纪律人员 | 压力、竞争、约束、执行、权柄 |
| 天权 | 正印 | 父母长辈、老师、导师、保护或资助者 | 学习、资格、文书、知识、支持、保障 |
| 天囚 | 偏印 | 专门领域的老师、特殊支持渠道中的人物 | 专门知识、研究、特殊学习方式、保护或约束 |

人物与事件是可选取象，结合问题、星性、落宫和掌宫选用。天印在此对应正官，天权对应正印；本表不改写人事管库。官禄宫主、魁星、文星／科名与天官分别识别，同星兼任时叠象，但不重复计算星力或当作多个独立证据。

#### 身份口径与时间层级

- 旧资料按阴阳干区分天印、天权、天贵、天耗、天暗的对应条文保留为口径分支，不与本模块身份拼接。盘面明确给出十神身份及体系时保留原字段和适用口径；同名不同体系先核口径，不全局替换名称。
- 分记**本命化曜身份及起法依据／流年化曜身份及起法依据／流年天干引动星曜**。年度“甲火、乙孛……”只给引动入口，不能据此替全盘改写十神。缺年度身份及已确认完整起法时，该栏留缺；仍可用已知本命身份解读被引动的原局关系。

### 2. 化曜关系速查

下表用于天官层的事件翻译。先有实际交感，再读关系；是否顺利、作用大小及伴随代价，随后结合原局体系层分析。

| 化曜关系 | 简洁事件之象 |
| --- | --- |
| 比劫生食神／伤官 | 自己、同伴或团队的投入，支持表达、技艺、创作和产出 |
| 食神／伤官生财 | 靠表达、技艺、技术、作品或服务挣钱 |
| 财生官 | 钱财、资源或经营成果帮助职位、事业和社会认可 |
| 财生杀 | 钱财和资源增强压力、竞争、执行或权力相关事务 |
| 官杀生印 | 职责、制度或压力引出学习、资格、文书及组织支持 |
| 印生比劫 | 长辈、老师、知识或平台支持自己及同伴 |
| 官杀制比劫 | 规则、上级、责任或纪律约束自己、同伴和竞争者 |
| 比劫克财 | 同伴竞争、利益分配、合伙花费或资源分流 |
| 财克印／财坏印之象 | 求财、经营或现实利益牵动、削弱原有学习、支持与保障 |
| 印克食伤／印夺食之象 | 长辈、规则、理论或保障约束表达、技艺及产出 |
| 食神／伤官制杀 | 用表达、技术、成果或解决问题的能力应对压力和竞争 |
| 伤官见官 | 表达、个人主张或技术方式与职位、权威、规则发生碰撞 |
| 伤官生财、财生官 | 表达技艺先转成收入或资源，再帮助事业与职位 |
| 财制印救食 | 钱财、经营或现实需求约束过度的印，使表达和产出得到空间 |
| 比劫护印 | 同伴或自身力量牵制损印之财，保护学习、支持或保障 |
| 官杀制劫护财 | 通过制度、管理和责任约束争利，保护钱财与资源 |

读取三方连续作用时，应分别确认各段交感。表中是事件关系之象，不凭单一关系直接承诺结果。

## 七、生官度

**按用户确认的本法：命主躔生官度，生官度即财度，按天官逢生读。**

- 保留“命主躔财度”这个条件，不改写成只有“天官自身躔财度”才可讨论逢生。
- 此天官规则与原局体系分析叠加，分别保留两层作用。
- 不由“逢生”一条直接推定其他制约全部消失。

## 八、输出格式

### 本命天官报告

| 输出项 | 应写内容 |
| --- | --- |
| 命主与格局基础 | 原有原局体系结论、本命喜欢什么力量、不喜欢什么力量 |
| 天官与本人关系 | 天官的身份、宫度、八法联系及所受支持、制约 |
| 天官喜忌 | 哪些组合帮助贵气，哪些组合形成阻碍，有无救应 |
| 从政机会 | 有哪些任职、选拔或获得职位认可的条件，以及关键限制 |
| 其他成就路径 | 官路不清楚但财、文、技艺等有象时，按已知结构解释，不强行归入从政 |
| 待引动条件 | 哪些本命条件需要结合限运、流年继续判断 |

### 流年天官报告

流年分析可采用下表；一般天官专题在已完成原局体系基础后，可先讲化曜象，再补本体作用。

| 输出项 | 应写内容 |
| --- | --- |
| 交感依据 | 哪些星曜、经由何种宫度或限运通道发生联系 |
| 星体本象 | 谁生谁、谁克谁，涉及什么星性、落宫和掌宫人事 |
| 天官化曜象 | 各星化曜身份、化曜关系及白话事件内容 |
| 合并解释 | 哪些人物或事务形成什么事件，原局体系层又补充了什么助力、压力和代价 |

### 客户报告的落点

本命客户报告按“结论先行 → 八方面按需展开 → 有依据的鼓励”：任职、组织职责和晋升条件进入**事业形态／社会成就**，财、印、贵曜等帮助进入**外部资源**，不另设重复天官长章。官路不明确时如实说明，不强写从政。

限运客户报告按既定五板块，将天官两层事件纳入**重点事件与关键年份**。次序为：原局与限运背景 → 实际交感 → 本体作用 → 双方人事 → 化曜关系 → 得失合读。躔度、神煞用于细化人物和事件，不省略，也不越位决定成败。

客户正文保留关键术语并就近解释，具体表达、有据鼓励，依 `../../qz-report/resources/report_style.md` 去重；完整证据留在内部。用户“不存档”时只在对话／内存中交付，不创建客户案例文件。

### 内部逐组证据

内部保存第三节的本命天官条件表，并按下表记录实际关系，不只写“某星吉／凶”：

| 证据项 | 内容 |
| --- | --- |
| 关系层级与时段 | 本命或限运；星曜 A、B；已成立的实际交感及依据 |
| 星体本象层 | A→B 或 B→A；生克与喜忌、双方力量、制化和代价 |
| 天官变五行层 | 两端化曜身份、体系及本命／年度口径；身份作用方向；事件之象 |
| 两端具体人事 | 各自星性、落宫、掌宫、躔度及相关神煞的已确认取象 |
| 综合与输出位置 | 好处、阻力、救应、成立条件、待核；对应客户报告哪一段 |
