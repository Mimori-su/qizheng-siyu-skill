# 官非与纠纷：事业、财运共用规则

已确认规则：官非纳入事业和财运，主要看难星严重克命度主、财生官杀的程度；不作为独立 Skill。下列次序为对既有交感、力量、制化及限运规则的程序性整理。

## 定位与顺序

1. 继承原局喜忌，以命度主为本人锚点。难星身份、年干化曜官杀、天官体系身份分别记录，不能因为名称相近就合并。
2. 先核难星是否实际克到命度主；逐星复核四时、宫宿生克、垣殿、填实、全通道与力量对比。强难直接作用、本人受制明显且缺救应，才提高此条压力的权重；不编概率和分数。
3. 再核财生官杀：明确财星取自哪套定位；分别核“财源→官杀”及“官杀→本人”的实际作用。A→B、B→C不自动等于A直接作用C，单有财或官杀标签不成结构。
4. 财生官可以对应事业支持、职责扩大；只有结合难星、受伤及现实领域，才讨论求财带来的约束、纠纷或代价。气数喜带来的吸引与克制成本可同时存在。
5. 看恩化难、用制难、分担等救应是否真实有效，再比较剩余压力。不能仅凭难星旺或有刃便认定官非。
6. 叠加双方本象、落宫、掌宫、化曜、宿度和神煞。事业侧写权责、工作安排、组织规则、合作责任；财运侧写收支、分成、债务、合同履行等，只有对应证据才列，不每篇机械补一章。
7. 问时间时依原局→宫限→度限→小限与飞限→太岁→年干化曜→顶星→流年星核引动。缺资料只限制应期，不编具体诉讼、处罚或破财日期。

## 客户与内部输出

客户融入事业或财运的“阻力、责任与行动建议”，采用“主要提醒→现实领域→成立条件与救应→可提前核对的事项”。两专题同一事项合并，单问纠纷也走相应专题并执行 qz-report 文风，不退回独立官非报告。

内部保留难星关系、实际作用通道、双方力量、财生官杀链、救应、引动、支持／制约和缺项；只存证据摘要，不添现实案情。

传统取象不能确认违法、犯罪、处罚、胜诉败诉或损失金额。已有真实法律问题，以事实材料与专业法律意见为准；不能因报告文风要求删掉这一实质边界，也不在每段重复免责。
