# 出身与父母分析框架

父亲的年干财星定位为**正财**。本文件只保存通用规则，不保存教学命盘、身份、个人经历、资产反馈或可识别的事件时间线。

## 1. 调用与分析任务

用户明确问出身、父母、祖辈、家庭背景、父母支持或相关阶段变化时调用。个人性格报告不自动增加本专题；只问父亲、母亲或一个窄问题时按范围回答。继承 reader → wangshuai → core 已完成的原局记录；教学整理无需补造命盘。

分开回答五件事：

1. 父亲、母亲各自的能力、财运事业与外部资源；
2. 家庭整体的资产、居住条件、祖辈与亲属支持；
3. 父母如何对待命主，命主怎样感受与回应；
4. 家庭资源中有多少、通过何种方式实际支持命主；
5. 哪些行运引动会改变关系、支持方式或家庭事务。

**父母有资源、愿意给、能够给到，以及命主感到舒服，是不同结论。**父母两人也分别记录，不把一方的财富、性格或关系模式套给另一方。

## 2. 定位：日月、度主与多点同参

| 观察入口 | 职责 |
| --- | --- |
| 太阳 | 父亲的自然人物象，连同同宫星及其余成立的交感观察父亲表现与外援；不限童年 |
| 月亮 | 母亲的自然人物象，连同同宫星及其余成立的交感观察母亲表现与外援；不限童年 |
| 日月所躔宿的度主星 | 分别作为父、母的另一观察中心；按该宿的日／月／木／火／土／金／水属性定位，不把日宿月宿折为火水 |
| 年干正财 | 父亲的重要人物定位，与太阳、田宅主及其作用交叉核对；不是年干偏财，也不是命度主仇星的同义词 |
| 年干正印 | 已保留的母亲辅助线索；身份须有可靠起法与依据，不凭原盘“印星”标签直接替代年干正印 |
| 田宅主 | 参与父亲人物定位；兼看家庭资产、祖辈和家庭支持，与太阳、年干正财同参 |
| 田宅宫本宫、对宫、两个三合宫 | 家庭氛围、居住、家产及相关事务；宫内星一般不直接等同父亲 |
| 命度主恩星 | 主动照顾、贵人外援与支持如何到达命主的线索 |

年干正财的确定复用 `../../qz-wealth/resources/wealth_framework.md` 的年干→正财天干→化曜表；不用年度引动星替代生年正财，不自行沿用旧“己化孛”错误。正印身份未核时保留缺项，日月等已有入口仍可分析。

日月躔度需要同时做四件事：**宿度类象、宫宿对力量的条件、同属性四宿的交感、度主星自身的作用**。度主星不是一个形容词，要读取它的力量、落宫、掌宫、化曜及完整交感。若日月度主与原局四核心重合，复用记录并分清当前人物身份；不无限递归再推“度主的度主”，也不混淆父母。

多点定位看不同身份与作用能否共同指向同一人事。星曜兼年干正财、田宅主，又与太阳交感，可加强父亲相关取象；同一颗星的多身份、重复通道不能重复计成多颗力量。

### 关系中心固定

“日月见恩，父母贵人运好”中的**恩，指命度主的恩星**。以日月度主为观察中心时，不暗换成太阳、月亮或其度主自己的恩星体系。难、仇、用等关系也注明以命度主为中心；命度主为日月时仍按光体与气数规则处理。

父母自身的条件可从日月及度主系统观察；“财星、气数星”须写清沿用原局的哪一种身份。需要另立父母自己的财官或调候太极而尚无已确认起法时，留待核，不自行重算一套。

## 3. 逐星核验与叠象

参与分析的日月、度主、田宅主、年干人物星及来助、来克、救应星，全部继承 `../../qz-wangshuai/SKILL.md` 的完整逐星记录：

- 本宫、对宫、两个三合宫逐宫列星；实际所躔宿同七曜属性四宿逐宿列星，包括同宿星；空项和未核项分开。
- 五星核月令旺相休囚死、宫宿生扶克泄、垣殿、四柱落宫填实、运行及实际来星力量。日月按气候、昼夜、月亮农历日期／月相和明晦，不套普通五行生克。
- 自身基础、外来生扶、受制、综合力量与可用性分开；强而受阻、弱而有补充分别解释支持分量、兑现阻力与持续方式，不打分或换算百分比。
- 每颗星叠加本象、落宫、掌宫、化曜、躔度事务及所落／所掌宫的相关神煞。神煞补充已经成立的主线，不单凭凶名定灾病或家庭事实。
- 宫气、宿气和实际星曜分别记录。只对有实际通道的星逐对读生克；A—B、B—C成立，不自动补出A—C。

“本宫看自身、三方看外界”用于区分内外作用：先读日月／对象星同宫的直接环境，再看对宫与三合的外部作用。具体是谁提供帮助、什么事情造成压力，仍凭来星掌落宫与实际关系定位。

## 4. 父母自身条件、家庭资源与实际支持

### 父母的能力、事业与财富

- 有贵：看日月及度主是否与原局可用的气数星、官禄相关星、天官体系有有效联系，再比较力量与受制；复用已确认的事业、天官规则，不以一个官名断具体职位。
- 有财：看与已定位财星、财帛主、田宅主的联系，分清父母创造收入、掌握资产、获得外援和留存条件。强弱决定作用分量，宫宿化曜说明行业与形成渠道。
- 见恩：按命度主恩星看父母的贵人外援与主动支持倾向；继续查该支持是否真正传到命主，不把“父母有贵人”直接省略为“命主已经得到全部好处”。
- 父母的定性层次依据有效力量、作用来处和受阻条件综合描述；教学中的实际金额只属反馈，不能提炼为某单一配置对应固定身家。

### 家庭、祖辈、居住与家产

以田宅宫及田宅主为入口，结合有效交感辨别家产、祖辈／亲属支持和生活氛围。家庭氛围可用以下候选象，均须回到本盘喜忌与力量：

| 星曜线索 | 家庭氛围的取象方向 |
| --- | --- |
| 日 | 温暖、正向、贵人或支持条件 |
| 月 | 体贴、照顾、生活上的关心 |
| 木、炁 | 学识、教育、玄学、原则与道德要求；炁可有交流较少之象 |
| 火、罗 | 行动力、急切或争执，依喜忌、作用强弱读得失 |
| 土、计 | 稳定与责任、交流较少、对细节或利益较计较等候选表现 |
| 金 | 娱乐、交际与生活享受 |
| 水、孛 | 逻辑、沟通、讲道理；支持或压力依实际作用 |

搬家、居住调整看水孛、迁移因素及迁移与田宅的实际作用，不见其中一项就断搬迁。房产规模、亲属身份与居住经历须有相应证据，不从田宅单星补造。

### 支持怎样到达命主

分别核：**资源源头 → 父母／家庭人物线 → 中间传递或制约 → 命主承接**。

- 田宅主、父母人物星为恩且有效生助：有主动供给、照顾、安家或学习支持的线索，力度仍核本星及后续生扶。
- 家庭有资源但传递受阻：说明具体阻碍领域、条件或需要的中间支持；不能只因田宅旺就断无条件获得家产。
- 父母线既有助力又有难星压力：支持与管理可同时存在，分别写物质所得、相处体感与代价。
- 若拟解释为“家财经恩星转给命主”，每一段都核通道。只有恩星直接助命、未见财星生恩的通道时，分别记录“家庭财源”与“另有恩助”，不编成完整转交链。

## 5. 相处模式与事实边界

父母星及其交感来星与命度主的恩、难、用、仇关系说明付出、管理、主动投入或约束方向；气数决定是否合需要，实际力量决定程度。日月有力可体现支持能量与照顾条件，俱晦或受遮要查帮助怎样发挥，不直接断父母冷漠。

“日见命度主难星”是父亲线关联命主承压，不等于“难星用普通五行克太阳”。日月见木炁、土计分别按光体、四时和月相判断，不能把日月合成一条固定吉凶口诀。

既有条件中的月见土计、日月见木炁或难星的健康／居家等取象，保留为**需结合条件的候选线索**：照顾家庭、交流较少、严格要求与疾病、虐待是不同判断。健康转健康专题核对；家庭主妇、具体疾病、打骂或 PUA 不由一颗星确认。现实已反馈的暴力按实际行为回应，不淡化为“为你好”。未反馈的经历不写成事实。

## 6. 行运：关系和帮助会随阶段改变

继承 `original_vs_transit.md`：原局 → 宫限 → 度限 → 小限与飞限 → 太岁宫群 → 年干化曜 → 顶星 → 流曜。只有命主盘时，观察其限运中父母线及命主所受影响，不冒称另起了父母自己的运表。

1. 先记录原局的相处基础：哪颗父母定位星关联何种支持、管束或资源阻力。
2. 找当前限运实际引动哪颗星，核其气数、力量、可用性，以及对父母人物线和命度主的有效作用。
3. 恩星被有效引动，可以表现为父母态度缓和、照顾增加、开始提供条件或支持方式转变；恩星受制或不合气数时，也保留兑现阻力和体感代价。
4. **取象先适配题目、年龄与人生阶段，再选择掌宫、化曜。**同星兼恩星、田宅主、科甲及夫妻主时，求学阶段可从父亲与学习支持解释；不是见夫妻主就自动说婚姻，也不是“上学”一律指童年入学。
5. 核对实际交限日期与当时周岁，软件岁数原样另存；年月需来自已给限表或已确认计算。“木运”等简称不明先问具体宫限／度限／年度引动，不自行补造一套运法。
6. 只有恩星有效助命时，可写“恩星引动缓解原有关系压力”；要命名“恩化难”，须另核难星→恩星、恩星→命度主每一段通道和力量。无本命通道而由限运建立者注明临时作用，不把阶段转好扩大为此后终身无矛盾。

案例只抽象出上述“原局基础—恩星引动—年龄过滤—关系转化”规律，不带个人出生信息、确切交限日、伤害经历或完整限表进入 Skill。单例得到的方法仍需后续案例检验。

## 7. 输出与校验

客户版与内部记录分开，按 `../../qz-report/resources/parents_report_template.md` 输出；语言服从 `../../qz-report/resources/report_style.md`。客户结论先行，具体说明父母条件、支持、压力及变化，不逐段附“这不代表……”；温和不粉饰，不要求客户因术数解释忍受伤害。

完成前核对：

- 父／母与家庭资产是否分开；父亲年干正财是否误写偏财；田宅宫内星是否被直接当父亲。
- 日月的实际宿度与度主是否都看了；转换观察中心时有没有暗换恩星定义。
- 每颗参与星是否完成宫、宿全通道与力量复核；无通道的生克链是否被补造。
- 家庭有资源、父母贵人好与命主实际受益是否有各自证据。
- 关系变化是否有具体限运入口及年龄依据；候选事件、实际反馈与实际验证是否分栏。
- 全文是否包含不应保存的案例细节；用户不存档时仅在对话中交付。
