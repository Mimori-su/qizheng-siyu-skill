# qz-wealth

## Purpose

财运、资产、田宅、收入、分利与损耗专题。沿已确认断法，依次分析财富来源、形态与权属、实际支配、流向和阶段层次；不以命主旺弱直接判有无财官。继承取得、具体股权形式等细分判法未齐，按具体缺口限制相应判断。

## When to use this skill

当用户请求与本 Skill 定位一致的学习、读盘、核心分析、专题分析、校时或报告整合任务时使用。若用户请求超出本 Skill 边界，先说明边界并交给对应上游或下游 Skill。

## Required inputs

qz_structured_data.md、qz_core_report.md 或对话中经复核的等价结果，以及用户问题。问时间另需限运／流年；输入齐全时交 qz-reader 按现行规则补齐可计算的限运，专题不另造算法或数据。仍缺的项目只限制对应判断，不强制建档。

## Output files

客户稿 `wealth_report.md`、内部档 `wealth_internal.md` 独立生成；用户要求“不存档／不入库”时仅对话交付，不创建案例文件。

## Workflow

1. 继承并复核读盘、原局喜忌与十一曜力量，不绕开 Core 定喜忌。
2. 必读 `resources/wealth_framework.md`，分列恩星、命度主财星（仇星）、财帛主、年干正偏财、日月及财帛／田宅／疾厄入口。
3. 查实际交感、力量、生扶、受伤与救应；逐条叠加星性、落掌宫、化曜、宿度、神煞，说明财源、层次、过程与代价。层次必读框架第10节及10.1执行清单，沿“财源规模 → 生财供给 → 本人所得 → 支配留存 → 限运实现”核验；同时查多路成财、财帛承载、日月会财及联系命身、禄马官魁文和三元禄助力，不把资源规模、标签数量或辛苦程度当金额算法。
4. 化曜作用另读 `../qz-core/resources/tianguan_analysis.md`，本体与变五行分层；问应期读 `../qz-core/resources/original_vs_transit.md`，不私改通用流程。
5. 按家庭来源／实际承接／自主创造／伴侣子女双向流动展开；分开现金、房产店铺、股票持仓、企业股权与合伙份额的载体、权属、收益与兑现，核留存、转换、分配与损耗。不把财生财写成获利保证，不把给家人或现金转资产直接判败财。
6. 官非与财务纠纷纳入本专题，读取 `../qz-core/resources/dispute_risk_rules.md`；核难星严重克命度主、财生官杀的强弱及救应，职场责任同时接 qz-career，不调用独立官非 Skill。
7. 按出身、自主求财、阶段所得、积累传承四轴定性判断，注明主体与时段，另论个人承受；每次回答关键财富上升限运／年份及同步的婚姻、子女、合作、事业等事件，执行 `resources/wealth_framework.md` 第11.1节，不把同步写成因果。先内部后客户，读取 `resources/wealth_report_rules.md` 的已确认七板块及 `../qz-report/resources/report_style.md`。边界见 `resources/finance_caution_rules.md`。

## Rules

- Reader 只读盘，不解读。
- Core 基于 `qz_structured_data.md` 或对话中经复核的等价结构化结果分析，不绕开数据契约。
- 专题 Skill 必须继承 `qz_core_report.md` 或对话中经复核的等价原局结果，不能各自独立乱断；不为满足文件名而强制存档。
- 一颗旺星真正得用可成为大财富／名气的关键条件，仍核完整结构；本人旺弱与外界财源大小分开，月亮、身度主及各自本对三合星体共同看承受与享用。
- 日月与财星有效联系、日月与命身有效联系，都是财富层次的正向依据，重点是贵人与机会；后一条不要求日月直接会财，也不只解释为体感或承受。岁殿、岁驾、禄元、禄勋、马元、马、官魁、文、天马地驿、三元禄有效会财亦加助力；按实际定位分栏，不造固定分值、不按标签数定金额。
- 旺财见太阳、旺食伤多路生财及财生财的千万级经验条件，按框架第10节使用；多条有效旺财、供给与承载并存时继续评估更高规模，不止步于首条财路。经验潜力档不当作当前身家或确定财富上限，客户反馈不得直接固化为单点公式或写入 Skill。
- 己化月＝月亮，故甲年正财、乙年偏财均为月亮；乙化孛＝月孛，故庚年正财、辛年偏财仍为月孛，不能混同。
- 不使用确定性、恐吓式、绝对化语言。
- 区分已确认规则、整理框架、推演与待核项；未明确的判法直接说明。

## Safety rules

- 疾病问题：只作传统术数取象参考，提醒咨询医生。
- 法律问题：只作传统术数取象参考，提醒咨询律师。
- 投资问题：不提供投资建议或收益预测，提醒咨询持牌专业人士。
- 心理危机或现实危险：建议寻求现实专业帮助或紧急服务。

## Output format

客户默认七板块：财富总评 → 财富形态与实际支配 → 家底与承接 → 自己的求财本领与路数 → 留存、分配与传承 → 重要阶段变化 → 发挥优势的建议。层次带主体、维度与时段，已确认经验量级可用，未教明的分档边界仍待校准；更来财与更喜欢分开，逐路说明代价。只问量级先给经验潜力档，再给二至四条关键依据和实际制约，不展开职业。其他单项按范围压缩，结论先行、末尾有据鼓励，技术证据留内部档。报告结构不替代尚未教明的具体判法，不改变其他专题模板。
