# 七政四余命理分析师 · 专家包

本目录保存 Agent 定义、插件配置、13 个子技能及参考资源。总入口与完整使用说明在上级 `SKILL.md`、`README_INDEX.md`。

## 使用

- 提供排盘文本、PDF 或清晰截图；只有出生资料时，按 `skills/qz-reader/resources/natal_chart_input.md` 核日期、时间基准、出生地与时区，再由经验证的完整本命引擎取得盘面，不凭空推造星位。
- “查看七政四余使用指南”：了解可问专题与输入要求。
- “帮我简要看看”：已有完整盘面时生成首次总览。
- “详细分析性格”“分析婚恋”“分析某年运势”：按所问专题输出。
- “看我的学历、升学或考证”：交 qz-career 的 `skills/qz-career/resources/education_framework.md`；qz-study 负责教材学习整理，不接个人学历判断。
- “不存档”优先，不要求为了工作流额外落盘。

## 加载与当前边界

- 总控包的技术标识为 `qizheng-siyu-full`，子技能位于本目录 `skills/`。不要仅复制 Agent 文件而遗漏资源。
- `.codebuddy-plugin/plugin.json` 是现有插件注册配置，不保证其他宿主直接兼容。请用目标宿主支持的本地导入方式；本包没有自动注册脚本，不提供不存在的注册命令。
- `qz-health` 已启用；学习整理、择日、校时仍保留原有 `disable: true` 标记。这是配置状态，不等于已实测所有宿主的加载行为。
- 官非归入事业、财运。旧独立官非模块与校时关键词计分器不随包提供。
- 程序负责提取、校验、三限补算、时点流曜与模板生成，不是自动断事引擎。文本解析只生成低可信度初稿，完整契约仍需复核。出生资料起盘按 Reader 规则核验；完整本命引擎未随包提供，尚待平台适配、完整输出与口径校准，不能宣称已可完整起盘。
- 小限、飞限、节气月限按 `skills/qz-reader/resources/annual_period_query.md` 的规则及明示程序约定自动补算；宫限和度限依已核限表。顶星按已采用的公式，独立工具据真实行度、限年数和星位计算命中；与三限计算分开，不改变月运启停。
- 时间输入须检查历史夏令时：整段夏令时期间先提醒确认钟表／标准／太阳时口径，再定时辰；换表重复或不存在时刻单独处理，不自动减一小时。
- `skills/qz-report/scripts/assemble_report.py` 仅拼接内部旧稿，不生成客户模板报告，也不能代替 `qz-report` 的整合判断。

## 辅助脚本依赖

Python 3：文本解析、校验、核心框架生成和旧拼接器只依赖标准库。PDF 文本提取使用 PyMuPDF（导入名 `fitz`），可回退 pdfplumber；PDF 渲染依赖 PyMuPDF。缺依赖时须明确报告，不把空文件当提取成功。具体命令参数查看对应脚本的 `--help`。
