# 性格分析模型

## 默认输出边界

“详细分析性格”“性格报告”“重新分析性格”默认只生成命主本人的性格，不自动调用[人际交往模型](%E4%BA%BA%E9%99%85%E4%BA%A4%E5%BE%80%E6%A8%A1%E5%9E%8B.md)。

默认包含：

- 社交面具、第一印象和一般沟通方式；
- 真实内核、情绪、安全感和成熟能力；
- 思维、价值观、优势、压力来源与建议；
- 四核心宿度与相关神煞的最后修饰。

默认不包含：

- 父母与家庭互动；
- 兄弟、朋友和社会群体的对象化分析；
- 恋爱对象、婚姻对象及相处模式；
- 领导、上司和职场关系。

只有用户明确要求“人际交往模式”“人际关系”，或点名具体关系对象时，才调用人际模块。只点名一类时，只分析该类。

## 两套证据

### 星曜

- 命宫主：社交面具、第一印象、对外处事。
- 命度主：相处较久后显现的能量内核。
- 月亮：内在情绪、安全感与潜意识。
- 身度主：成熟能力、精神承载与深层驱动。
- 四者均要结合[交感通道](%E4%BA%A4%E6%84%9F%E9%80%9A%E9%81%93.md)。

### 宫位

- 命宫本宫、对宫、三方及命宫主：外界中的自己，偏早年处世。
- 相貌宫本宫、对宫、三方、相貌宫主及交感星曜：内心想法，相由心生。
- 福德宫本宫、对宫、三方、福德宫主及交感星曜：社会交互、价值观与道德取向。

## 修饰层

完成星曜骨架与宫位结构后，默认直接调用[性格修饰层-宿度与神煞](%E6%80%A7%E6%A0%BC%E4%BF%AE%E9%A5%B0%E5%B1%82-%E5%AE%BF%E5%BA%A6%E4%B8%8E%E7%A5%9E%E7%85%9E.md)。

1. 只重点读取命宫主、命度主、月亮、身度主所躔的星宿；其他星曜宿度暂不进入性格主流程。
2. 对四个核心锚点，先看星曜落入宫位的神煞，再看该星曜所掌宫位的神煞。
3. 月亮及身度主同样处理；若两者为同一星曜，合并证据，不重复加重。
4. 星宿与神煞只作最后一层“形容词”，用于细化表现，不可推翻星曜、强弱、交感和宫位主结论。
5. 只采用含义明确、与性格主题相关且证据可追溯的神煞；不因神煞名称直接制造吉凶结论。

用户明确触发人际分支时，先完成个人性格骨架，再按点名范围调用[人际交往模型](%E4%BA%BA%E9%99%85%E4%BA%A4%E5%BE%80%E6%A8%A1%E5%9E%8B.md)。

## 强弱组合

| 组合 | 倾向 |
|---|---|
| 命度主旺、命宫主旺 | 主动性强，愿意行动改变环境 |
| 命度主弱、命宫主强 | 适应环境、借势应变，可能不想主动改变环境 |
| 命度主强、命宫主弱 | 行动力强，社交或外部承接较弱；阻力大但韧性强 |
| 月亮、身度主强 | 精神承受与意志较强 |
| 月亮、身度主弱或交感难星 | 内心承压与意志稳定性较弱 |

## 客户表达

默认按“外在感觉—真实内核—安全感—成熟能力—思维价值观—一般沟通与边界—星宿神煞修饰—优势—需要照顾之处—建议—正向收束”输出，并统一遵循[客户报告正向表达规范](../../../qizheng-siyu-expert/skills/qz-report/resources/report_style.md)。

先让客户感到被理解并看见自己的优势，再说明挑战产生的条件及保护作用，最后提供现实可行的调整方向和有依据的鼓励。不得为了增加情绪价值而编造优点、弱化风险或改变强弱判断。

仅在明确触发后，按需追加家庭父母、朋友社群、恋爱娱乐、婚姻或领导职场。避免人格打分和道德判决。
