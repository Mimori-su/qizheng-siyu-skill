# 亢宿

## 类象速查

[二十八星宿类象速查#亢宿](../%E4%BA%8C%E5%8D%81%E5%85%AB%E6%98%9F%E5%AE%BF%E7%B1%BB%E8%B1%A1%E9%80%9F%E6%9F%A5.md#%E4%BA%A2%E5%AE%BF)

> 亢金龙 · 东方青龙 · 二十八宿第 2 位（龙颈） · Kàng Xiù

---

## 🎯 一句话记住它

**亢是龙颈——昂起的咽喉，天庭疏庙。它管"承命"：内朝听政、刑狱听讼、录功行赏。**
**角是"门"，亢是"朝"；角是立案，亢是审理。**

**明则政令通，暗则喉咙塞，赤则争讼起，动则换声气**。

---

## 🔑 断事三问（核心用法）

断事前先问三句，本宿之象立出：

1. **这件事的"上奏/听政"通道通不通？** —— 汇报、提案、申诉、上访、内部会议、审批流
2. **谁是"内廷"决策者？** —— 上级、评审、内部会议、掌权核心、长辈会议
3. **事过"咽喉"还是卡在喉咙？** —— 表达、执行、上传下达是否顺畅；话敢不敢说、能不能说清

> ⚖️ 吉凶总则：**利断事，忌争讼。** 内朝有序则吉，辅臣失次则凶；咽喉通则吉，气机郁结则疾。

## 📖 故事线（四段记忆法）

### ① 天上 · 弯弓之状

亢宿四星像一张弯弓（"四星恰如弯弓状"），弓已拉开、蓄势待发——这就是亢宿的姿态：喉咙已张开，话要出口、令要下发。亢宿四星属室女座，其"名天府，一名天庭，总领四海"。

记忆点：**弯弓蓄势，咽喉待发。**

### ② 地上 · "疏庙"到底是什么

"亢为疏庙，主疾"。按周制，天子路寝有五门（皋、库、雉、应、路），有四朝——**外朝（皋门内，决罪听讼）、中朝、内朝、询事之朝（询国危、国迁、立君）**。亢宿所代表的"疏庙"就是**外朝**——宗庙、社稷的前殿，皋门内决罪听讼之所，三槐九棘，百官列位。所以"疏庙"就是"庙廷"，后世"庙堂"代指朝廷，即由此来。孔子诛少正卯的"两观之诛"，就发生在外朝的雉门外。

记忆点：**疏庙=外朝=听政之所=庙堂。**

### ③ 人间 · 从庙廷到朝廷

亢宿兼具内外朝之象："亢四星，天子之内朝也，总摄天下奏事，听讼理狱，录功者也。"到这一步，亢宿成了"朝廷"的代表星。其天区最亮的是**大角星**（牧夫座α，全天第四亮星）——"天栋"，主帝座。栋者，屋脊正中之横梁：**既中且正、又居高位**，正是乾卦九五之象——"上梁不正下梁歪"，正梁正，则天下正。故"大角者，天王帝庭"，大角星主要用于王者占（"秦之亡也，摄提不动而大角亡去"）。

记忆点：**天栋主帝座，上梁正则天下正。**

### ④ 断事 · 过咽喉

角主入门，亢主承命；角是立案，亢是审理。凡"话要出口、事要上达、功要论定"之事皆属亢：汇报、提案、审判、考核、表彰、内部会议、复审、答辩。

记忆点：**说得出、上得达、断得清。**

## 👤 性格特征

### 正面：内廷喉舌、公正判官

- **核心特质**：内在秩序 + 发声权。重规矩、会议、责任、审理、公平，遇事愿意讨论、愿听意见。
- 刚正不阿、有决断力、善理事务、处事公正。
- 能替人主持公道，适合做"内部拍板、居中调解"的人。

### 负面：闷声憋话、火气上头

- 暗弱者：把事情憋在心里、不愿表态、怕说错话，申冤无门。
- 赤芒者：说话带火、语气锋利，一声就引爆争端，易招口舌官司。
- 情绪起伏、易急火攻心（咽喉/颈项/呼吸象征）。

### 一句话总结

**亢宿的人，是"朝堂"本身：要么有话语权，要么被消音，要么一开口就引爆。**
明=有人听你说话；暗=话到喉咙说不出口；赤=开口即争；动=换一个发声位置。

## ⚡ 断事速查（应用层）

### 关键词

**内朝 · 听政 · 奏事 · 刑狱 · 录功 · 咽喉 · 表达 · 审判 · 考核 · 申报 · 伸冤 · 承命 · 会议 · 会审 · 复审 · 疾疫**

### 四态×领域交叉表

**政治与法律**——角是门，亢是朝；角是立案，亢是审理

| 状态 | 表现 |
| --- | --- |
| 明 | 内部运转正常、辅臣进忠言、政策讨论清楚、司法听审有序 |
| 暗 | 领导失职、会议拖延、政令不行、案件难审、官员互相推责 |
| 赤 | 内斗、诉讼、监管重罚、政策急转、官员风波 |
| 动 | 高层改组、部门合并、审判方向改变、政策口径更新 |

**经济与市场**——亢宿经济象征在监管、会议、审批、执行、疾疫、粮价与市场信心

| 状态 | 表现 |
| --- | --- |
| 明 | 市场规则解释清楚、监管有度、董事会能拍板、价格会商有效 |
| 暗 | 政策迟迟不出、监管口径含糊、高层内耗、审计不明（市场最怕"不表态"） |
| 赤 | 监管突然出手、罚款、价格波动、医疗疾疫消息引焦虑 |
| 动 | 企业换高层、监管规则变更、估值体系重排 |

**个人财运**——亢宿不是投机财，而是**职务财、审议财、批款财**：
- 明：预算会审通过、申请批款、保险理赔、复盘合同
- 暗：钱卡在审批/会议/领导签字/报销/仲裁
- 赤：罚款、诉讼费、赔偿、医疗急支
- 动：收入结构变、岗位调整影响工资、财权重分配

**军事、地缘与兵变**

| 状态 | 表现 |
| --- | --- |
| 明 | 军令清楚、边防有序、指挥系统稳定 |
| 暗 | 军令不明、内部协调失效、边防反应迟缓 |
| 赤 | 兵象、边境摩擦、军警冲突、强硬执法 |
| 动 | 军队调防、指挥层更替、联盟关系变化 |

**疾病、公共卫生与灾害**（仅作传统象征，非医学诊断）

- 龙颈：咽喉、颈项、气管、声音、呼吸通道；主火与疾：炎症、发热、急性反应；主内朝：身体内部会诊、诊断、复查
- 明：疾病可控、检查有结论、医嘱清楚；暗：隐性病、拖延不查、诊断不明；赤：急病、炎症、发热、外伤火气；动：病情反复、换医换院、方案调整

**家庭、人际与婚姻**

| 状态 | 表现 |
| --- | --- |
| 明 | 家庭能坐下来谈、长辈主持公道、婚约被双方家庭正式讨论 |
| 暗 | 内部沉默、问题不说破、长辈不表态、名分迟迟不定 |
| 赤 | 家族会议变争吵、房产养老子女教育医疗费爆发 |
| 动 | 家庭权力结构变化、老人退位、子女主事、角色调整 |

**人际**——亢宿不是社交热闹，而是"**谁能进入核心圈，谁能在会议中发声**"。

## 📅 择日与值日要点

- **亢宿值日宜做"过咽喉、定案论功"之事**：开会、述职答辩、复审、签约审议、体检复查、案件审理、绩效评定、保险理赔、正式表态。
- **亢宿值日忌做"隐瞒拖延、硬顶权威"之事**：有话不说憋着、拖延检查、会议中硬顶领导、口舌争讼。
- **一句话口诀**：明则政令通，暗则喉咙塞，赤则争讼起，动则换声气。

**甲子历四层观察**（术数系统，非科学预测）：
- 年运：国家内部治理、核心高层会议、公共卫生政策、疾病流行、司法改革、粮食价格
- 月运：政策发布、医保医疗议题、学校纪律、企业内部审查、市场监管、法务流程
- 日运：开会、面试复审、诉讼庭审、体检复查、签约审议、绩效答辩、家族会议
- 时运：内部消息传来、领导批示、突然召开会议、咽喉不适、口舌之争、审批状态改变
