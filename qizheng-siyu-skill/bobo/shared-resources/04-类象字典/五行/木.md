# 木

|         |                                                                                                                                         |
| ------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| **木**   | **描述**                                                                                                                                  |
| **性质**  | 木主生发，生长，发芽，坚韧，有直来直去的特性，凡是世界上具有这种特性的事物，都可以归纳为木。<br><br>木曰曲直，曲就是弯曲，直就是伸直，所以木就具有能屈能伸的特性，特别是乙木。<br><br>木主仁。也代表长寿。大家可以看到很多树木都是有上千年历史，所以它主长寿。 |
| **性格上** | 木气中和，木主仁慈的，会乐善好施，有怜悯、恻隐之心，比较朴素、实在。<br><br>木气过强，就会倔强，固执，偏激，执拗的特性。<br><br>木气过弱，容易懦弱，妒忌，小心眼、冷酷无情。                                          |
| **感情上** | 阳木（甲寅）多，比较耿直。<br>阴木（乙卯）多，表达比较委婉。                                                                                                        |
| **事业上** | 木，医疗，主要是中医，慈善、救助，衣服、手工等。<br>木克土，从事工程建筑、房地产行业较多。<br>木生火，从事从事文化，教育，传播这方面的事业。                                                              |
