# 气理象数·七政读盘框架

这张卡用于把盘面资料、六步推演与现实反馈接在同一条链上。它是通用读盘框架，不替代已确认的星曜、宫位、宿度、交感与专题断法。

## 四个层面

| 层面 | 在断事中负责什么 | 不能单独代替什么 |
| --- | --- | --- |
| 气 | 环境、状态、动力、时机与可发挥程度 | 不能只凭强弱直接判成败 |
| 理 | 生克、制化、条件、方向与转化关系 | 不能脱离实际主体与领域 |
| 象 | 星曜、宫位、宿度、干支等呈现的人、事、物 | 不等于已经发生的事实 |
| 数 | 多寡、先后、重复、节奏、时间与应期 | 不编造精确分数或日期 |

## 两条方向要分开理解

现实中的事情，会从环境与动力逐渐形成关系、显出形象，再呈现出程度、次序和时间；可记为：

```text
气 → 理 → 象 → 数
```

实际读盘时，看到的却通常是星、宫、度数、限运等可见资料。此时应从象与数回溯它们背后的关系和气势，再拿现实资料核验：

```text
象、数 → 理 → 气 → 现实反馈
```

这与本库总纲“先论气，后论理，再取象，最后断事”并不冲突：前者是**读取资料的入口**，后者是**形成判断与表达时不可倒置的推演顺序**。不能只见一个象便直接下结论。

## 六步如何接入

| 六步 | 主要调用 |
| --- | --- |
| 定题 | 明确对象、领域、时间、问题类型与可验证条件 |
| 取用 | 找到当前太极、病与药，确定谁是主体 |
| 生克 | 读“理”：谁作用谁、作用方向与转化条件 |
| 定量 | 读“数”：力量、数量、阶段、节奏与可达程度 |
| 流通 | 回到“气”：动力从何而来、经由何处、在哪里受阻或转化 |
| 叠象 | 用不同系统的“象”建立现实画面与独立证据链 |
| 外应 | 用当下真实信息与后续事实校验，不补造细节 |

## 结果不只分吉凶

同一条结构应至少分别看：

1. **实际所得：** 有没有机会、资源、位置或结果；
2. **主观感受：** 命主是否轻松、安心、有掌控感；
3. **过程代价：** 是否伴随压力、等待、责任、奔波或消耗；
4. **持续性：** 是一时显现，还是有原局与现实承接。

因此，生扶过多可能成为负担，克制也可能帮助强旺之物成形；所有判断仍须回到当前太极、实际力量、流通与现实条件。
