# 五行

五行是一组描述气的运动性质与作用方式的模型，不等同于五种静态物质。

- [木](../04-%E7%B1%BB%E8%B1%A1%E5%AD%97%E5%85%B8/%E4%BA%94%E8%A1%8C/%E6%9C%A8.md)：生发、成长、曲直。
- [火](../04-%E7%B1%BB%E8%B1%A1%E5%AD%97%E5%85%B8/%E4%BA%94%E8%A1%8C/%E7%81%AB.md)：炎上、表达、传播。
- [土](../04-%E7%B1%BB%E8%B1%A1%E5%AD%97%E5%85%B8/%E4%BA%94%E8%A1%8C/%E5%9C%9F.md)：承载、转化、藏纳。
- [金](../04-%E7%B1%BB%E8%B1%A1%E5%AD%97%E5%85%B8/%E4%BA%94%E8%A1%8C/%E9%87%91.md)：收敛、规则、从革。
- [水](../04-%E7%B1%BB%E8%B1%A1%E5%AD%97%E5%85%B8/%E4%BA%94%E8%A1%8C/%E6%B0%B4.md)：润下、流动、隐藏。

分析顺序：存在 → 季节状态 → 生克关系 → 是否通关 → 流通方向 → 现实取象。
