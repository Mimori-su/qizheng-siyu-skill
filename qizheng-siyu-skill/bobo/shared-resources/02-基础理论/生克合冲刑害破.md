# 生克合冲刑害破

- 生：给予、滋养、输出，也可能形成泄耗。
- 克：管理、约束、制衡、压力，不自动等于凶。
- 合：连接、合作、黏合，也可能牵绊。
- 冲：移动、变化、对立、重构。
- 刑：反复、纠结、内耗或持续压力。
- 害：隐性伤害、误解、小人或暗耗。
- 破：结构松动、持续瓦解。

必须结合 [旺相休囚死](%E6%97%BA%E7%9B%B8%E4%BC%91%E5%9B%9A%E6%AD%BB.md)、作用方向和 [流通](../01-%E6%A0%B8%E5%BF%83%E6%96%B9%E6%B3%95%E8%AE%BA/%E6%9C%AF%E6%95%B0%E5%85%AD%E6%AD%A5%E6%8E%A8%E6%BC%94.md#step-4%E6%B5%81%E9%80%9A) 判断。

## 地支关系结构

### 六合

子丑、寅亥、卯戌、辰酉、巳申、午未，按无向关系保存。合表示牵连、合作、亲近、黏合或缠住，不自动等于合化，也不固定吉凶。

### 六冲

子午、丑未、寅申、卯酉、辰戌、巳亥，按无向关系保存。冲先表示变动、对立、分离、打散、加速或转折；问移动、分离、解除或到达时，冲可能正好应象。

### 六害

子未、丑午、寅巳、卯辰、申亥、酉戌，按无向关系保存。害偏向暗中不合、阻碍、隔阂、暗损、猜疑或恶意，但关系本身不指定行为方。

### 三刑与自刑

- 子刑卯、卯刑子。
- 寅刑巳、巳刑申、申刑寅。
- 丑刑戌、戌刑未、未刑丑。
- 辰、午、酉、亥为自刑；必须出现同支重复或与本命、行年等形成重见，孤立出现一个支不成立自刑。

三刑按有向关系保存，不要求同组三支全部出现。

### 三合层级

- 完整三合：亥卯未木、寅午戌火、巳酉丑金、申子辰水。
- 半合：生支与中神，或中神与墓支。
- 拱局：只有生支与墓支，中神未现。
- 补局：缺少的中神由四课、三传、本命或行年等有效层级补入。

完整三合、半合、拱局和补局必须分级保存，不能把任意同组三支中的两支都称为完整三合。
