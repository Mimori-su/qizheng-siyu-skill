读表口径：四时按节气月令划分；昼为卯至申，夜为酉至寅。“正月”“五六月”等原称照录，不擅自视为公历月份。日月不套用普通五行生克，重点看气候、昼夜、月相与实际交感。星曜无交感时，不据此直接断本命事件；须待大限、度限或流年引动，运过后不再把该运事件当作持续发生。喜忌均有条件，不能以单星直接定吉凶。

简称：＝；＝；＝。

## 五星四时

| 星曜、时令 | 有利条件 | 不利条件及待核异说 | 条件与复核说明 |
| -------------- | ---------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| 木·春（春旺） | 孟春、正月寒未退，日照、火罗温木；二三四月根渐固后，火可通明、土可培植、金可琢削；夜生见有光之月另有取象。 | 一说初春水孛伤寒木，水过旺亦可木浮；同页又说“初春樨木，遇水滋荣”。**初春用水待核**；“樨”照录、标疑字。二三四月跨节气季界，不整段归春。 | 初春气数上不喜欢水，但是如果木太弱了需要一点水来生，最好同时见火暖。不然寒水冻木 |
| 木·夏 | 燥木喜水孛润；夏末秋初，**昼生躔四水度且与日交光**，另有济润之说。 | 火罗并行易增燥；夏末秋初**昼生躔四火度又与日交光**，有焦木之说。既说巳午月见金“无妨”，又说五六月见金则折，**待核**；有水救或火制金时须另论。 | 夏天的木就是不喜欢火，首先是气数上不喜，其次容易火多木焚。见金无妨是因为金在夏天处于死的状态，难克木，但见了还是会伤到木，但是不严重，所以说无妨 |
| 木·秋（条文称木死于秋） | 九月寒露附近，火罗助木可令其变化。 | 秋木弱时，又称见日凋、见火焚、见金残，水泛也未必有益。**秋火可助与可焚并列待核**，尤其要分秋初、深秋及木的实际力量。 | 还是喜欢水的，它只是有前提条件，说火焚，金残，此时见水帮不了多少。 |
| 木·冬 | 昼生日照、火罗温木；躔火度与日交辉，或有巳午未时的日光条件，可另论。另记冬木见金“祸轻”。 | 夜生、躔四土度又逢水孛，有寒木受损说；同时记“冬木遇水生，多承祖业”与冻水寒木、弱木漂流。**冬水两说待核**，不能写成“冬木恒喜水”或“恒忌水”。 | 多承祖业这种不用说。冬木不喜欢水生，会冻木了，此时见火暖才好生。 |
| 火·春（条文称火相于春） | 正二月寒，喜木炁生扶、火罗温养；夜生与月相交，晦月遇火增辉另有说法。木泄水而生火、土制水等，须形成实际制化链。 | 水孛可克火；一面说罗可为余奴犯主，一面又说罗可敌杀，须看它实际参与哪种结构。月朗而火明，另称火“不掌权”，不能只凭火月同会论喜。 |  |
| 火·夏（火旺） | 火过旺时，喜水孛制伏；入水宫、水度或得水照，可成水火相济。另记春末夏初火入水宫、水入火地的结构；若水来克而土能制水，可转化。 | 木炁再生旺火、火罗与太阳同会而无水，易过燥。但也说**火与水孛同行**受克：这与“分别入对方宫位”不是同一条件，不合并。 | 判断四时喜忌就是有很多条件与搭配，不能合论 |
| 火·秋 | 夏末秋初余热尚在，可借水济火；交秋初候遇水孛“不甚为害”。 | 到八九月又忌水孛、喜木炁；主火渐退时宜木炁、朝阳，金水可能使火更弱。**初秋用水与火退忌水并列待核**。末句“深秋之火以此同论？”原问号保留。 | 秋天气数喜水，此时火力还可，来一点水也行。来金水就太多了，来木气生也行但怕火炎土燥 |
| 火·冬（失时） | 三书均有木炁扶火、日光温火之说；所述“夜火贯日”还附带禄印爵贵同会条件。称宫度得生助、三方有助时，可承受部分水孛；土计确为用时另有正说。 | 多忌水孛；亦称水孛、土计、罗喉交互损火。**土计为助或为忌待核**，不能脱离“制水、助火”的实际链条。 | 土计为助的前提条件是火被水克，喜土制 |
| 土·春（初春偏寒、木渐旺） | 昼生与日交会、夜生得火照可暖土；另称土真正司令而旺时，木炁或可疏通。 | 初春土弱遇水孛易泥滑，木炁再克更受压；春末夏初条文另有“四五月洪水”说，不能算作整个春季。“四柱空地”含义尚不明，**不等同于已确认的落宫地支填实规则**。 |  |
| 土·夏 | 热土喜水孛润，**同宫或三方对照**条件更明确；称土确实过旺时，木炁可制。 | 火罗过多、昼生再受烈日照而无水，易燥。同时存在“土旺于夏”“夏土相”两种原词，先并存，**不换算成统一分值**。 | 土旺于夏”“夏土相”的意思是描述土的四时旺相休囚的能量状态。 |
| 土·秋 | 夏末初秋尚热，喜水孛济润；若秋金泄土、土已弱，则喜火罗或日温。 | 前一种情况忌火日无水而焦；后一种情况又忌水孛使弱土更弱，并忌金泄、木克。**秋土取水还是取火待核**，先分月令早晚及土本身强弱。 | 这些比较和取用都是有前提条件的，要对比力量大小，分析对了喜用自然不同， |
| 土·冬 | 三书多喜太阳温土、火罗助暖；另有水→木→火→土逐层转化的例子，须逐环实际成立。 | 水孛同躔或躔水更寒；另称尤忌计奴。木单独来克土，不能因“木可泄水”就直接判喜。 |  |
| 金·春（条文称春金囚、柔弱） | 初春寒未退，火罗可温炼；土计高强生扶可用；另有条件认为火土同居时，水孛可不忌。 | 水孛同行可助寒、泄金，缺火日尤须慎；火的作用限于寒金需温，不能外推为春金一律喜火。 |  |
| 金·夏（易销烁） | 五六月炎蒸，水可制火；土计同行仍须水孛拱照，燥土才可能生金。 | 火罗过烈、五六月夏日或七八月秋阳暴照，均有烁金说。原句“**夏令之金、不宜生水、就赖水以制其刚**”前后语义相冲，**原样保留待核**。 |  |
| 金·秋（司令、偏旺） | 三书：水可泄旺而显清，火罗可炼旺；特别提八九月火罗。夜见月、昼同日各有取象；金水朝拱日还须满足组合。 | 土计再生可能埋金；原注也提醒木、土、水、火、金任一过盛均有弊。这里的“喜水火”以金确实旺而需要泄、炼为条件。 |  |
| 金·冬（寒凝） | 昼喜日光、夜喜火罗；土得阳温后可助金。特别提十一、十二、正月的寒凝条件。 | 水孛交互增寒、泄金；限定在水孛又坐寒宫、三方缺火日土木时更不利。另有冬金见月不利说。 |  |
| 水·春（初春尚寒） | 木炁、火罗可温化；昼生水孛与太阳同行，有解冻说；二三月转和后，水可济润。 | 同条说忌金交互；却说“水生春夏，遇金则吉”，**春金吉忌待核**。“昼生为妙，夜生贫寒”所指前项在原段中也需复核；四五月泛滥另论，不统归春。 |  |
| 水·夏 | **水盛、泛滥**时，喜旺土堤防、木炁疏泄。 | 另说六月水被火日枯涸、七八月旱时再逢土计不利，应重金水生扶和垣殿；夏水与日同宫也有“日炎水沸”说。**水盛与水弱是两支**。条文“至四七月”照录为疑字，暂不据此划月份。 |  |
| 水·秋 | 七八月水量足时，土可堤防，水亦可润土；称秋值金、与日同行另有正面取象。 | 水已经受克、泄而气脉虚时，不能再套“土堤防”作喜；秋金生水也须先核水是否需要增量。 |  |
| 水·冬（得令而易冻结） | 火罗、太阳可解寒；**水确实过盛**时土计作堤，木炁可泄旺。十一、十二、正月另分昼借日、夜借火罗。 | 金再生水、金水宫再增寒有不利说；另称月亮增寒不喜。“得令”不等于在冬季可以不调候。 |  |

## 太阳、月亮：以气候、光照和月相另列

| 星曜、时令 | 条件性喜忌 | 待核之处 | 条件与复核说明 |
| ----- | ------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------- | --------- |
| 日·春 | 分**初春**喜火罗、木炁温助，金水反不利，土计晦光；**春深**阳气渐旺，反喜金水土计，忌火罗木炁。称春夏木炁叶盛可蔽日，但夜生减轻、带吉化又有例外。 | 同页既说水金佐日，又将水孛、土计、**金**列为不宜交会的“云雨星”，**待核**。既定规则为“日不喜木炁遮蔽、火罗争光”为基本警惕；初春例外不自动改成通则。 |  |
| 日·夏 | 喜水孛济润；喜金水、土计相照；两书均忌木炁火罗增燥、争光。 | 仍要看水与日是否真正交感及水的力量，不把“见水”直接写成吉。 |  |
| 日·秋 | 余热尚重时喜金水相辅；**深秋**阳气渐衰，木炁、火罗又可助。 | 秋初与深秋方向不同；不能把深秋木火助日套到全秋。 |  |
| 日·冬 | 重温暖：午时、夜生得火罗有利；称十一、十二、正月金水不宜径作“从阳”，但巳午未时单金、独水又可另论；冬不论昼夜喜火罗、次木炁。 | 夜生忌水孛土计遮日，却说土计“亦有益”，**待核**。罗近日遇朔：“惟朔则不吉”，另有说法“晦朔夜生，日喜罗助，冬月最妙”，**直接相反，待核**。 |  |
| 月·春 | 晦月不按明月论；喜得时的日照，夜月见木炁、火另有助益；木带桃花且二月等条件构成特定组合。 | 土计遮月、孛随月掩光为忌；不能只凭“木月”“火月”两字套用特定组合。 |  |
| 月·夏 | 称水孛润而不寒、火罗照而不燥，喜木炁、忌土计；夜月可喜金，昼借日。称火罗若带官魁、文印等吉化可另论。 | 又说五六七八月若火罗带刑囚暗耗、羊刃，或望夜近月、夏秋昼生同居，可争光；则概称夏月喜金水、**不喜火罗**。**火罗三说并列待核**。 |  |
| 月·秋 | 喜水、金；木炁会月、孛伴月另有正面组合。称深秋火罗可用。 | 弦望火罗争光两书均提醒；晦朔土计，忌，昼生可无妨，**待核**。 |  |
| 月·冬 | 寒月昼借日、夜借火罗；忌水孛增寒，夜逢土计尤其须慎。对单金、独水、巳午未时日同、三方四正火罗拱照另列例外。 | 另有说法认为冬木炁扶月“无益”，与既定的“月喜木炁来清风”总原则有差异，**保留待核**，不擅自改掉总原则。 |  |

日、月须分别核对昼夜条件。月亮还须核农历初几、朔望晦明；这属于光照条件，不是重新按普通五行给日月定旺衰。
