# 七政四余定太极方法

七政四余的星曜、宫位、星宿、神煞、长生、化曜、纳音和八卦提供了丰富的取象语言。真正断事时，必须先确定当前问题的观察中心。

但字典越厚，看盘不一定越容易。真正拿到一张盘时，如果不知道这次到底要看什么，所有词条都会同时跳出来：看到月亮想起母亲，看到火星想到冲突，看到桃花又转去说感情，最后每句话都像有道理，却没有一句真正围绕问题。

所以进入方法篇以后，第一件事不是继续增加类象，而是先确定观察中心。

> **先定太极，后取其象。**

## 15.1 什么叫太极点

太极点，就是**当前所问之事在盘中的观察中心**。

“太极”听起来很大，实际用法并不玄。你想看谁，就先确定谁是中心；你想看哪件事，就把观察范围转到相应领域。中心一旦确定，盘里的其他星、宫、度和各种类象，才有了远近、主次和作用方向。

例如，同一张本命盘可以问很多问题：

- 看命主整体，中心是命主本人；
- 看事业，中心转到命主与官禄领域之间的关系；
- 看财富，中心转到财帛领域以及钱怎样进入命主；
- 看配偶，不只看感情气氛，还要找到配偶这个对象；
- 看某次工作机会，还要继续缩小到具体事件与时间范围。

可以把太极的层级理解成：

> **人 → 领域 → 事件 → 时间。**

层级越往后，问题越具体，能调用的象也越集中。

### 先把问题说清楚

定太极之前，先完成一个简单的问题契约：

| 要确认的内容 | 要问清楚什么 | 例子 |
| --- | --- | --- |
| 人物 | 看谁，事情涉及谁 | 命主本人、母亲、配偶、合作方 |
| 领域 | 看哪一类人事 | 事业、收入、婚恋、家宅、健康 |
| 事件 | 是总体倾向还是一件具体事情 | 整体事业，还是这次换工作 |
| 时间 | 看原局基础，还是某限某年 | 本命倾向、未来三年、某次流年 |
| 结果标准 | 什么叫成，什么叫不成 | 收到录用、签下合同、资金实际到账 |

“我以后怎么样”太宽，很难定中心；“今年这次转岗能否落实，主要阻力在哪里”就清楚得多。题目越明确，后面的主证据越容易收束。

这里也要分清“定太极”和“找用”。定太极回答的是**看谁、看什么**；找病药和用神回答的是**什么在帮助它、什么在阻碍它**。中心还没有确定，便急着找喜忌，很容易连帮助谁、伤害谁都说不清。

## 15.2 为什么一定要先定太极

一颗星可以同时拥有很多类象，但当前问题只会调用其中一部分。

以月亮为例：

| 当前问题 | 月亮可能承担的角色 | 还要与什么合看 |
| --- | --- | --- |
| 问母亲 | 母亲、女性长辈、照顾者 | 家庭与父母相关领域、对象宫主、印与养育类象 |
| 问情绪 | 安全感、内在需要、情绪波动 | 身主、身度主、福德和相貌领域 |
| 问身体状态 | 睡眠、体感、液体及周期性变化的传统象意 | 疾厄领域、身主、实际身体信息；不能代替医学判断 |
| 问婚恋 | 女性一方、情感需要、相处中的感受 | 夫妻与男女领域、配偶对象太极、关系证据 |
| 问事业 | 公众、女性客户、照顾型工作或内在承载 | 官禄主线与化曜；也可能只是一条辅助象 |

如果问题是母亲，月亮的母亲象会提高权重；如果问题是事业，月亮未必就是母亲，可能是在说明公众、女性客户、服务方式或命主的心理承载。

这就是为什么不能“看到月亮就断母亲”。类象只是可能范围，太极点才决定当前该从哪个入口读取。

太极还有另一个作用：确定生克的方向。同一个克，对被克者是压力，对主动控制者却可能是管理和投入；同一个生，对受生者是资源，对生出者则是输出和消耗。中心不同，所看到的得失就不同。

## 15.3 没有固定最重要的星

看盘时，经常有人问：“到底命宫主最重要，还是命度主最重要？月亮是不是永远比其他星重要？”

更准确的回答是：

> **没有脱离问题以后仍然永远最重要的星，只有当前问题里的重点太极。**

这不代表三主没有轻重，而是三者各自负责不同层面：

| 观察任务 | 主要入口 | 主要回答 |
| --- | --- | --- |
| 命主本人 | 命度主 | 命主核心、直接承受与主要动力 |
| 外部环境 | 命宫与命宫主 | 命主站在什么现实环境中，怎样对外承接 |
| 身心感受 | 月亮与身度主 | 身体、情绪、心力与内在承载 |
| 具体事业 | 官禄领域及其主星 | 工作、职位和社会责任怎样展开 |
| 具体财富 | 财帛领域及其主星 | 资源怎样形成、流动并与命主连接 |
| 具体对象 | 对象宫位的宫主星 | 对方本身怎样，与命主怎样发生关系 |

看命主整体时，本书以命度主定位命主核心，命宫主和身主从环境、身体与内在感受补充。但问题转到事业、配偶或子女时，就必须增加相应的专题与对象太极。不能因为命度主重要，问所有事情都只围着命度主转；也不能因为月亮在古法中受重视，便把每件事都解释成情绪或母亲。

“重点”永远是相对当前任务而言的。命度主是命主锚点，专题太极是事情入口，对象太极是人物入口，它们不是互相取代，而是共同组成一条有主次的判断链。

## 15.4 主太极点与辅太极点

一次判断可以有多个观察点，但不能有一堆同样重要的中心。

### 主太极：决定这次到底回答什么

主太极是当前问题最需要解释的对象或事项。它负责定方向，也负责筛选类象。

具体问事时，还要始终保留命主锚点。因为“盘里有财”不等于“钱能到我手里”，“夫妻宫有象”也不等于“我与对方一定形成关系”。专题太极要与命度主发生实际联系，事情才真正属于命主。

所以一条完整的主线常写成：

> **命主锚点 ↔ 专题太极／对象太极。**

### 辅太极：负责交叉验证和补充过程

辅太极不是第二个结论中心，而是围绕主问题提供独立证据。它可以说明来源、过程、身份、结果或时间，但不能喧宾夺主。

以财运为例：

| 层次 | 观察内容 | 主要作用 |
| --- | --- | --- |
| 命主锚点 | 命度主 | 判断这笔资源是否与命主真正连接 |
| 专题主太极 | 财帛宫与财帛主 | 判断财富领域的基础、来源与流向 |
| 领域辅证 | 财帛宫内星、对宫与三方 | 补充赚钱环境、过程和参与者 |
| 来源辅证 | 官禄、田宅、迁移等相关领域 | 区分工资、长期资产、异地机会等来源 |
| 身份辅证 | 财、禄及相关化曜 | 说明资源以收入、项目、职位或其他身份出现 |
| 时间层 | 大限、限度和流年引动 | 判断原局中的财象何时被启动 |

若问的是工资，官禄与禄位的权重会上升；若问房产，田宅会进入主线；若问某笔外地项目款，迁移、合作对象和合同信息也会被调用。问题一变，辅助证据的排序便跟着变。

辅证越多不等于结论一定越准。只有来自不同层次、确实指向同一件事的证据，才算有效重合。同一个软件标签换几个近义词，仍然只是一条信息。

## 15.5 论本人与论六亲，不是同一个太极

看命主本人时，以命度主为核心；看六亲和其他对象时，观察中心要转到对方，但仍要保留对方与命主之间的关系。

| 所问对象 | 对象入口 | 需要补看的信息 |
| --- | --- | --- |
| 命主本人 | 命度主 | 命宫主、月亮与身度主 |
| 父亲 | 田宅等家庭领域的宫主，并参考太阳的天然人物象 | 与命主的作用、家庭领域及相关时间引动 |
| 母亲 | 月亮等母亲与养育象，并结合家庭领域及其宫主 | 同宫星、躔度、印与承载类象，以及与命主的作用 |
| 兄弟姐妹 | 兄弟宫主 | 兄弟宫内星、同辈类象及与命主的关系 |
| 配偶 | 夫妻宫主 | 夫妻宫是关系场域，宫内星描述相处氛围；再看与命主的联系 |
| 子女 | 男女宫主 | 男女宫内星、子女天然象及养育、承接信息 |
| 下属或员工 | 奴仆宫主 | 团队执行、劳务环境和与命主的上下关系 |

这张表只说明入口，不代替应用篇的专题规则。真正使用时要注意两点。

第一，**人物和领域不能混为一谈**。夫妻宫说明婚姻与合作这个场域，夫妻宫主更贴近配偶对象；宫内星说明什么力量进入关系，并不自动等于配偶本人。官禄宫里有火星，可能是工作环境急迫、行业带火象或过程多竞争，不等于上司一定就是火星性格。

第二，**天然人物象不能单独取代对象太极**。太阳可以代表父亲，月亮可以代表母亲，但只有当家庭领域、对象宫主、化曜或其他证据共同指向时，人物判断才更稳。反过来，多套系统同时指向母亲，月亮、养育之象和印曜又被时间引动，母亲便会成为当前重点。

太极转换并不是把命主丢掉。看配偶时，既要看配偶本身，也要看配偶怎样作用命主；看子女时，既要看子女的状态，也要看命主是否能够承接养育过程。只看对方，不看双方关系，仍然无法回答“这件事对我意味着什么”。

## 15.6 太极改变后，什么会跟着改变

太极一换，至少有四件事会变化。

### 一、星曜的角色会变

同一颗月亮，问母亲时是人物主象，问事业时可能只说明公众、女性客户或身心承载；同一颗金星，问财富时可以取钱财与交易，问感情时则可能取关系、审美或年轻女性。

星曜没有变，当前被调用的类象变了。

### 二、生克身份会变

恩、难、余奴、仇、用都围绕太极而定。例如以木为太极时，水是生木的恩，火是木所生的用，金是克木的难，土是木所克的仇；若改以金为太极，土转为恩，水转为用，火成为难，木成为仇。

因此，不能把某颗星永久贴成“恩星”或“难星”。太极不同，它与中心的关系也会改变。太阳、太阴仍按前文的光体规则另论，不机械套入普通五星四余的五行身份。

### 三、同一件事的得失会变

一次升职，对事业太极可能是成果，对身主却可能是压力；一笔购房支出，对短期现金流是消耗，对田宅积累却可能是资产增加；结束一段合作，对关系领域是分离，对摆脱长期牵制又可能是解决问题。

所以“吉凶”不能脱离对象。必须说清楚：对谁有利，对哪个领域有利，代价落在哪里。

### 四、证据权重会变

问婚恋时，夫妻、男女、配偶对象与相关化曜权重提高；问事业时，官禄、命主与职位承接更重要。原本很显眼的桃花，在事业问题中可能只是社交修饰；原本不起眼的官禄主，却可能成为判断能否落实的关键。

换太极不是任意换说法。每次转换都要有明确理由，并在文字里说明当前站在哪个中心看。否则前一句以命主为中心，后一句突然站到配偶或上司的角度，结论会互相打架。

## 15.7 没定太极时最常见的错误

| 常见错误 | 实际表现 | 修正方法 |
| --- | --- | --- |
| 问题太宽 | “看看我以后怎样”，什么都能说 | 先限定人物、领域、事件、时间和结果标准 |
| 围着显眼星曜转 | 看到月亮说母亲，看到桃花又改说感情 | 先写太极，再决定哪些类象与问题有关 |
| 把一颗星当永恒中心 | 所有专题都只看命度主、月亮或某颗吉星 | 保留命主锚点，同时增加专题与对象太极 |
| 把人物与场域混淆 | 夫妻宫内星直接等同于配偶本人 | 宫位看领域，宫主看对象，宫内星看进入领域的力量 |
| 同时设置太多主太极 | 每颗星都很重要，最后无法定结论 | 只保留一条主线，其余降为来源、过程、结果或时间辅证 |
| 先定吉凶再找证据 | 先觉得某星吉，再把所有信息解释成好事 | 先定中心和关系，再看力量、流通与承接 |
| 判断中途暗换角度 | 前面说对命主有利，后面又用配偶立场下结论 | 每次转换都明确写出“现在以谁为中心” |
| 忘记现实成立标准 | 只见象，不知道怎样才算应验 | 事先说明到账、签约、入职或关系落实等可核对结果 |

实际看盘时，可以把定太极压缩成六个动作：

1. **定题：** 这次到底问什么？
2. **定人：** 看谁，涉及谁？
3. **定领域：** 事情落在哪个人事宫？
4. **定主线：** 命主锚点怎样连接专题或对象太极？
5. **列辅证：** 哪些信息负责来源、过程、身份、结果和时间？
6. **定标准：** 现实中出现什么，才算事情真正成立？

完成这六个动作，才进入六步骤分析法的病药、生克、旺衰和流通。这样做看似多了一步，实际上会省下大量无效联想。

太极点确定以后，再围绕当前中心读取星曜、宫位或化曜的单一信息，并逐步建立叠象证据链。
