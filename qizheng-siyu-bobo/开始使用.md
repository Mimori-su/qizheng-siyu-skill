# 七政四余74技能分享包｜开始使用

版本：2026-10-14-r5。保留作者与来源署名。

## 加载

1. 解压后保留整个 qizheng-siyu-full 文件夹，以根目录 SKILL.md 为总入口。
2. 交给支持本地 Skill 的工具加载；有本地文件读取能力的其他助手也可以按总入口读取子技能与资源。不能只复制 Agent 文件。
3. 包含 1 个总控和 13 个子技能，共 14 个入口。已有 disable: true 标记保持，相关入口仍已包含。
4. .codebuddy-plugin 是既有宿主配置；其他平台采用其实际导入方式，不保证所有平台直接兼容。

## 内容与使用

现行四时条件、本命格局系统、格局报告模板与来源说明已补入 shared-resources。财运包含财富层级判断清单和关键财富上升期及同步事件规则。

先提供完整郑氏星案恒星制盘面；只有出生资料时，不凭空推造本命星位。要求“不存档”时留在对话／内存。

> 使用 qizheng-siyu-full，分析2027年财运，先补算小限、飞限与节气月限。[粘贴原盘与限表]

## 可选计算

文字读盘不要求安装 Python。运行流曜和限运工具时，使用 Python 3.10 或更高版本，并在自己的虚拟环境安装依赖：

~~~bash
python3 -m pip install -r qizheng-siyu-expert/skills/qz-reader/scripts/transit_requirements.txt
~~~

PDF 提取／渲染另需 PyMuPDF；文本提取可选 pdfplumber 回退。

十一曜工具自测：

~~~bash
python3 -B qizheng-siyu-expert/skills/qz-reader/scripts/calculate_transits.py --at '2026-10-09T12:00:00+08:00' --mansion-profile xhcl_original --format md
~~~

小限、飞限、节气月限可自动补算；完整洞微宫限和度限仍沿用可靠原盘。宿界、月孛和时间口径必须一致，单点流曜不能代替全年。

回归测试：

~~~bash
python3 -B -m unittest discover -s tests -v
~~~
