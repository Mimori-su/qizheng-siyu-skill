# 七政四余命理分析师 · 专家包

本目录保存 Agent 定义、插件配置、13 个子技能及参考资源。总入口与完整使用说明在上级 `SKILL.md`、`README_INDEX.md`。

## 使用

- 先提供排盘文本、PDF 或清晰截图。只有出生资料时，不凭空推造七政四余星位。
- “查看七政四余使用指南”：了解可问专题与输入要求。
- “帮我简要看看”：已有完整盘面时生成首次总览。
- “详细分析性格”“分析婚恋”“分析某年运势”：按所问专题输出。
- “不存档”优先，不要求为了工作流额外落盘。

## 加载与当前边界

- 总控包的技术标识为 `qizheng-siyu-full`，子技能位于本目录 `skills/`。不要仅复制 Agent 文件而遗漏资源。
- `.codebuddy-plugin/plugin.json` 是现有插件注册配置，不保证其他宿主直接兼容。请用目标宿主支持的本地导入方式；本包没有自动注册脚本，不提供不存在的注册命令。
- `qz-health` 已启用；学习整理、择日、校时仍保留原有 `disable: true` 标记。这是配置状态，不等于已实测所有宿主的加载行为。
- 官非归入事业、财运。旧独立官非模块及校时关键词计分器已退役，不随分享包提供。
- 程序负责提取、校验、模板生成，不是自动排盘或自动断事引擎。文本解析只生成低可信度初稿，完整契约仍需复核。
- 依据已给十二宫、出生时间及限表，自动补算小限、飞限和节气月限；立春与年中换限采用当前规则。完整宫限与度限仍由可靠原盘提供。
- `assemble_report.py` 仅拼接内部旧稿，不生成客户模板报告，也不能代替 `qz-report` 的整合判断。

## 辅助脚本依赖

Python 3：文本解析、校验、核心框架生成和旧拼接器只依赖标准库。PDF 文本提取使用 PyMuPDF（导入名 `fitz`），可回退 pdfplumber；PDF 渲染依赖 PyMuPDF。缺依赖时须明确报告，不把空文件当提取成功。具体命令参数查看对应脚本的 `--help`。
