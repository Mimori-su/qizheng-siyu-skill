## 1. 总纲：外界给予与本人承受分开

- 财运、事业在本专题中看外界给予本人的钱财、资源、人脉、名气、社会地位。核心问题是：**从哪里得到什么好处，怎样得到，付出什么代价。**
- 命度主、身度主看个人与外界交互；旺不等于有财官，弱不等于无财官。不得以“身弱难任”直接否决财源和社会成就。
- **一颗旺星真正得用，也可形成取得大财富、名气的关键条件**，无需为了判好凑齐许多吉星；“旺”却不是“得用”的充分条件，仍核实际交感、受制、救应、来财路径和限运。同星多职不重复计证，不凭星数累加财富。
- 取得财富／名望，与有没有身体、福气承受和享用分开。**月亮与身度主一起判断承受和享用，各查其本宫、对宫、两三合宫的星体及作用**，不能只读两个主星本身。求财劳损另看命度受克及寿元星。只作传统取象，不诊断疾病或推断寿命。
- **日月既参与承受，也参与财富层次**：日月会财、日月联系命身都可带来贵人和机会，分别记录资源到财源与资源到本人的路径；不把后一条收窄为生活舒适，也不要求日月必须直接会财才认可贵助。具体见第10节。
- 先继承结构化盘面、十一曜力量和原局喜忌。无文件但对话已完成上游结果时可沿用并复核，不为流程强制存档。

## 3. 分析顺序与财富层次

继承原局 → 分列财源太极并核有效通道与可用性 → 出身与家庭资源 → 本人承接与自主创造 → 财富形态、归属与实际支配 → 留存、分配和传承 → 接限运看阶段变化 → 分轴判断层次与个人承受 → 双层输出。先有支持／制约证据，再下层次结论；客户写作顺序仍为结论先行。

1. 分列命宫／命宫主、命度主、月亮、身度主，不再用未展开的“三主／身主”缩写代替。核财源与本人的交感；承受与享用由月亮、身度主及各自本对三合的星体共同判断，不把“有财源”和“自己舒服”合成一个判断。
2. 逐星看四时、昼夜／月相、入垣升殿、落宫与躔度生扶克泄、四柱落宫地支填实、受制及救应；继承 qz-wangshuai，不编分数或加权公式。
3. 直接作用仍限本宫、对宫、两三合宫、实际同躔七曜属性宿度。仅有本体相生或化曜名相配而无通道，不串联；限运建立的临时联系标明时段。
4. 恩星、财星、日月力量决定帮助和财源量级；财星越旺、财源越充分，发展空间越大，前提是核过受克与可用性。财星兼恩星时，既看财源也看直接扶助本人；日月会财、联系命身及禄马贵曜会财的帮助分别加入比较。受克继续看损伤、制化，不抹掉全部财象。
5. 食伤生财、财生财说明财源。**财生田、福生财不只限宫主生宫主，宫内星及年干正偏财也可参与**；逐端记录其财、田、福身份来自掌宫、落宫还是化曜，再核实际作用方向和通道。不可因星曜有财的标签或同处某宫，便自动把结构判为成立。
6. **总评必须回应财富层次，但不用单一终身标签**。按第10节区分出身、自主求财、阶段所得、积累与传承；定性层级与已确认的千万级经验条件均可用，必须带主体、维度和时段。多路旺财及其供给、承载应综合评估更高规模，不能发现首条旺财就停在千万；未教明的金额边界、固定分值与单星金额公式不补造。证据不足以细分时给有据范围或缺项，不强行拔高。
7. 取得、持有形态、实际支配、留存、个人承受、兑现时机分别给结论。家庭资源、企业资产、受托或平台可调动资金不是本人资产；高收入、账面高峰和最终积累也不同。身体和体感压力不自动抵消强财源。

## 4. 财源在哪：每条财路分开解读

逐条写为：**财源星 → 生扶／制约者 → 双方星性、落宫、掌宫、化曜、宿度、相关神煞 → 行业／岗位／人物 → 得财方式及代价。**宫主定位人物与资源来源；宫内星和宫位体系描述活动、氛围。落宫与掌宫都看，不把任一项当唯一因果。

### 建议求财路数：更来财与更喜欢分开

- **更有来财条件的领域**：比较本盘各条财源的力量、与本人交感、支持、受制与实际可用性；明确适合从事的领域及取得收入的方式，说明为何值得优先经营，不只列星名或行业清单。“最来财”是已分析财路间的相对判断，不是保证某行业收入最高。
- **本人更喜欢、愿意投入的领域**：看气数喜忌、用星及原局作用；再核这份喜好是否接到有效财源。喜欢不等于最赚钱，也不因“是用星”就认为没有代价。
- 两者相合，合并成重点路数；两者不同，明确比较赚钱空间、体感与成本，让客户看见取舍，不擅自要求只选其中一条。无证据支持的兴趣不包装成副业收入。
- **每条推荐路数都附成本和代价**：从具体作用链取学习／技能投入、时间精力、回报等待、奔波、合作分利、资源依赖、竞争或责任压力等。只写有依据的项目；精力、身体与享用由月亮和身度主相关结构复核。缺现实资料不编投入金额、成本比例或健康诊断。
- 统一写成“适合领域 → 做什么／靠什么得财 → 谁或什么支持 → 为什么更来财或更合心意 → 需要付出的成本与成立条件”。这里只给职业、服务、经营方向的取象，不给证券标的、杠杆、下注或具体交易建议。

### 财生财与财克财：两层分别记录

先读 `../../qz-core/resources/tianguan_analysis.md`。实际交感成立后，果老本体和天官化曜关系分别读象，方向不可混淆；本体相克可与化曜相生并存。

- **财生财**：财身份的 A 支持财身份的 B，说明 A 领域资源支持 B 领域，可取投资、持续投入、业务扩展。丙丁年水与炁为老师示例，正偏财按表分别读，水生炁须有通道；单向投入不等于收益闭环或必赚。
- **财克财**：两端有财的身份，同时存在制约。壬癸年正偏财为金、木，实际交感下金克木，可读赚 A 领域的钱影响 B 领域的财，也可取交易或资源交换。写清原因、方向和利弊，不能固定为破财。
- 两例是“财的身份叠加星曜作用”，不是十神同为财就自行相生相克。食伤生财等另按变五行身份关系记，本体制约不取消化曜事件象，化曜吉象也不抹掉代价。

## 6. 财库、支出、分利与破财

### 财库与积累

- **财库主要看田宅，重点是库是否被破**，不是仅见财星入库便判留得住。结合田宅及相关星曜的实际受克、交战、余奴／劫财作用与救应说明库的完整性，不见某个凶名便判破库。
- 收入、现金流、积累分别判断；有收入不等于已积累，分出部分也不等于财源全无。
- 库的对应：**水—辰、土—辰、木—未、火—戌、金—丑**。土—辰为老师本轮追补。此映射辅助田宅判断，不套别派“逢冲即开库／发财”规则；“库被破”的具体强度界线与案例待补，不捏造开闭算法。

### 钱花到哪里

| 作用 | 区分的现象 |
| --- | --- |
| 财星／财帛主被泄 | 正常花销或支持另一领域，查接受者本义及落掌宫；连到田宅可取给家里／父亲钱，不能脱离实际关系固定如此 |
| 财生财 | 投入另一财源，投入与回报分开 |
| 财克财 | 交易、交换或两财路相互影响，说明方向，不直接当净亏损 |
| 财受克、比劫克年干财、余奴克财 | 合作分钱、主动投入，或竞争和利益损害；主动／被动暂以“或”并列，不用尚未确认的条件擅自单选 |
| 难星、余奴参与 | 压力、分权、利益损耗、烦心；连到男女可涉及恋爱／吃喝玩乐支出，须有作用路径 |

## 8. 财富来源、承接、创造与流向

本节是本轮确认的整理框架。每条链都沿原局实际交感、旺衰、喜忌、受伤与救应，再叠星性、落宫、掌宫、化曜、宿度和神煞；不能仅按人物宫名编出财富事件。

### 出身与家财承接分开

- **家庭资源**：父母／祖辈的经济基础、房产或家业，以及教育、人脉、平台支持。父母定位另读 `../../qz-core/resources/parents_framework.md`，不把父母有资源直接写成本人富有。
- **本人承接**：分开日常供养、教育投入、居住支持、经营家业、取得资产或权益、继承。能享用、能代管、能参与经营和已经归本人所有是不同结果。
- 逐段核“资源来源 → 提供者 → 传递或阻碍 → 本人所得”。某段没有实际通道时标缺口；A→B、B→C 不改写为 A 与 C 直接交感。支持到达与本人感受分别判断。
- 家庭资源雄厚但本人取得有限、家里起点一般而靠自己累积、家庭提供起步条件后本人扩大经营，均须允许并存或分阶段变化。未取得的家财不计当前个人积累。
- **尚未建立“继承取得／只能受助／承接受阻”的专用判据**。现有证据只能支持到哪一层就写到哪一层，不以恩星旺、田宅好直接确认产权或遗产归属，不推断亲属死亡时间。

### 自主创造与再投入

继承第2–7节的财源身份与取象，不重建一套财星：比较自己创造收入的本领、外部资金／平台的帮助、实际取得和逐路代价；家庭资本与本人经营贡献分开。财生财可描述继续投入另一财源，投入、回报、再投入分别核，不把一次投入写成持续盈利。

### 伴侣、子女与财富双向流动

| 方向 | 要回答的问题 | 不可混同 |
| --- | --- | --- |
| 伴侣 → 本人 | 带来资金、资源、机会，还是分担生活成本 | 对方有财不等于本人已取得；共同生活受益不等于个人产权 |
| 本人 → 伴侣 | 日常支出、共同经营、分配或权益转移 | 共同家庭投入不自动等于败财 |
| 子女 → 本人 | 直接给予、带来机会或支持家庭经营 | 子女有成就不等于给本人钱；儿童相关业务不等于由子女带财 |
| 本人 → 子女 | 抚养教育、创业支持、赠与或传承 | 主动安排与被动损失分开，不把给子女一概说成留不住 |

关系主体须先定位，男女宫的恋爱、娱乐和子女含义按所问、现实年龄和反馈区分；子女专题细节另读 `../../qz-children/resources/children_framework.md`。每条分别核提供者与接收者身份、方向、实际通道、力量及行运；不能仅凭相生认定已经收款。专用的子女带财与转移判据尚待补充，不从一般关系自动生成。

### 留存、形态转换与损耗

沿第6节区分正常消费、家庭责任、合作分利、再投入、财富转移与真正损耗。现金变房产、股票或企业份额首先是形态变化，是否形成价值、能否持续持有另核；不能因现金减少就判败财，也不自动判投资成功。将资产给予伴侣、子女时分别记个人口径与家庭口径，不能把两者混为同一份损失。比劫／余奴克财的主动与被动区分仍保持原待补状态。

## 9. 财富形态、权属与实际支配

### 持有载体与现金流分轴

| 持有载体 | 内容 | 分开记录 |
| --- | --- | --- |
| 现金与存款 | 已到账、可支配的钱 | 现有余额与期间收入 |
| 房产与实物资产 | 住宅、商铺、厂房等 | 自住／出租／经营使用／出售及相关成本 |
| 股票持仓 | 上市公司股份 | 持仓价值、分红和卖出所得；不预测价格或回报 |
| 企业股权、合伙份额 | 自营、参股或合伙经营中的权益 | 企业整体规模、本人份额、实际分利及退出所得 |

现金流是持续流入／流出的表现，不是与上述载体互斥的资产类别。房产可带来租金，股权可带来分红；产权是权利归属维度，不额外算一份资产。房屋、店铺还须区分持有物业、租用场所经营与持有经营公司份额，不能见“店铺”就确认拥有房产。

每项资产分别问：**来源 → 谁拥有 → 本人可以使用／经营／处置／取得收益的范围 → 是否持续产生收入 → 兑现条件 → 负债和维持成本 → 最终流向 → 时段**。这些是记录维度，不是评分或估值公式。现实权属、份额及负债需要现实资料确认，盘面只提供传统取象线索。

- 家族或企业总资产、营业流水、管理规模，不直接算本人财富；共同持有也不全额归本人。
- 持仓估值、分红收入、出售回款分列，不能把同一权益及其变现再次累计成几份财；存量用时点、收入用期间。
- 待收款、未兑现权益和未来继承与已到账现金分开；缺金额与权益资料时只做质性画像，不编净资产。
- 可描述“资产厚而现金偏紧”“现金流强而资产积累较少”“权益占比较高、兑现待时”“资产与持续收入兼备”，它们不是自动高低排序。

### 接入已有取象，不新增单点判法

财帛看现金流与可动用资源，田宅看房产／店铺／固定资产和积累，疾厄＋财星涉及股权投资及负债，兄弟／夫妻＋财星可涉及合伙。所有入口都须有完整作用链；**尚无把股票、非上市企业股权、合伙份额或具体产权逐项锁定的专用规则**，不能指定“某星旺＝股票获利”或“某宫＝已经有房”。财富形态转换的具体年份仍接限运，不因年运见财便写成到账。

## 10. 财富层次：四轴判断，带主体与时段

| 维度 | 判断对象 | 关键区别 |
| --- | --- | --- |
| 出身层次 | 家庭可提供的物质与资源起点 | 家庭基础与实际给到本人分开 |
| 自主求财层次 | 本人创造财源、经营扩大与持续获得收入的空间 | 个人贡献与外部资本／平台分开 |
| 阶段所得层次 | 某一步运真正取得、持有和可以支配的财富 | 峰值、当前持有、现金流与兑现分别说明 |
| 积累与传承层次 | 保存、损耗、形态转换、分配及传给谁 | 个人留存、家庭保有、主动转移和真实流失分开 |

四轴不相加、不平均成分数，也不要求每轴都能定档。依据是已经核实的财源与恩星／日月力量、有效传递、受制救应、财库和限运；“富足／小富／大富”等档位需明确说的是哪一轴、谁和哪一时段，缺判例界线时给有据范围或说明暂不能细分。不能用出身高代替自主赚钱强，也不能用收入高代替留存高。

另列月亮、身度主与命度的承受和享用：有财富且辛苦、有财富却现金紧、收入适中而生活宽裕可以分别表达，不将舒服程度冒充财富量级。财富高峰、阶段回落与后期留存不固定到年龄段；缺行运不预言何时转折。

### 财源规模与经验量级（2026-10-13 教学补充）

先比较各路财的力量与实际可用性，再综合供给、承载、贵助及本人所得。“加分”是**增加正向依据、提高层次判断**，不是数字评分；同星多职、多入口或同一助力的别名保留不同含义，但不重复增加星力。

| 已确认条件 | 层次用途 |
| --- | --- |
| 一颗财星较旺，如入垣或升殿，且实际可用 | 财运较好、有较强财源的基础；重点是财星，不把任意强星都当强财 |

财源是否直接支持本人也要看：年干正偏财可兼命度主恩星；命度主财星受生，与年干财、财帛主受生是不同路径。同一结构中，本体相生和食伤化曜生财可能方向不同，分层保留后合读；逐端核通道，不将 A→B、B→C 写成 A 与 C 直接交感。财帛主的力量与生扶体现资源承载和可动用条件，不因只看年干财而漏掉。

### 日月贵助：会财与联系命身都加分

1. **日月与财星有关系**：有效会照财星、财帛主或进入已经成立的财源支持结构，增加财源机会、平台、贵人及资源。太阳的千万级经验条件保留；月亮的贵助也进入层次判断，不自行补“月亮单独等同某金额”的公式。
2. **日月与命身有关系**：经已确认通道联系命宫、命宫主、命度主、月亮／身宫或身度主，给本人带来支持、机会和承接条件，亦提高财运层次。此路独立于日月直接会财；不把它只归为情绪舒适，不把日月作为身命本体的身份重合当自我交感。
3. 两路可以并存。分别写帮助到财源还是到本人，不强行合成“日月直接生助命度主”。日月为光体，不硬套普通五行生克。
4. 昼夜、月相、垣殿、填实、受蔽与救应决定助力分量。有力且可达，贵助更强；有联系但偏弱或受制，保留机会线索并说明落实限制，不把已成立财源全部归零。贵人、外部资金与机会不等于本人已拥有相应资产。

### 10.1 财富层级判断的执行清单（2026-10-14 老师确认）

判断链：**财源规模 → 生财与持续供给 → 本人承接及实际所得 → 支配、兑现与留存 → 限运实现**。这是核验顺序，不是评分或金额算法；每一步保留支持、制约和缺项。

1. **分主体与四轴**：先注明个人、家庭、伴侣、企业或受托平台口径，再分别判断出身、自主求财、阶段所得、积累传承。家庭起点、个人创造、当期收入与最终积累不能互相代替。
2. **定位财源并去重**：分列恩星、命度主仇财、财帛主、年干正偏财、日月及相关宫位入口。同曜兼数职保留职责，但不算多颗财星；多路成财须有不同的真实来源或作用路径。
3. **核实际力量与可用性**：逐星继承四时、日月特例、宫宿、垣殿、落宫支填实、运行和全通道生扶受制记录，比较财星与支持／制约星。旺财仍查受阻、救应和到达条件；偏弱得持续生扶仍可积累。一颗旺星真正得用可成关键财源。
4. **核生财及接续**：食伤生财、恩星供给、财生财及事业、家庭、伴侣、团队等支持逐段查通道与双方力量。本体生克和化曜事件分层读；A→B→C不能改写成A直接作用C，持续投入也不自动成为收益闭环。
5. **核贵助与机会**：日月会财、日月联系命身两路分别进入层次；后一条不只解释为享福体感。禄马、官魁文、岁殿岁驾、三元禄等有效会财作附加依据，不替代财源力量，不按标签数量跳档。
6. **核所得、承载与留存**：分别说明供养、机会、代管、持有权益、分红及出售兑现；财帛承载与田宅积累同参。现金、房产、股票、企业权益、营业流水和管理规模分开；资产转换、再投入、合作分利、家庭给予与真实损耗分别判断。
7. **综合给经验层级**：依第10节已确认条件判断潜力档，注明哪一主体、维度和时段。多路优势与供给、承载、贵助、留存共同成立时继续评估更高规模；百万、亿级以上的精细边界仍待校准，不把潜力写成当前身家、必达金额或终身上限。
8. **核实现窗口与同步事件**：依第11节及11.1节定位关键财富上升宫限、度限与年份，说明哪条财源改善、本人取得什么、同期婚姻／子女／事业／合作等事件及联系。财务活跃和净财富上升分开，同步与带财因果分开。

另列**月亮、身度主及完整交感的承受与享用**。命主旺弱、辛苦程度、现金紧张和局部受损不自动抹去有力财源；财富规模也不自动推出生活舒适。层次结论须能回到上述判断链，而非只列旺星或吉名。

现行顺序沿 `../../qz-core/resources/original_vs_transit.md`：**原局 → 宫限 → 度限 → 小限与飞限 → 太岁本宫／对宫／两三合 → 流年天干引动 → 顶星 → 流年星。**

老师本轮末段列“小限、太岁＋三方宫、飞限、流年天干、本命盘顶星”。保存列举，但未明确修订先后，财运模块暂不改通用顺序；若老师明确重排，再同步所有入口。

每个窗口写：被引动的财源／损耗 → 实际宫宿通道 → 来源人物／领域 → 本人取得与持有形态 → 得财／投入／分利／开支／负债／转移等性质 → 留存与流向 → 支持、制约及兑现条件。比较该阶段是获得家中支持、自主积累、扩大经营、资产转换、消耗还是传承，不把它们定成人人必经的年龄顺序。缺小限／飞限资料时沿 qz-reader 现行规则补算；所需输入不足则保留缺项，不造日期。一日流盘不全年化；恩限、财限不直接等于一定赚钱。

### 11.1 关键财富上升期与同步事件（2026-10-14 老师补充）

每次财运分析都要回答：**哪些宫限、度限和年份是关键财富上升窗口，以及同期容易伴随什么事情。**沿已确认限运顺序，先核是哪条财源得到生扶、本人取得与留存是否改善，再定位同时被引动的人事；只有投入、支出、转换或分利证据时，如实写事件性质，不把见财一律写成财富上升。缺限表或年度资料时，给已能成立的阶段范围并说明应期缺项，不凑关键年份。

- **身份交叉入口**：优先核年干正偏财兼夫妻主、男女主等身份，也查命度主财星、财帛主与这些人物／事件星的有效联系。财星兼夫妻主，可有婚姻确立、伴侣事业或夫妻合作与财运上升同期的线索；财星兼男女主，可有生育、子女事务与财运变化同期的线索。男女宫／主还兼恋爱、学生、粉丝与娱乐等取象，须结合年龄、所问和反馈择取，不自动断生子。
- **多职与关系同参**：奴仆主、官禄主、田宅主、迁移主等与财源重合或有效交感时，继续查团队扩充、事业平台、购置或使用场地、迁居及渠道变化。财星落夫妻／男女等宫与财星兼该宫主是不同入口，分别记录；仅有标签或宫名，没有力量、实际通道及限运引动时，不补造事件。
- **同步性与因果分开**：婚姻、生育与财富上升可以同期发生；写“这一阶段财源扩大，也容易同步出现……”即可。只有逐段成立的“事件／资源来源 → 财源 → 本人所得”支持链，才进一步解释该事件如何带财。不得写成结婚或生子必发财，也不把同步事件当作致富建议。
- **交付粒度**：逐窗口写清“公历起止／关键年份 → 引动财源 → 上升依据与所得形态 → 同步事件 → 事件与财的有效联系 → 制约与待核”。标明宫限、度限与年度入口；同一财富变化多次引动合并，不重复计钱或星力。真实反馈和盘面推演分栏，未发生事项不写成已验证事实。
