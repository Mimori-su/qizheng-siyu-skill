# 财运报告输出框架

版本：2026-10-14-r5｜财运七板块不变，沿用经验量级及多路成财、日月和禄马贵曜助力；层次核验执行 `wealth_framework.md` 第10节及10.1清单，关键财富上升期与同步事件执行第11.1节；未教明的细分边界继续保留。

## 一、客户版：结论先行，七个板块

| 板块 | 回答客户的问题 | 分工与边界 |
| --- | --- | --- |
| 1. 财富总评 | 起点如何、主要靠什么获得财富、能积累到什么程度、关键助力与限制在哪里 | 三至五点；出身、自主求财、阶段所得、积累与传承分轴，不给单一终身高低标签 |
| 2. 财富形态与实际支配 | 财富主要存在哪里，怎样变成可以支配的钱 | 现金／房产店铺等／股票／企业股权与合伙份额；分别看归属、收益、兑现及负担 |
| 3. 家底与承接 | 家里能提供什么，本人能得到哪些，哪些仍需自己争取 | 教育、人脉、供养、居住、经营家业与继承分开；不能由家里有财直接判本人已有财 |
| 4. 自己的求财本领与路数 | 适合做什么、靠什么得财、怎样扩大、付出什么代价 | 更来财与更喜欢分开；逐路落到具体业务／岗位／人事，过程与承受融入本节，不另起重复长章 |
| 5. 留存、分配与传承 | 钱能否留下，投入哪里，流向伴侣、子女或其他领域 | 正常开支、合作分利、再投入、形态转换、主动给予与真正损耗区分；也写伴侣／子女给本人的支持 |
| 6. 重要阶段变化 | 哪步运获得、创造、转换、分配或消耗财富 | 时间窗口、来源、取得方式、形态、去向、兑现条件；无资料不编年份，不固定年轻／中年／晚年的财富走势 |
| 7. 发挥优势的建议 | 最值得经营什么、补足什么、如何发挥已有优势 | 少量有依据的具体建议与鼓励，不重复总评，不给证券标的、资产配置、杠杆、下注或买卖建议 |

完整财运报告以七板块为覆盖清单；资料不足的部分只说明相应缺项，不能为了凑齐各节补造。用户只问一项时保留“核心结论 → 相关分析 → 建议”，不强制扩为完整报告。简版压缩文字，不降低证据要求。

只问财富量级时，先给有据的经验潜力档，再用二至四条说明旺财、生财路径、日月／禄马贵助与关键制约；不展开职业、行业或完整七板块。不能因旧版“金额待校准”一概省略已确认档位，也不把经验档写成现实已拥有的金额。

### 1. 总评：明确层次的主体、维度与阶段

先简明说出主要优势与现实意义，再给有依据的层级或范围。可用 `wealth_framework.md` 第10节已确认的千万级经验条件，多路有效旺财、供给与承载组合则继续评估更高发展空间；未教明的金额边界不补造。每次说清在谈家庭起点、自主求财、某阶段所得还是可留存积累，不能用一个档位代替四个问题。不编分数、当前身家或确定财富天花板。

本人强弱、外界财源、留存与享用分别判断；一颗旺星真正得用可成为关键财源，不以星数凑层级。财富高峰、当前持有和后期积累分开，家庭或企业的规模不当作本人资产。内部按第10.1节保留“财源规模 → 生财供给 → 本人所得 → 支配留存 → 限运实现”的完整证据链；客户正文择要说明决定层次的依据和限制。

总评中的助力至少核三类：财源得到的生扶与承载、日月会财及联系命身带来的贵人与机会、禄马贵曜会财的资源和渠道。不要求日月只联系财星，也不把命身贵助只写成情绪舒适。标签的解释有具体指向，不堆吉名，不按数量机械跳档。

2026-10-13 补充确认：总评充分展开有依据的本领、支持与扩大成果的路径，区分已知资产、待验证的层次判断和有条件的发展潜力；不为了情绪价值抬高金额档位，也不称命盘能算出确定财富上限。资产规模、现金、负债和局部损耗分别表达，局部受制不自动降低全部财源评价；关键制约须与优势同样清楚。

### 2. 财富形态：载体、权属、现金流三层分开

解释哪种形式更突出及其依据；股票持仓、公司股权、合伙份额不得混写为手头现金。房屋店铺还须区分物业、租用场所经营与经营公司的权益；租金、分红、经营流入是收益方式，产权是归属维度，不能作为额外资产重复算。

写清本人拥有／可支配什么、能否持续产生收入、兑现条件及维持负担。现实权属未知则不作事实确认。不得按单一宫位或星曜锁定某种资产，更不能把这一节写成应该买房或买股票的投资建议。

### 3. 家底与承接：资源充足和真正得到是两回事

区分家庭底子、支持方式、传递障碍、本人的实际所得。可以有良好出身而承接有限，也可以先受家庭支持再靠自己经营扩大。继承判法不足时只说明已有支持线索，不补造继承人、份额、时间或亲属死亡事件。

### 4. 求财路数：每条只讲新增信息

采用“适合领域 → 做什么／怎样得财 → 谁或什么支持 → 更来财或更合心意 → 成本与成立条件”。行业、岗位、人物与取得方式来自星性、落掌宫、化曜、宿度、神煞的完整叠象，不只报旺衰。

更来财但更费力、喜欢但规模有限，直接说明；学习、等待、奔波、分利、依赖与责任只写该路数有据的代价。家庭资金与本人经营贡献分开。不得把承受压力自动改写为财源不存在，也不把财生财写成必然回报。

### 5. 留存与流向：先分事件性质，再说得失

对伴侣与子女同时看“对方 → 本人”和“本人 → 对方”。子女有成就、子女相关产业与子女直接带财分别核；夫妻共同支出、家庭保有和个人资产减少可以并存。不给伴侣子女贴“败财”标签，也不隐去有据的损耗。

资产转换、传承、赠与和真正流失分别叙述；比劫／余奴克财主动与被动尚无统一判法时，保留“合作分利或被动损耗”，待真实反馈再明确。负债与财务纠纷有证据才融入，不为每篇固定添加风险段落。

### 6. 阶段变化：财富会改变形式，也会改变归属

每次明确关键财富上升限运／年份，按实际引动写“公历窗口／关键年份 → 被引动财源及上升依据 → 本人取得／持有形态 → 同步事件及与财的联系 → 收益、分配和留存 → 条件与建议”。继承 `wealth_framework.md` 第11.1节，优先核年干正偏财兼夫妻主、男女主等身份，并查其他财源与婚姻、子女、团队、事业及场地事件的有效联系；同步不自动等于带财因果，男女主不自动等于生育。发生财务事件、获得权益、收到分红和出售兑现分别表达；只有投入或转换证据时如实说明。无行运资料给已成立的阶段条件和应期缺项，不补年份。

### 7. 收束与文风

依 `../../qz-report/resources/report_style.md` 的“财富表达：充分肯定优势，不虚增金额”，先讲能发挥的优势，再具体说明代价与成立条件；不把坏处包装成好处，也不因结尾有参考说明就补造金额。结尾采用该节已确认的发展空间说明，不逐段重复；涉及真实资金或产权问题依现实资料及相应专业评估。

## 二、内部理论档：证据先于客户文字

1. **问题与口径**：本命／年度、快照日期、规则版本、个人／家庭／企业主体、已知事实、盘面推演、缺项与待反馈。
2. **上游继承**：原局喜忌、可用星、十一曜力量、四核心及各自通道；承受与享用另核，不覆盖财源结论。
3. **财源身份**：恩星、命度主仇星、财帛主、年干正偏财、日月、田宅与疾厄入口，同星多职不重复计证。
4. **来源与传递**：父母／家族、自己、伴侣、子女、合作等；提供者、接收者、有效通道、力量与救应、实际取得层次及阻碍。家财承接未知不当作完成。
5. **逐路叠象**：双方星性、落宫、掌宫、化曜、本体与变五行、宿度、神煞；取得方式、行业岗位、喜好、优先理由与成本。
6. **资产形态表**：载体、实际归属／份额、使用经营与支配、持续收益、兑现条件、相关负债成本、存量时点／流量期间、事实或推演状态。未知可留缺，不造金额，不重复计财。
7. **留存与去向**：财库完整性、消费、分利、再投入、转换、转移与损耗；伴侣／子女双向链；个人与家庭口径分别说明。
8. **阶段轨迹与同步事件**：完整限运顺序与触发，逐窗口保留上升依据、所得形态、同步事件、财星／人物主身份及实际宫宿关系，区分同步与因果、推演与反馈，注明哪段暂时成立；有财务事情不等于净收益增长，不能把一日快照写成全年状态。
9. **分轴层次与享用**：出身、自主求财、阶段所得、积累传承分别给支持、限制及可判程度；单列经验档依据、多路成财与财帛承载、日月会财、日月联系命身、岁殿岁驾／禄马官魁文／三元禄会财。标记类别、实际通道、助力分量与去重须清楚；峰值、持续性、可兑现性与个人承受分栏。
10. **待核与复盘**：老师明确规则／整理框架／推演／未决项，主动与被动、继承、股票与合伙份额细分等不冒称已有判法；真实反馈独立记录，不将生成报告当作验证。

主要结论须能回到“身份 → 通道 → 力量及救应 → 叠象 → 人事／载体 → 时段”。不能只用现实名词覆盖缺失的术数依据。

## 三、交付与归档

- 默认先完成内部证据，再生成独立客户稿；文件为 `wealth_internal.md`、`wealth_report.md`。用户只要其一则按范围交付。
- 七板块自本版本起为财运默认，不改其他专题模板；多专题整合时合并重复事实，不丢上述关键区分。
- “不存档／不入库”时仅对话交付；其他归档沿已有授权。教学与格式示例不生成个人档案，完整客户案例不进入 Skill。
- 本轮尚未教明的具体断法集中见 `wealth_framework.md` 末节，不因框架正式化而补齐成伪规则。
