# 洞微大限、度限、小限月限与流年引动

版本：2026-10-12。来源：老师「洞微大限／度限／小限／飞限／流年」投喂、四项答复及“躔度、神煞一起解读”的补充；本轮追加小限起点、月限起法与节气换月的确认。老师已确认规则优先；程序起算约定单列，不冒称古文原义。本文明确标注的待核项不作为自动计算条件。输出采用已确认的《洞微大限与流年报告模板》：客户五板块、内部另档；按完整宫限、单年和单专题调整详略，不新增吉凶权重。

## 1. 定位与执行顺序

原局提供力量、喜忌及人事结构，限运负责引动。先继承本命格局和十一曜力量记录，再执行：

```text
原局喜忌与可用性
→ 宫限（大环境、阶段体感）
→ 度限（较小环境、阶段事件主轴）
→ 小限与飞限（分别检查当年引动）
→ 太岁宫的本宫、对宫、两个三合宫
→ 流年天干化曜
→ 顶星
→ 流年星及年度修饰
→ 需要细看月份时，叠加节气月限与所需时点的流曜
```

这是分析顺序，不是各信号的固定权重表。小限和飞限分别记录作用途径，不预设二者谁压倒谁。顶星、化曜和太岁是不同入口，不能把年干化曜或太岁引动统一改称“顶星”。同一星被多个入口激活，保留各入口；不把它算成多颗星或多份独立力量。

无本命直接交感时，须说明由哪项限运建立临时作用；没有成立的通道，不仅凭同年出现就连成生克链。运过后不把阶段事件写成终身常态。

## 2. 所有参与星曜的共同检查

宫限、度限、小限、月限、飞限、太岁、化曜、顶星和流年星各层中，实际参与的星曜都要逐颗解释。每颗星都读取：

| 要素 | 判断职责 |
| --- | --- |
| 星曜本象 | 人物、事情、五行或日月光体性质 |
| 旺衰与原局可用性 | 季节、昼夜／月相、入垣、升殿、落宫与躔度生扶克泄、四柱落宫填实、受伤救应 |
| 对命度主的关系与气数 | 恩、难、余、仇、用与气数喜忌分列；日月不套普通五行生克 |
| 落宫、掌宫 | 事件发生领域、来源领域及人物；领域间可有因果，也可同步发生 |
| 化曜 | 本命化曜身份、年干化曜引动分别标注 |
| 躔度 | 实际星宿名称、七曜属性、度数；参与升殿／受生受克、同属性四宿交感及具体事件取象 |
| 神煞 | 该星落宫及所掌宫位的相关神煞，限宫相关神煞；区分本命与流年，补充人物、事件性质与表现 |
| 交感及引动来源 | 哪颗星通过什么宫／宿通道作用，哪一限运或年度入口使其应事 |

躔度同时参与力量、通道和取象，不能只在结尾附一个宿名。神煞只在整体作用已经成立后补充事件细节，不靠孤立神煞定成败。调用已确认类象库；资料未给则留缺，疑字保留原文并标注，不能自行改字或据疑义增加判断。此处覆盖所有实际参与限运的星曜，不套用个人性格专题“只读四核心所躔宿”的范围限制。

木、火、水度限中的正曜与四余不设预先主次：凡实际出现、交感或被引动的相关星曜，都是当年需要分析的主角。不得以“正曜主、四余辅”删减。主星／余奴等身份仍可描述实际关系，但不决定是否分析；具体作用大小比较旺衰、通道、受制与救应。

## 3. 宫限：阶段环境与体感

宫限类似省份的大环境，首先看气数喜忌及与命度主的关系。难限容易带压力，恩限容易获得帮助；但客观所得与过程体感分开判断。例如夏生土命得到火恩之助，可能同时经历燥热、不顺心或抵触。继承四时细分与原局可用性，不把恩限直接写成顺遂、难限直接写成失败。

### 宫限主

| --- | --- |
| 子、丑 | 土、计 |
| 寅、亥 | 木、炁 |
| 辰、酉 | 金 |
| 巳、申 | 水、孛 |
| 午 | 日 |
| 未 | 月 |

本轮宫限主清单漏列卯、戌。既有宫位属性为卯火、戌火，可查已确认盘面中的火宫及宫主；该表的补项单列待核，不因省略就丢掉这两宫，也不据此擅自新定四余参与条件。老师原文“重点看主星日月木火土金水”用于定位宫限主本身，不扩张为忽略其余实际参与星曜。

### 检查方法

1. 定宫限所在宫及起止时间，承接原局喜忌与力量。
2. 看限宫守星、对宫和两个三合宫的星曜，逐颗记录气数及恩难余仇用。宫名说明领域，但不能只凭“夫妻限／福德限”等名称下事件结论。
3. 看宫限主自身强弱、躔度、落宫、掌宫及实际交感星曜；参与星曜都使用第 2 节共同检查。
4. 星曜之间有生克制化时，定位促进、阻碍、受伤与救应；再映射现实领域。整体判断需同时包含好处、代价、过程及力量大小。

## 4. 星曜、宫位与事件作用

分别检查三类关系：

- 星曜对星曜：如水克火，宫内实际交战即有不顺过程，即使双方各有喜用价值也需说明矛盾或代价；结果仍看力量与制化。
- 星曜对宫：如水克火宫，水所掌领域对本宫领域构成压力，不能混写成“火星必然已经被克”。
- 宫位对宫位：通过星曜之间的真实作用，把各自掌宫与落宫联系起来。

老师示例：戌为相貌宫，火为相貌主居戌，男女主水进入该宫。水克火既影响水、火代表领域，也影响相貌宫的心情、自我形象与内在想法；可出现颜值焦虑或内耗等象，但不能未经反馈写成已发生事实。

若水掌财帛 a、男女 b，火掌夫妻 c、相貌 d，则可考虑 a→c、a→d、ab→c、ab→d、ab→cd；也可表示 ab 与 cd 领域同步有事。这里是候选事件组合，不表示所有组合都必定同时发生。是否为因果、是哪条实际表现，要结合当年引动、专题问题和真实反馈；尚无老师确认的统一排序，不把助手上一轮建议的固定优先级当正式断法。

兄弟主克男女主可作为感情受第三方干扰的倾向线索，结合婚恋模型的其他因素判断程度；不据此认定某位现实人物已经插足。

## 5. 度限：阶段事件主轴

在宫限背景下看度限，流年应事重点观察度限。

| 四同属性宿度 | 度限主／相关星曜 |
| --- | --- |
| 木度 | 木、炁，均分析 |
| 火度 | 火、罗，均分析 |
| 土度 | 土；本轮未把计列作土度限主 |
| 金度 | 金 |
| 水度 | 水、孛，均分析 |
| 日度 | 日 |
| 月度 | 月 |

土度限主表未列计，不等于计出现时不分析；计若守限、同躔、交感或被年度引动，仍按其实际作用完整检查。

1. 逐颗看度限主旺衰、躔度、落宫、掌宫、化曜、相关神煞及交感。
2. 检查当前宿及其他三个同属性宿度上的星曜，记录该限容易发生的事情。日宿、月宿分别成组，不改归火宿、水宿。
3. 检查限主受克，以及克该宿属性的星曜躔在同属性四宿中这两条不同路径。如火交感水，或水／孛躔火度，均是克火限的线索。
4. 克限可使限主及相关星曜的落宫、掌宫领域出现不顺；具体年份须查是哪一个年度入口引动水／孛等克星，不能将“水相关年份”固定等同某一个地支年或某一个年干。
5. 比较实际力量与救应。忌神受制所得与其代表领域受损可同时存在，保留得失两面。

## 6. 小限

老师已明确：**命宫是出生当年的起点，一岁命宫、二岁财帛，逐年逆行，立春换宫**。“阳九与小限相同”按此统一，不再把古引文“命宫起子”另算一套以子年为固定锚点的小限。

### 程序计算

- 出生所在立春年为第一年，之后每过一个立春加一；不按公历元旦或生日换岁。以 `Y(t)` 表示时点 `t` 所在的立春年度，`n = Y(查询时点) - Y(出生时点) + 1`。
- 人事宫序依次为命、财帛、兄弟、田宅、男女、奴仆、夫妻、疾厄、迁移、官禄、福德、相貌，位置为 `(n - 1) % 12`。再由本命十二宫映射取得地支。
- 等价地，以子丑寅卯辰巳午未申酉戌亥编号 `0…11`，小限地支为 `(命宫地支索引 - (n - 1)) % 12`；须与本命人事宫映射相符，不按男女改变方向。
- 年运默认由 Reader 的 `../../qz-reader/resources/annual_period_query.md` 所述 `../../qz-reader/scripts/calculate_periods.py` 补算；原始排盘没写小限，不作为缺失断法或跳过该层的理由。数据可在本轮内存中传递，不要求先有同名实体文件，也不以临时手算替代已提供的程序。

有用户指定的小限时与计算结果核对；不一致先核出生时间、年度边界和盘面映射，保留冲突，不能静默改盘。

判断顺序：

1. 先完成宫限、度限状态与喜忌。
2. 小限宫位的人事领域会被激发；看小限宫主、宫内星是否激发大限结构，尤其是否影响或克制度限主、四同属性宿度上的星曜。
3. 所涉星曜完整叠加躔度、掌落宫及相关神煞。
4. **特别重视流曜进入小限宫后的作用**：是否为原局气数喜、有帮助，是否克小限宫，是否引动或克大限／度限；比较来星、原局星与限主的力量和救应。本命宫内星与指定时点流曜分栏，不把一次快照延伸为全年常驻。

来源：《星学大成》阳九起例和《兴平会海》小限起例，本轮据老师粘贴内容整理，未独立校勘原典。原引文涉及二十五岁移入限中的句子，老师尚未展开，暂不自动改写现行逐年起法。

### 6.1 月限：小限宫起生月，交节逆移

老师本轮选定：**当年小限宫起出生的节气月份，逆取至所看节气月份，一月一宫**。寅月为正月、申月为七月，采用交节换月，不用农历初一或公历月初。出生月也按出生时点的节气月求得，不能把排盘所附农历月直接代入。

设小限地支索引为 `s`，出生节气月序为 `b`、所看节气月序为 `m`（寅为 1，卯为 2，……丑为 12），则：

`月限地支索引 = (s - (m - b)) % 12`

小寒起丑月仍属于上一立春年度；到立春同时更换年度小限与寅月月限。各节气月从十二个“节”的实际交节时刻起，至下一“节”前止：立春、惊蛰、清明、立夏、芒种、小暑、立秋、白露、寒露、立冬、大雪、小寒；不以中气换月。程序计算完整公历起止时刻，注明北京时间（Asia/Shanghai，UTC+08:00）；区间为左闭右开 `[起时, 止时)`，交节当刻归新月限。

月限是在当年小限及宫限、度限背景下细分月份，不替换全年小限。依其所到本命人事宫讨论当月领域，再叠原局喜忌、相关星曜的完整资料与流曜作用，追查是否引动大限结构。求精细月份时仍持续观察流曜对**小限宫**的影响，不能只追逐月限宫。沿已有规则分析，不自行新增月限宫主优先级、吉凶评分或应事门槛。

古文财帛见生、兄弟荐举、田宅增业等例子用于说明宫位领域被激发；具体助阻仍以原局、力量、实际作用及救应合断，不将“必灾”“损人丁”等原句转成固定预测。不另引入“先到太阴所泊宫再起生月”的第二次起算。

来源：本轮用户提供《兴平会海》《星学大成》《星学正传》引文及“小限宫起出生月份”“节气月份、交节换月”的明确选择，未独立校勘原典。

## 7. 飞限：六年循环，立春切换

本轮已确认：第七年重新从本宫开始，六年一轮；飞限年度以立春切换，不按进入宫限后的精确周年换年。

| 轮内年份 | 飞限位置 |
| --- | --- |
| 1、2 | 当前宫限本宫 |
| 3、4 | 当前宫限对宫 |
| 5 | 按阴阳方向首先遇到的三合宫 |
| 6 | 另一个三合宫 |
| 7、8 | 重新回本宫，进入下一轮 |

已知某宫限的轮转年序 n 时，轮内位置为 `(n - 1) % 6 + 1`。宫限本身仍用实际交宫时间，不因飞限立春换年而挪到立春。

**本次程序起算约定**：交入新宫限当下为第 1 年，直到下一个立春；每经过一次立春，年序加 1。可写为 `n = Y(查询时点) - Y(宫限交入时点) + 1`，须先确保查询时点处于该宫限。若恰在立春交宫，新宫限从该刻起为第 1 年，下一个立春才是第 2 年。这是补足自动计算的约定，不标为古文已明确之法。年度内交宫时，以实际交宫时间切成前后两段，新宫限重新起第 1 年。

- 阳宫：子、寅、辰、午、申、戌；第五年取盘上顺时针首先遇到的三合宫。
- 阴宫：丑、卯、巳、未、酉、亥；第五年取盘上逆时针首先遇到的三合宫。
- 地支方向按老师此前“子为中、丑为前、亥为后，宫前后顺时针”的定义落实：子丑寅卯辰巳午未申酉戌亥为顺时针序。第五／六年，阳宫依次为本宫索引 `+4、+8`，阴宫依次为 `-4、-8`，均对 12 取余；不根据不同绘图界面的视觉方向另改算法。
- 飞限只看飞限宫所守星，不读取飞限宫主的星体状态作为飞限判断，飞限不是太极点；不将三方对照的星曜自动算作该宫守星。
- 守星仍须看其本象、旺衰、躔度、落宫、掌宫、化曜、相关神煞及怎样引动大限／度限。不能因“只看守星”省略守星的取象。
- 飞限宫为空时如实记空，不以宫主代替守星。守星的具体本命／流曜范围待补，已提供本命守星可先核，流曜另走流年层。

来源：《星学大成》飞宫起例，六年循环和立春边界以老师答复为准；第五／六年方向承接已给宫前后定义。交宫年序依本节公开的程序约定，不改用精确周年或生日。

## 8. 流年引动

### 小限与飞限

先看二者相关星曜是否激活大限结构，重点是度限主及四同属性宿度上的星曜。每条线都记录所作用的对象与领域。

年运先运行 Reader 的限运补算程序取得年度小限、飞限及宫限／度限分段；需要月份时取十二节气月限。具体时点的流曜另调用郑案流曜查询并叠入对应的本命宫位。宫限、度限须继承用户给出的实际限表，补算小限、飞限、月限不等于重新推算洞微大限。

### 太岁宫

观察太岁地支所在本宫、对宫、两个三合宫，主要看各宫内的本命星曜。如午年看午、子、寅、戌。不自行加六合为同等入口。

### 流年天干化曜引动（年度入口）

| 年干 | 甲 | 乙 | 丙 | 丁 | 戊 | 己 | 庚 | 辛 | 壬 | 癸 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 引动星曜 | 火 | 孛 | 木 | 金 | 土 | 月 | 水 | 炁 | 计 | 罗 |

年度化曜引动对应本命星曜的落宫、掌宫及其关系。如孛落夫妻而又代表财帛、男女等领域，则沿这些领域说明相关事情，是否吉利再看本命力量、喜忌、交感、制化和限运承接。化曜身份不能替代这些判断。

上表只定位年度引动星，不是全盘十种天官身份的完整映射。本命身份、流年身份及各自起法来源另记；不能仅凭“甲火乙孛”替全盘改写十神。

### 顶星

老师本轮确认：顶星会发生相关事情，不把“相关现象”与“可记录事件”人为拆成互斥情况。按顶到的星之本象、力量、落宫、掌宫、化曜、躔度与相关神煞解释内容，吉凶仍综合判断。

保留这条作为老师体系的应事规则；不由此保证特定婚期、职位、金额或灾害，也不把尚未收到的事件反馈写成已经验证。缺顶星数据或算法时明确缺失，不能用太岁或化曜代造。旧资料“明顶”为限度线与本宫星重叠，其他顶法未展开时按原盘标签记录。

### 换宫、换度与克限

- 交宫限、交度限是重点转折观察点，常对应环境、工作或该度限主题的变化；事情容易在第一年出现，不能把所有换限一律断作换工作。
- 年度引动克限星时，重点看限主受伤及落宫、掌宫受到影响的事情，比较克星与限主力量、是否有解救，再描述程度。
- 最后叠加流年星，区分本命星和流曜。流曜进入小限宫、顶度、划度等有明确作用时写清路径，不能略去前面的限运层。

## 9. 躔度与神煞如何进入事件解读

内部每条事件至少留出以下关联：

```text
星曜与引动来源
→ 本象、力量及喜忌
→ 落宫、掌宫与化曜所指领域
→ 实际躔度的力量条件、交感和事件类象
→ 相关本命／流年神煞补充具体性质
→ 谁促进谁／谁阻碍谁，涉及什么事情，有何得失和救应
```

这是推演记录要求，客户章节另按《洞微大限与流年报告模板》组织。客户文字需要体现躔度、神煞实际带来的内容，而不是只写“某星旺／弱”；但无已确认类象或不参与该事件时不得硬凑。原局与年度的神煞分别标注；同一宫位、同一本命／流年来源的重复检索只记一次，不同宫位分别保留作用归属。

## 9.1 天官变五行：对已引动关系作双层读取

本命先依《天官分析顺序》完成天官与身命关系、得地八法、喜忌及救应；限运不重建一套本命格局。年度入口顺序保持不变，在定位实际交感星曜之后逐组处理：

**本体作用与方向 → 双方星性、落宫、掌宫人事 → 两端化曜身份及关系 → 躔度、神煞细化 → 好处、阻力、代价与救应。**

- 本体受制不取消化曜关系的事件象；化曜相生也不取消本体压力。不要求两层同向，不把两层抵消为一个吉凶。
- 身份、来源及时间口径须明示；若无实际宫度或限运通道，不任意配对。连续作用每一段分别核通道。
- 原局不好用者仍可读当年事件，不包装为优势；本命无直接联系而由限运接通者标为临时作用，运过不写成终身常态。
- 本命化曜、流年化曜和流年天干引动星分栏。缺年度身份及确认起法时，不补算；可沿已知本命身份解释被引动的原局关系。
- 内部留存逐组两层证据表，客户文字纳入重点事件和关键年份，不加重复长章。天官八法不自动扩张果老一般生克通道。
