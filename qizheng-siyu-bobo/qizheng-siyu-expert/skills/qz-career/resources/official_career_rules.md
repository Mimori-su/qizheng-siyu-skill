# 天官与官禄同参：任职、专业身份与授权

> 2026-10-09：将老师已讲规则整理为检查顺序。公务员、国企、教师等是组合取象方向，不设“单星即职业”的判式；调动规律仍待案例检验。

## 一、定位与分工

天官、官禄主、官禄宫内星一同观察，分别核与命宫、命度主、月亮、身度主的联系。沿用 `../../qz-core/resources/tianguan_analysis.md` 的起法、得地与八法，不另造天官体系。

- 天官：任职、组织认可、职责与授权。
- 官禄主及官禄体系：职业路径、组织环境、工作任务和评价关系。
- 本人四核心：机会到达、承接、投入、承受和体感。
- 日月及支持星：平台、贵人、背书、保护、专业认可及资源条件。

这些定位点可汇成同一职业线，也可各自对应不同角色。星曜身份重合只记一颗星、多项身份，不能当成多颗独立贵星叠加。

## 二、组织任职与从政倾向的检查顺序

1. **与本人有联系。**按既定八法核天官与身命的关系，穿、贯、守、冲、钓等保留具体类型。八法不擅自扩充为普通星曜之间的新交感通道。
2. **力量与可用性。**看季节、宫度、填实、生扶、受克和救应。天官有力、未受伤且得用，是任职方向的重要支持；仍与官禄及其他定位点合参。
3. **财与文贵支持。**检查财生、官魁、文科等实际参与。继承“命主躔财度”等生官度规则，不能缩成只有天官躔财度。四柱填实、空陷分别保留，不将空陷单独写成职业否决。
4. **岗位内容。**以星曜本性、落宫、掌宫、化曜、宿度及神煞，区分行政管理、教学、研究、专业服务、经营或支持岗位；职业身份与机构性质分别说。
5. **平台与声望。**核事业相关星与太阳的实际交感、太阳力量和帮助到达方式；月亮、恩星的支持并看。大平台、上级信任、公开认可、专业口碑分别定位，不能一概等同于大公司或高官阶。
6. **行运与现实入口。**看任职、录用、考核、资格、晋升等哪一条结构被引动。进入体系与获得实权、取得职称与行政晋升分别判断。

官禄不是“当官”的同义词。未形成体制路径时，仍可读为企业职务、专业身份、制度责任或公开评价。

## 三、官杀、食伤、印的制化

先保留每颗星的身份来源，再查作用双方的真实通道、力量、领域和限运。

- 本体生克与化曜生克两层分别记录，允许两层呈现不同得失，不互相抹去。
- A 与 B、B 与 C 各有通道，只能逐段讨论传递，不自动认定 A 与 C 直接交感。
- 食伤制、印化可能体现专业输出、制度处理、资格或资源承接；具体结果须看被制者、施力者及本人需要。
- “官杀混杂，同时受食伤制、印化”暂列多重职责、评价或变动的追查线索。调动、借调、职责调整、升迁、压力与保护分别核，不以该组合单断不稳定。

## 四、事业层次与权限

组织信任按经手、保管、执行、审批、决策和人事管理分清，不按接触的资金、文件或资源规模推职级。

制度认可、专业权威、公众名望与经营规模各有证据，不折算成统一分数。贵人或客户的层次只说明外部资源质量；转化成本人职位、成果或收入，另查到达通道、持续性及现实反馈。

未确认的计划、代办、临时承担与正式任命分开。尚未建立现代职级标尺，不编官阶、组织规模或成功概率。

## 五、专题衔接

- 完整财源、财库与留存接 qz-wealth；财生事业可为投入，事业产生收入须另有证据。
- 合同、处罚、仲裁、诉讼取象纳入事业／财运，共用 `../../qz-core/resources/dispute_risk_rules.md`，不再转独立官非 Skill；现实法律判断仍需事实、证据与法律专业意见。
