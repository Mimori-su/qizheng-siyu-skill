# 事业分析框架：定位、路径与层次

> 2026-10-09：依据老师的事业教学、案例研究反馈及写入授权整理。下列为已采用的分析程序；第九节为待检验解释，不是固定断语。现代官阶、收入与事业规模的星力换算标准尚未建立。
> 旧版教材索引留存：水火相济化杀为官 262–267；官非专题 314–326；基本喜忌 175–180。本轮未重新校勘原页，新增程序不归称为这些页的原文。

## 一、先拆事业问题

官非与纠纷作为本专题和财运的内置内容，共用 `../../qz-core/resources/dispute_risk_rules.md`。先核难星克命度主和财生官杀的实际程度、通道及救应，再解释职责、合同与组织边界；不新增独立 Skill 或每篇固定风险章。

事业回答“在什么体系、承担什么工作、凭什么获得认可”；财运回答“资源和钱归谁、从哪里来”。两者可以相连，也可以分离。

| 观察项 | 要分清的问题 |
| --- | --- |
| 组织平台 | 谁提供机会、保护、背书与资源；组织类型是什么 |
| 实际岗位 | 本人做什么、负责到哪一步；雇主行业与本人专业分开 |
| 个人专长 | 能解决什么问题，哪些本领已有学习、作品或服务成果支持 |
| 收入来源 | 工资、业务收入、其他财源；个人收益与企业资金分开 |
| 兴趣与体感 | 愿意投入什么，工作条件如何，责任和成本能否承受 |

不默认职业一定以挣钱或晋升为目的。主业、副业、学习可分属不同结构；先分别定位，再判断相互支持、冲突或暂时独立。

## 二、本人四核心与天官、官禄同参

继承 qz-core 的命度主中心与原局喜忌，依次检查命宫本对三合、命度主落宫体系、月亮体系、身度主体系；实际同躔七曜属性四宿另查。

| 定位点 | 主要问题 |
| --- | --- |
| 天官 | 任职、组织认可、职责、考核与授权；继承天官得地、八法、财生与制化检查 |
| 官禄主 | 职业关系、岗位路径与职业作用如何落到本人 |
| 官禄宫及宫内星 | 工作环境、制度、任务与领域作用结构，不只看宫名 |
| 命宫、命宫主与命度主 | 机会能否到达本人、本人怎样承接；身份重合不重复计证 |
| 月亮与身度主 | 实际表现、持续投入、承受与享用，不只看职位得失 |
| 日月、相关恩星及可用之星 | 平台、贵人、保护及资源，分别核路径和力量 |

**天官与官禄同参，多点定位一线，但不强迫所有定位点直接相连。**分别连接身命、财源或专业星时，可形成不同职业线。间接传递逐段列通道，不改写成两端直接交感。

官禄主、天官、官星、魁星、文星和年干身份分别保留。原盘化曜、采用的天官体系、流年身份与年度引动入口分栏；同名有歧义时核起法，不把“天印”等全局替换。

## 三、逐星核力量与实际作用

复用 `../../qz-wangshuai/SKILL.md` 的完整记录，缺项才补查；帮助、制约及救应星同样核验：

1. 四时节气月段、旺相休囚；日月另看昼夜、月相明暗，不套普通五行生克。
2. 入垣、升殿与实际宫度相符否；宫气、宿气的生助、克制、泄耗分开。软件标签不能替代核实。
3. 四柱落宫地支填实，仅比落宫，年支太岁最重，不以宿度对应地支代替。
4. 本宫、对宫、两个三合宫，以及实际所躔宿同七曜属性四宿的星曜；空宫、空宿也记已查。
5. 来生、来克、承接、制化双方的力量、后续补充与受损；迟留伏逆按已给状态与确认规则读，不凭未知速度补算。

宫气／宿气与实际星体作用分栏。躔木宿受到宿气约束，不等于木星直接克它；某宫有难星、某类宿检索见难星，也不能省略作用对象与通道。

力量沿用“强、偏强、中等、偏弱、弱＋状态说明”；依据不足写待定，不打百分比。助力分清**帮助分量、到达本人程度、兑现阻力、后续补充和持续性、本人喜好与代价**。强而受制可表现为阻隔或断续；弱而受生可表现为积累。实际节奏仍须比较作用双方及限运。

## 四、找到职业路径与具体任务

从气数喜、力量突出、能解决问题三类入口找候选可用星，回原局核可用性，再与天官、官禄和身命对接。行业取象不限官星，不把全盘星性罗列为行业清单。

每条职业线说明：**谁／什么提供机会 → 有效通道 → 本人承担什么工作 → 形成何种成果或认可 → 条件与代价。**

- 星曜本象与化曜定人物、能力、产出、职责；落宫定领域，掌宫追来源与牵涉事项。
- 宫气、宿气分别说明力量与现实作用，允许同星同时得到环境支持、受到事务约束。
- 宿度细化任务、对象与方式；神煞补充性质，不能单靠文昌判教师、天厨判餐饮、印章象判官员。
- 区分**公司行业／本人岗位／个人专长／收费项目**。服务某行业公司与从事其核心技术分开。
- 主副业分别判断专业适配和收入适配。有岗位而财源在别处，或有专长尚未收费，均可保留。

组织任职、专业技术、内容教学、经营业务、受托服务是归纳类别，不是单星职业表。具体组织和岗位类型依据组合、限运及现实条件判断。

## 五、事业与财源：作用方向、资源归属

财帛主、财星与官禄宫内星、官禄主、天官有联系时，分别辨认：

- **财生官或事业相关星：**资源投入职位、事业；再查出资者、归属和去向。本人投入、外部资助、组织资金支持分别看；经手资金、垫付报销不直接归为本人投资。
- **事业成果支持财源：**已有通道与生助关系才讨论变现，仍须说明收益是否归本人。
- 本体与化曜两层方向可以不同，分别读后叠加；不能只见食伤、财、官标签便默认“食伤生财、财生官”。

平台规模、企业资金、贵人资产、本人收入与净资产分栏。完整财运接 qz-wealth，不以事业线替代财库与留存判断。

## 六、事业层次分项评估，不合成总分

| 维度 | 判断口径 |
| --- | --- |
| 外部资源质量 | 日月、恩星及支持星的力量与到达通道；机会、资金、师承、背书、保护分别看 |
| 组织信任与授权 | 经手、保管、执行、审批、决策、人事管理分别看，不按所接触资源推职级 |
| 专业成果与认可 | 学习、资格、作品、交付、客户认可、职称；专业等级与行政职级分开 |
| 业务与组织规模 | 个体服务、持续经营、团队复制需相应结构与反馈，成交不等于规模能力 |
| 自主性与持续性 | 平台依赖、独立获客、持续产出、助力补充及个人投入 |
| 承受与体感 | 月亮、身度主、气数及相貌等实际作用，说明责任、精力、兴趣和生活余裕 |

命主旺弱不直接决定财官大小。一颗有力且得用的星可成为关键资源，仍须说明怎样转成本人的成果、权力或收益。分项写有力、受阻、尚待兑现，再作综合判断。

跨案例统一比较“原局资源条件 → 到达本人 → 运限引动 → 现实成果”。暂无标尺时只作定性比较，不从格名或星数换算现代官阶、资产金额和成功概率。

## 七、稳定性、事件得失与体感

- 分别记平台／雇佣关系、职位、任务及收入稳定性；借调、换项目、服务主体变化、项目收尾、离职失业分别定位。
- 平台好、责任增加、本人不喜欢可同时成立；外界机会与主动投入分开。
- 贵人支持可表现为机会、保护、学习条件、自由时间、费用支持或背书，须结合实际领域选择，不能固定绑定具体福利。
- 事件分别记过程、结果与体感。冲突后可能减责或受保护，责任增加也可能加重消耗，得失不净算成单一吉凶。

## 八、行运与反馈验证

遵守 `../../qz-core/resources/original_vs_transit.md`：本命 → 宫限 → 度限 → 小限与飞限 → 太岁本对三合 → 年干化曜引动 → 顶星 → 流年星。参与星的宿度、神煞继续带入。

进入平台、岗位调整、资格晋升、学习启动、开始收费、持续客户、教学或产品化分别核对，不让一次换限包办全部成长。

反馈标“已发生／计划中／年份或月份不明”。只核到宫度限、年干或太岁时标局部核对，不补年度盘、顶星或精确月份。事件早于换限不能归给新限触发；宫限与度限切换分别处理。

## 九、待验解释与隐私

以下只作追查线索：

- 官杀交感且同时被食伤制、被印化，可能有多套职责或评价力量牵动；须结合力量、领域及限运，区分调动、压力、支持或晋升，不能断必不稳定。
- 平台可能支持专长和副业，也可能只维持主业，不预设最终转型。
- 学习、收费、客户入口成立后，仍需持续性和组织能力证据才讨论规模扩大。

程序可执行，不等于案例规律已有统计验证。新反馈先查反证，不为解释已知细节临时造规则。

Skill、示例和同步镜像只保留抽象方法，不加入姓名、出生信息、完整盘、逐年经历或可交叉识别的罕见组合；案例另按私有归档授权处理。

## 十、内部最小记录

每条线保留：定位星与身份来源 → 宫度／时段与通道 → 力量喜忌 → 本体与化曜作用 → 本象、宫位、宿度、神煞叠象 → 岗位／资源／成果 → 代价与反证 → 限运及反馈 → 已确认或待验。
