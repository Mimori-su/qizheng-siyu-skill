# 出身与父母报告输出框架

版本：2026-10-09 本轮授权整理初版。对应 `../../qz-core/resources/parents_framework.md`；沿已讨论的“总评 → 父亲 → 母亲 → 家庭资源 → 阶段建议”组织，不替换其他专题模板。规则未提供或资料不足的部分不补写。

## 一、客户版

结论先行，内容集中在父母自身条件、相处方式、实际助力与阶段变化。父母人物判断与家庭整体资源分开，不用大量心理描述代替资源、工作或生活事务。

### 1. 出身与父母总评

简要回答：家庭的主要资源在哪里；父亲、母亲各提供什么；哪些支持容易获得、哪些需要条件；关系最值得留意的变化。一点一个判断，不在开头堆术语或重复后文。

### 2. 父亲：自身条件、相处与支持

- 自身条件：能力、财运事业、平台与外援，层次用有据的定性语言。
- 相处方式：怎样表达关心、提出要求，命主怎样承接与感受。
- 实际助力：资金、住房、学习、机会或其他已定位支持，说明力度、条件和阻力。
- 有限运资料时，用一小段写“早期表现 → 转变阶段与事情 → 后来的支持方式”。

### 3. 母亲：自身条件、相处与支持

覆盖与父亲相同的三类问题，使用母亲自己的证据；不要把父亲的财富、家庭总资源或一个宫位的氛围直接复制给母亲。限运变化同样按年龄、阶段表达。

### 4. 家庭资源、祖辈与居住基础

集中写家庭资产、居住条件、祖辈／亲属支持及家庭氛围；再交代命主能获得哪一部分、怎样获得、有哪些现实条件。不重复前两节已说明的个人照顾方式；没有证据的亲属身份、资产金额和搬家经历不补写。

### 5. 阶段变化与相处建议

有明确运限资料时，择要汇总重要时间窗口及家庭议题；父母章节已经写过的变化只点明行动重点，不再整段重述。没有运限资料时直接给相处与资源使用建议，不凑时间表。

建议对应前文：如何表达需求、区分金钱支持与情绪需要、协调家务与责任、争取学习或独立空间。真实伤害需要保护和边界，不要求忍受或强求和解。结尾给予有依据的肯定，并集中保留一句传统术数参考说明。

### 客户文风

读取 `report_style.md`。采用“结论 → 具体表现／简短依据 → 必要的条件或建议”，不逐段加没有新信息的否定免责。支持与压力可以同写，不把坏的说成好的。没有真实反馈时用清楚的倾向表达，不把父母的内心、行为或身家当已知事实。

## 二、内部理论记录

先完成内部，再据同一结论写客户版。以下是证据字段，不要求每次机械输出所有空表。

| 字段 | 核验内容 |
| --- | --- |
| 问题与资料 | 分析父亲／母亲／家庭的范围、盘面版本、资料来源及缺口 |
| 父母人物定位 | 太阳、月亮、各自躔宿度主；年干正财、正印、田宅主的身份来源；重合与去重；正印起法未核可缺项，不为填表补算 |
| 关系中心 | 恩难等以命度主为中心；另作对象观察的范围，不暗换父母自己的恩财体系 |
| 逐星力量与交感 | 完整宫宿通道、四时／光体条件、宫宿双层取象、支持与制约，引用已核记录 |
| 自身条件 | 父母各自的能力、资源、财官线索与局限 |
| 家庭与到达路径 | 田宅及祖辈／房产线；资源源头、传递、制约、命主所得与体感 |
| 相处与变化 | 原局作用、救应、同星多身份筛选、限运入口与确切日期、年龄／阶段 |
| 叠象 | 本象、落宫、掌宫、化曜、实际躔度、相关神煞如何支持具体描述 |
| 结论状态 | 已给盘面、老师规则、解释推演、实际反馈和未核项分开 |
| 隐私 | 方法资源仅留去身份规律；完整案例与经历不得进入 Skill 或规则镜像 |

允许归档的完整报告，客户文件与内部文件分别命名 `qz_tianshu_parents_report.md`、`qz_tianshu_parents_internal.md`。用户“不存档”时只在对话完成两层内容；只教方法或只总结案例规律时不生成个人报告和档案。
