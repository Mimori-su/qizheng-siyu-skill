# 报告风格

## 语言原则

- 中文为主，字段名和文件名可保留英文。
- 内部审查与通用跨专题汇总先数据后判断、先证据后结论；本命格局客户版先给简明总评，再展开有据分析，最后给具体鼓励建议。专题客户模板优先于通用顺序。
- 内部逐项区分“教材明确内容”“整理后的分析框架”“模型推理”“不确定项”；客户正文直接给出有依据的判断，不逐段展示审核话语。
- 语气自信、清楚、温和；结论强度与证据相称，不使用恐吓或无依据的绝对断言。

## 语言的艺术

### 自信表达：说清判断，不在句尾反复退让

2026-10-09 老师确认，适用于所有客户正文，包括性格、格局、婚恋、人际、事业、财运、健康、限运、合盘、校时与简析。只问单项也执行；该规范由 qz-report 集中管理，各专题不另养一套相冲突文风。

- 单项按所问范围输出，简版只压缩文字，不降低证据要求；不要为了套整合模板加上用户没问的其他专题。
- 客户先看结论，内部保留理论依据、支持与制约。尚无正式专题模板时，采用“核心结论 → 具体分析 → 针对性建议”，不直接交付技术审查标题。

- **结论 → 具体表现或依据 → 必要的行动指引**。已经说清楚就收住，不在段末再解释一遍自己没有承诺什么。
- 结论已有“容易、倾向、更适合、有机会”等强度表达时，不再机械追加“但不代表……”“这不等于一定……”“不能据此认定……”；没有新增信息的否定句删掉。
- 依据充分时直接写“适合从事……”“主要财源在……”“今年重点是……”。不叠加“可能、或许、一定程度上、值得优先验证”等缓冲词；判断的确定程度仍由证据决定。
- **真实代价写具体，空泛免责不补写**。例如写“项目增加，同时交付任务和分成成本也会增加”，不再跟一句“得到机会，不代表可以少做事情”。不利之处照实、委婉地说，并给出应对方向。
- 只有确实改变结论或行动选择的条件、反面证据、关键资料缺口，才在相关位置简要说明一次。内部审核话语留在理论档，不把“不能这样断、不能写成、尚不能证明”逐段搬进客户正文。
- 通用参考说明集中在结尾一句；健康、法律、投资或现实安全问题所需的具体边界仍按相关规范执行。删冗余，不补造事实、承诺结果或掩盖风险。

#### 改写示例

以下只示范表达，不新增断法；使用时须已有相应依据。

- 原：“你更适合靠专业服务获得收入，但这不代表你一定能赚大钱。”  
  改：“你更适合靠专业服务获得收入，重点把擅长的内容做成稳定、可交付的服务。”
- 原：“有助于取得合作支持，同时也增加任务与压力。得到机会，不代表可以少做事情。”  
  改：“有助于取得合作支持，同时也增加任务与压力。”
- 有实质风险时保留：“这一路数的优势在知识、设计与服务；重资产投入则要控制固定成本和回收周期。”不要为显得自信删掉后半句。

### 财富表达：充分肯定优势，不虚增金额

2026-10-13 老师确认；补充财运及格局报告中的财富表达，不改变原局判断规则或专题结构。

- **先讲能做成什么**：充分写明已有依据支持的财富来源、个人本领、外部支持和扩大成果的路径；鼓励要具体，不靠堆砌赞美或增加篇幅。
- **规模与代价分别说**：资产规模、现金状况、负债、合作消耗及局部投资损失分别表达，不因局部受制一概压低整体层次。影响优势兑现的关键制约，与优势同样清楚地交代；不把坏处包装成好处。
- **讲发展潜力，不设死上限**：区分已知资产事实、经验层次判断与条件具备时的发展空间。财运专题可按 `../../qz-wealth/resources/wealth_framework.md` 第10节采用老师已确认的经验量级，不能一律省略；命盘不能可靠换算当前人民币身家或确定财富天花板。不为了情绪价值抬高金额档位，也不把单个反馈固化成星曜与金额的对应规则。
- **贵人与机会也是财富助力**：日月会财与日月联系命身都进入财运层次；岁殿岁驾、禄马官魁文、三元禄有效会财亦予正向表达，具体说带来什么支持、机会或渠道。不把命身贵助只写成心情舒服，不堆标签或固定分值；完整成立条件继承财运模块。
- **结尾只作一次整体说明**：普通财富表达采用下句，不在各段反复免责；这句话不能替正文中无依据的金额承诺兜底，涉及真实资金的专业边界仍按财运规范执行。

> 以上侧重优势充分发挥时的发展空间，仅作传统取象参考；实际财富规模，还需结合时代背景、起步资源、个人业务与经营成果判断。

## 合并语气

- 保留 Core 和专题中影响结论的真实制约、资料缺口与必要风险；合并或删除重复的谨慎声明，不原样叠加到客户正文。
- 删除重复铺陈，但不得删掉关键制约因素。
- 本命格局客户版采用“简短依据＋现实意义”，展开可用星的行业、能力、资源与成就路径，不只报旺衰或心理标签。八方面是覆盖清单，可合并；同一结论不反复铺陈。依据充分时直接写适合方向，少用重复限定套话；总体参考说明集中在结尾一句，缺关键条件和重要制约仍如实保留。
- 限运客户版按五板块先结论后展开：阶段讲环境重心，事件讲实际变化、帮助、代价与应对，年份讲何时引动。躔度与神煞应进入有依据的具体描述，不变成术语清单；不得只输出旺衰或心理状态。同一事件不跨节反复铺陈。真实不利温和而清楚，不强行转成好事；建议和鼓励对应已有依据，总体参考说明集中结尾，关键缺项和现实专业边界仍须明示。
- 传统格局名是点睛语，不是结论本身：只调用 qz-core 已核定的正向名称，每篇通常一至两个，紧接白话解释；“有形但受限”写“有……之象，但……”。负向格名不进客户正文，现实压力与改善方向仍如实表达；不用“大贵、巨富、极品”等旧式词承诺结果。
- 多专题相互冲突时，写“存在不同取象，需要复核”，不强行得出统一结论。

## 推荐句式

- 宫度生克继承上游“双层解读”，把力量翻译成人事：该星代表谁，哪些宿度事务让其受到约束，哪些宫位领域提供滋养或支持。宫助与度制可同时表达，具体事务有依据才写；正文择要说明帮助与代价，不只列“得生、受克”，也不重复内部检查表。
- 星曜力量继承上游已核定的“力量等级＋状态说明”，再翻译帮助怎样到来：用神有力受制，可写支持有分量而落实费周折；偏弱但有效受生，可写后续有资源接续、适合渐进积累。具体说明补充或阻碍的来源，不只重复旺衰标签；完整依据见 qz-wangshuai 的“力量状态与帮助的供给方式”。不换算成百分比、收益或持续年数。
- “你的优势在……，适合通过……取得成果。”
- “主要支持来自……；需要承担的成本是……，可以提前做好……。”
- 关键资料确实缺失时：“目前缺少……，这一部分先分析到……。”只说明一次，不让其他有依据的判断一起退让。
